# SymPy 符号计算：表达式、方程与微积分

## SymPy 打印

### 1. 全局配置 (`init_printing`)

`init_printing()` 不仅仅是一个开关，它包含丰富的配置项，用于定义全局的渲染行为。
- **工作机制**：它会自动检测当前终端（IPython, Jupyter, 或纯控制台）并挂载最合适的打印机。
提示：

**常用核心参数**：
- `use_unicode=True/False`：强制或禁用 Unicode 字符渲染。
- `order='lex' | 'rev-lex'`：控制多项式的排列顺序（按字典序排，或逆字典序排）。
- `use_latex='mathjax' | 'png' | 'svg'`：在 Jupyter 中强制指定 LaTeX 的渲染引擎。

### 2. 基础打印函数 

针对表达式 $x^2 + \frac{1}{2}$，不同的打印器有截然不同的应用场景：
#### 2.1 标准字符串 `str(expr)`
- **输出**：`x**2 + 1/2`
- **工程意义**：这是最基础的 1D 纯文本，结果可以直接被 Python 原生的 `eval()` 或 SymPy 的 `sympify()` 解析回表达式。常用于日志记录（Logging）或数据序列化。

#### 2.2 美观打印 `pprint(expr)`
- **输出**：在终端画出二维的分数和指数。
- **工程意义**：当在没有 GUI 的服务器终端调试推导逻辑时，`pprint` 是唯一能让你直观检查公式对错的工具。默认使用 Unicode，若终端乱码，需显式传入 `pprint(expr, use_unicode=False)` 降级为 ASCII。

#### 2.3 LaTeX 源码 `latex(expr)`
- **输出**：`x^{2} + \frac{1}{2}`
- **进阶参数控制**：你可以通过参数精细控制排版。例如控制乘号的样式 `latex(expr, mul_symbol='dot')`（使用 $\cdot$ 而不是空格），或者让矩阵输出为 `bmatrix` 格式 `latex(matrix, mat_str='bmatrix')`。

## SymPy 基本操作

### 1. 替换
- 是有个subs(a, b)来实现将表达式中的所有某物实例替换为其它东西
- 用法如`expr.subs(x, 1)`
说明：

 替换通常出于以下原因:
1. 代点算出具体位置的值
2. 用另外一个子表达式替换子表达式
3. 进行一些受控的简化
- 该用法不会改变表达式(sympy表达式是不可变的, 没有改变表达式的函数)

### 2. `sympify`
- 用来将字符串转换为表达式
```python
str_expr = "x**2 + 3*x - 1/2"
expr = sympify(str_expr)
```

### 3. `evalf`
- 将数值表达式计算为浮点数
```python
expr = sqrt(8)
expr.evalf()
# 结果为浮点数形式
```
- 可以一任意精度计算浮点表达式, 例如`evalf(15)`将保留15位小数
- 类似`evalf(subs={x: 2.4})`实现对表达式的数值评估
- 使用chop标志设置是否删除输入误差
说明：

舍入误差: 取近似值从而减少计算代价

### 4. `lambdify`
- 一次性在多个点上评估一个表达式
```python
import numpy 
a = numpy.arange(10) 
expr = sin(x)
f = lambdify(x, expr, "numpy")
```

## SymPy 基础介绍

### 1. 符号运算

- 符号计算处理的是以符号形式进行的数学对象的计算
- 这意味着数学对象被精确地表示，而不是近似地表示，并且带有未求值变量的数学表达式保持符号形式
- 符号结果可以进行符号简化, 能够一符号的方式进行各种运算
- 表达式不会计算出结果，而是输出符号化的结果
- 除了明显的简化外, 大多数简化不会自动执行
- sympy包含了用于包含了用于绘图、打印（如数学公式的二维漂亮打印输出，或 ）、代码生成、物理、统计、组合学、数论、几何、逻辑等的模块

sympy的优点: 开源免费\轻量级\作为库使用

### 2. SymPy 注意事项

#### 2.1 符号

- 在 SymPy 中，变量不会自动定义。要定义变量，我们必须使用 `symbols`
- `symbols` 接受一个由空格或逗号分隔的变量名组成的字符串，并从中创建符号; 然后，我们可以将这些符号赋值给变量名
- 符号的名称和它所赋值的变量名称之间不需要有任何关系, 符号可以有超过一个字符的名字
```python
>>> a, b = symbols('b a')
>>> a
b
>>> b
a
```

- 如果一个变量被改变，已经用该变量创建的表达式不会自动改变
说明：

```python
x = symbols('x')
expr = x + 1
print(expr)
```
其结果为x + 1 , 原因在于:
将 `x` 改为 `2` 对 `expr` 没有影响。这是因为 `x = 2` 将 Python 变量 `x` 改为 `2`，但对我们在创建 `expr` 时使用的 SymPy 符号 `x` 没有影响。当我们创建 `expr` 时，Python 变量 `x` 是一个符号。创建后，我们将 Python 变量 `x` 改为 2。但 `expr` 保持不变。

- 在表达式中更改符号的值，使用 `subs`

#### 2.2 等号

- 在 SymPy 中，`==` 表示精确的结构相等性测试, 只有在结构上完全相等是才会返回`Ture`
- 如果$a = b$，那么$a - b = 0$ 。因此，检查是否相等的最佳方法是取$a - b$并简化它，看看它是否变为 0。

#### 2.3 其它事项

- 使用 `**` 进行幂运算, `^` 表示逻辑异或
- 每当你结合一个SymPy对象和一个SymPy对象，或者一个SymPy对象和一个Python对象时，你会得到一个SymPy对象
- 每当你结合两个Python对象时，SymPy永远不会介入，因此你会得到一个Python对象

## SymPy 简化

### 1. 通用化简函数：`simplify()`

- **功能**：智能尝试应用多种底层化简操作，并使用启发式算法确定表达式的“最简”形式。

**示例**：

- `simplify(sin(x)**2 + cos(x)**2)` → `1`
- `simplify((x**3 + x**2 - x - 1)/(x**2 + 2*x + 1))` → `x - 1`
- `simplify(gamma(x)/gamma(x - 2))` → `(x - 2)*(x - 1)`

注意：

**局限与陷阱**：
1. **“最简”定义不明确**：例如希望将 $x^2 + 2x + 1$ 变为 $(x + 1)^2$，调用 `simplify` 仍会返回展开的形式（此时应使用 `factor()`）。
 2. **执行速度较慢**：在选择最佳结果前，它会尝试非常多种类的化简运算。
3. **无输出形式保证**：它不保证结果具有特定的数学结构（如不可约因式等），甚至可能错过某些 SymPy 本能做到的特定化简。

- **使用建议**：最适合在交互式环境中探索未知表达式时使用。若明确知道需要何种化简，应直接调用后续的特定函数。

### 2. 多项式与有理函数化简

#### 2.1 展开：`expand()`

- **功能**：将多项式展开为单项式求和的规范形式

#### 2.2 因式分解：`factor()` 与 `factor_list()`

- **功能**：在有理数域内，将多项式分解为“不可约”的因式。它是 `expand()` 的逆操作。
- **保证**：调用它处理带有理系数的多项式时，能保证得出的每个因式都是不可约的。
- **结构化输出**：使用 `factor_list()` 可以返回一个包含常数项及 `(因式, 幂次)` 列表的结构化元组。
```python
factor_list(x**2*z + 4*x*y*z + 4*y**2*z)
# (1, [(z, 1), (x + 2⋅y, 2)])
```

#### 2.3 提取公因式：`collect()`

- **功能**：在表达式中，收集某个指定变量的共同次幂。
- **配套方法**：结合 `.coeff(x, n)` 方法，可以直接提取出表达式中 $x^n$ 对应的系数。

#### 2.4 约分：`cancel()`
- **功能**：将任意有理函数转化为标准形式 $p/q$。其中分子 $p$ 和分母 $q$ 是没有公因式的展开多项式，且首项系数没有分母（即系数为整数）。

#### 2.5 部分分式分解：`apart()`
- **功能**：对有理函数进行部分分式分解，拆解为多个分式的和。
```
   3       2
4⋅x  + 21⋅x  + 10⋅x + 12
────────────────────────
  4      3      2
 x  + 5⋅x  + 5⋅x  + 4⋅x

 通过apart后化简为

 
  2⋅x - 1       1     3
────────── - ───── + ─
 2           x + 4   x
x  + x + 1
```

### 3. 三角函数化简

提示：

SymPy 中的反三角函数按 Python 约定命名，即在前面加 `a`，如 `acos`, `asin`)_

#### 3.1 恒等式化简：`trigsimp()`

- **功能**：使用三角恒等式化简表达式，同样使用启发式算法返回“最佳”结果。
- **范围**：支持常规三角函数，也支持双曲三角函数。

#### 3.2 恒等式展开：`expand_trig()`

- **功能**：应用和差角公式或倍角公式展开三角函数
- 如将 `sin(x + y)` 展开为 `sin(x)*cos(y) + sin(y)*cos(x)`）
- 它与 `trigsimp()` 的操作方向通常相反。

### 4. 幂运算化简 (Powers)

注意：

三种幂运算恒等式及其在复数系统中的有效性前提：
- **$x^a x^b = x^{a+b}$**：始终成立。
- $x^a y^a = (xy)^a$**：**非**始终成立（反例：$x=y=-1, a=1/2$ 时计算结果冲突）。成立的充分条件是：$x, y \ge 0$ 且 $a$ 为实数。
- **$(x^a)^b = x^{ab}$**：**非**始终成立。成立的充分条件是：$b$ 是整数。


基于上述法则，对应以下化简函数：
- **`powsimp()`**：从左至右应用恒等式 1 和 2 合并幂次。
- **`expand_power_exp()`**：从右至左应用恒等式 1，拆分指数。
- **`expand_power_base()`**：从右至左应用恒等式 2，拆分底数。
- **`powdenest()`**：从左至右应用恒等式 3，化简嵌套的幂。
- **`force=True` 参数**：如果不希望受限于上述成立条件，可以在调用这些函数时传入 `force=True`，强制忽略变量的安全假设进行化简运算。

### 5. 指数与对数化简

注意：

对数恒等式 $\log(xy) = \log(x) + \log(y)$ 与 $\log(x^n) = n\log(x)$ 并非对任意复数都成立，其充分条件是 **$x, y$ 均为正数且 $n$ 为实数**。

- **`expand_log()`**：从左至右应用恒等式，展开对数。
- **`logcombine()`**：从右至左应用恒等式，合并对数。
- _(这两个函数同样支持使用 `force=True` 强制化简。)_

## SymPy 矩阵

### 1. 矩阵的引入与创建

在使用矩阵之前，需要从 `sympy` 导入 `Matrix` 类以及相关的特殊矩阵函数。SymPy 中的矩阵默认是可变的（Mutable），如果需要不可变矩阵，可以使用 `ImmutableMatrix`。
```python
from sympy import Matrix, eye, zeros, ones, diag, symbols
```

#### 1.1 基础创建

最常见的创建方式是通过传入一个“列表的列表”（list of lists）。
```python
# 创建一个 2x2 矩阵
M = Matrix([[1, 2], [3, 4]])
# 创建一个列向量 (等价于 3x1 矩阵)
V = Matrix([1, 2, 3]) 
```

对应的数学表示为：
$M = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}, \quad V = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}$

#### 1.2 特殊矩阵构造器

SymPy 提供了快速构造常见矩阵的方法：
- **单位矩阵：** `eye(n)` 创建一个 $n \times n$ 的单位矩阵。
- **零矩阵：** `zeros(r, c)` 创建一个 $r$ 行 $c$ 列的全零矩阵。
- **全 1 矩阵：** `ones(r, c)` 创建一个 $r$ 行 $c$ 列的全 1 矩阵。
- **对角矩阵：** `diag(1, 2, 3)` 创建对角线元素为 1, 2, 3 的矩阵。`diag` 也可以用来拼接块矩阵（Block Matrices）。

### 2. 基本属性与操作

#### 2.1 形状与索引
与 NumPy 类似，SymPy 矩阵支持基于 0 的索引。
```python
M.shape  # 返回元组 (rows, cols)，例如 (2, 2)
M[0, 1]  # 获取第 1 行、第 2 列的元素 (值为 2)
```

#### 2.2 行与列的提取
```python
M.row(0)  # 提取第一行，返回 Matrix([[1, 2]])
M.col(-1) # 提取最后一列，返回 Matrix([[2], [4]])
```

#### 2.3 基础数学运算

矩阵支持标准的算术运算符（要求维度匹配）：
- **加减法：** `M + N`, `M - N`
- **矩阵乘法：** `M * N` (注意：这是矩阵乘法，不是逐元素乘法)
- **标量乘法：** `3 * M`
- **矩阵求幂：** `M**2` (等价于 `M * M`)
- **求逆：** `M**-1` (等价于 `M.inv()`)

#### 2.4 转置
```python
M_T = M.T
```

### 3. 核心线性代数运算 (Linear Algebra)

这是 SymPy 矩阵模块最核心的价值所在，支持符号计算。

#### 3.1 行列式 (Determinant)

计算矩阵的行列式：

```python
M = Matrix([[1, 2], [3, 4]])
det_M = M.det()  # 返回 -2
```

#### 3.2 行最简形 (Reduced Row Echelon Form - RREF)

`rref()` 方法返回一个元组：`(简化后的矩阵, 主元列的索引元组)`。

```python
M = Matrix([[1, 2, 3], [2, 4, 6], [1, 1, 1]])
M_rref, pivots = M.rref()
# M_rref 为 Matrix([[1, 0, -1], [0, 1, 2], [0, 0, 0]])
# pivots 为 (0, 1)
```

#### 3.3 零空间与列空间 (Nullspace & Columnspace)

- **零空间：** `M.nullspace()` 返回一个列表，包含构成零空间基的列向量。
    
- **列空间：** `M.columnspace()` 返回一个列表，包含构成列空间基的列向量。
    

#### 3.4 特征值与特征向量 (Eigenvalues & Eigenvectors)

- **特征值：** `M.eigenvals()`
    
    - 返回一个字典：`{特征值: 代数重数}`。
        
    - 例如 `{3: 1, -2: 1}` 表示特征值 3 和 -2 的代数重数均为 1。
        
- **特征向量：** `M.eigenvects()`
    
    - 返回一个列表，列表元素为元组：`(特征值, 代数重数, [特征向量列表])`。
        

#### 3.5 对角化 (Diagonalization)

如果矩阵 $M$ 可对角化，`diagonalize()` 返回矩阵 $P$ 和对角矩阵 $D$，使得 $M = P D P^{-1}$。

```python
P, D = M.diagonalize()
# 验证： P * D * P**-1 == M
```

### 4. 矩阵微积分 (Matrix Calculus)

SymPy 允许矩阵元素为符号变量，从而支持微积分操作。

#### 4.1 符号矩阵

```python
x, y = symbols('x y')
F = Matrix([x**2 + y, 2*x*y])
```

#### 4.2 雅可比矩阵 (Jacobian)

如果要计算向量函数对变量的雅可比矩阵，可以使用 `jacobian()` 方法：

```python
X = Matrix([x, y])
J = F.jacobian(X)
```

上述代码将计算：

$J = \begin{bmatrix} \frac{\partial (x^2+y)}{\partial x} & \frac{\partial (x^2+y)}{\partial y} \\ \frac{\partial (2xy)}{\partial x} & \frac{\partial (2xy)}{\partial y} \end{bmatrix} = \begin{bmatrix} 2x & 1 \\ 2y & 2x \end{bmatrix}$

### 5. 求解线性方程组

给定方程组 $Ax = b$，在 SymPy 中可以使用 `LUsolve` 或 `solve` 等方法直接求解：

```python
A = Matrix([[1, 2], [3, 4]])
b = Matrix([5, 6])

# 方法 1：使用矩阵逆 (不推荐用于大型或病态系统)
x = A.inv() * b

# 方法 2：使用 LUsolve (推荐)
x = A.LUsolve(b)
```

## SymPy 求解器

### 1. 关于等式表达的底层逻辑

- **等式的声明**：在 SymPy 中，符号等式不能使用 Python 原生的 `=` 或 `==`，必须使用 **`Eq(左边, 右边)`**。例如：`Eq(x, y)`。
- **“默认等于零”机制**：求解器默认将所有传入的非 `Eq` 表达式视为等于 0。
- 在使用等式求解的时候建议使用`solveset(x**2 - 1, x)`

### 2. 求解代数方程

#### 2.1 单变量求解：`solveset`
```python
solveset(equation, variable=None, domain=S.Complexes)
```
(默认在复数域内求解)

说明：

**返回类型**：
   - **有确切解**：返回集合 `FiniteSet`、`Interval`（区间）或带通项公式的集合（如求解三角函数 `sin(x) - 1` 返回的解集）。
  - **无解**：返回空集 `EmptySet` (显示为 `∅`)。
- **算法无法解出**：返回条件集 `ConditionSet`（表示数学上知道这是个方程，但无法给出显式解）。

- `solveset` 对同一个根只输出一次，**不包含多重根的重数信息**。如果你需要计算根的多重性，需调用 **`roots()`** 函数，它会返回一个字典 `{根: 重数}`。


#### 2.2 线性方程组：`linsolve`

用于求解线性系统，支持三种数学上常用的输入形式。解的元组顺序严格对应你传入的符号顺序。

1. **表达式列表形式**：`linsolve([x + y + z - 1, x + y + 2*z - 3], (x, y, z))`
2. **增广矩阵形式**：传入包含系数和常数项的 `Matrix`。
3. **$Ax = b$ 形式**：提取出系数矩阵 $A$ 和常数向量 $b$ 后代入。


#### 2.3 非线性方程组：`nonlinsolve`
支持求解各类非线性方程组，能够同时处理仅有实数解、仅有复数解、以及拥有无穷多解（返回含参变量的解集）的系统。


注意：

目前 `solveset` 和 `nonlinsolve` 仍有功能盲区，遇到以下情况需**回退使用老版本的 `solve()`**：
1. **涉及 LambertW 函数的超越方程**（如解 $x e^x - 1 = 0$）。
2. **非线性方程组中包含三角函数**。
3. `nonlinsolve` 算不出来的带有指数变量的混合非线性组。
    

### 3. 求解微分方程

SymPy 提供了 **`dsolve`** 用于求解常微分方程 (ODE, 位置函数只含有一个自变量的微分方程)。

- **前置准备：定义未求解的函数**
    在解微分方程前，不能只定义普通变量，必须把 $f(x)$ 声明为一个函数类：
    `f, g = symbols('f g', cls=Function)`
    
- **构建微分方程**
    使用 `f(x).diff(x)` 表示一阶导数 $f'(x)$，`f(x).diff(x, x)` 表示二阶导数 $f''(x)$。通过 `Eq()` 将它们组装起来。
    
- **核心求解：`dsolve`**
    - **语法**：`dsolve(diffeq, f(x))`
    - **返回值**：返回的是一个 `Eq` 等式实例。因为很多复杂的微分方程解无法写出 $f(x) = ...$ 的显式形式，只能给出隐函数表达。
    - **积分常数**：结果中自动生成的任意常数将被统一表示为 `C1`, `C2`, `C3` 等符号。

## SymPy 微积分

### 1. 导数 (Derivatives)

- **基础求导**：使用 `diff()` 函数。例如 `diff(cos(x), x)`。    
- **高阶求导**：
    - 方式一：多次传入变量，如 `diff(x**4, x, x, x)`。
    - 方式二：传入阶数，如 `diff(x**4, x, 3)`。
- **多元偏导数**：按顺序传入变量和对应的阶数。例如计算 $\frac{\partial^7}{\partial x \partial y^2 \partial z^4} e^{xyz}$，语法为 `diff(expr, x, y, 2, z, 4)`。
- **面向对象调用**：作为表达式的方法调用，`expr.diff(x, y, 2)` 与 `diff(expr, x, y, 2)` 完全等价。
- **延迟计算 (Unevaluated)**：使用 `Derivative` 类可创建一个**不立即求值**的导数对象（常用于公式展示或包含未知函数时）。需要计算时再调用 `.doit()` 方法。
- **未知阶数**：可以传入元组 `(x, n)` 表示对 $x$ 求 $n$ 阶导数。

### 2. 积分 (Integrals)

#### 2.1 不定积分

- 使用 `integrate()` 并传入积分变量。如 `integrate(cos(x), x)`。
- **注意**：SymPy 计算不定积分时**不会自动添加积分常数**（如 $+C$）。如果需要，可以自己手动加上，或者将其转化为微分方程用 `dsolve()` 求解。

#### 2.2 定积分

- 传入包含上下限的元组 `(变量, 下限, 上限)`。
    - 示例：计算 $\int_0^\infty e^{-x} dx$，语法为 `integrate(exp(-x), (x, 0, oo))`。
    - **技巧**：在 SymPy 中，无穷大 $\infty$ 使用两个小写字母 `oo` 表示。

#### 2.3 多重积分
- 连续传入多个限制元组即可。如 `integrate(expr, (x, -oo, oo), (y, -oo, oo))`。

注意：

如果积分只有在特定条件成立时才收敛，`integrate` 会返回一个 `Piecewise`（分段函数）表达式。

### 3. 数值积分 (Numeric Integration)

当符号积分极其困难或不可能求解（如被积函数过于复杂）时，可以调用底层的 `mpmath` 库进行数值积分。

- **调用方式**：先构建 `Integral` 对象，再调用 `.evalf()` 方法。如 `Integral(exp(-x**2), (x, -oo, oo)).evalf()`。
    
- **自定义精度**：可以传入参数设定有效数字位数，例如 `integral.evalf(50)` 将计算至小数点后 50 位。
    

### 4. 极限 (Limits)

- **基础求极限**：使用 `limit()` 函数。语法为 `limit(函数, 变量, 趋近点)`。
- **避免使用 `subs()`**：在奇点（Singularity）求值时，不能使用直接代入法 `subs()`，因为这会导致 `nan`（Not-a-Number）或忽略增长率问题。必须使用 `limit()`。
- **单侧极限**：传入第四个参数 `'+'` 或 `'-'`。例如求 $\lim_{x \to 0^+} \frac{1}{x}$，语法为 `limit(1/x, x, 0, '+')`。
- **延迟计算**：未求值形式使用 `Limit` 类，配合 `.doit()` 执行。
    

### 5. 级数展开 (Series Expansion)

- **泰勒/渐近展开**：使用表达式的方法 `expr.series(x, x0, n)`。默认情况下，它会在 $x_0 = 0$ 处展开到第 6 阶。
- **朗道阶数 $O$**：展开式的末尾会带有类似 $O(x^4)$ 的项（大 $O$ 符号），表示所有次幂大于或等于 4 的项均被忽略。
- **截断级数**：如果仅需要前面的多项式部分而不需要 $O$ 项，可调用 `.removeO()` 方法去除它。
    

### 6. 有限差分 (Finite differences)

用于没有闭式解析函数或处理离散点时的导数近似。
- **直接应用差分**：`differentiate_finite(expr)` 可直接给出该表达式的有限差分形式。
- **基于求导实例**：如果你已经有了一个 `Derivative` 实例，可以使用 `.as_finite_difference()` 将其转化为有限差分近似，支持传入自定义的网格步长（如 `[-3*h, -h, 2*h]`）。
- **底层权重计算**：`finite_diff_weights()` 可以用于专门计算特定差分方案下的权重系数。
- **灵活求值**：`apply_finite_diff()` 允许直接传入指定的阶数、横坐标列表和待估算点，输出有限差分的结果。
