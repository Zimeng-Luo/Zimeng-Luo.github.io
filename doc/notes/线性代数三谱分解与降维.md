# 线性代数（三）：特征分解、二次型与 SVD 降维

矩阵变换有些方向只会被缩放，这些方向由特征向量描述；数据的主要变化方向可以通过协方差与 SVD 找到。本篇把代数判定连接到降维应用。

## 特征值与相似对角化

`Av=λv` 中 v 必须非零。特征值来自 `det(λI−A)=0`，对应特征向量是 `(A−λI)v=0` 的非零解。计入代数重数时，特征值的和为迹，乘积为行列式。

```text
A = PDP⁻¹
Aᵏ = PDᵏP⁻¹
```

n 阶矩阵只有具备 n 个线性无关的特征向量，才可这样对角化。不同特征值对应的特征向量线性无关，但重复特征值未必有足够独立向量。比如矩阵 `[1 1; 0 1]` 与单位矩阵特征值相同，却不可相似于单位矩阵。

相似变换是同一线性映射的换基表示，保持特征多项式。实对称矩阵更特殊：特征值实数，可以取正交归一特征向量，写成 `A=QΛQᵀ`。

## 二次型关注曲面的形状

```text
f(x) = xᵀAx
x = Cy  →  f(x) = yᵀ(CᵀAC)y
```

实二次型用对称矩阵表示，交叉项系数在对称位置各分一半。换坐标对应合同变换，通常不是相似变换。

| 关系 | 形式 | 主要保持量 |
| --- | --- | --- |
| 等价 | `B=PAQ`，P、Q 可逆 | 秩 |
| 相似 | `B=P⁻¹AP` | 特征值等谱信息 |
| 合同 | `B=CᵀAC` | 实对称情形的惯性指数 |

对实对称矩阵，正定表示所有非零 x 都满足 `xᵀAx>0`，等价于所有特征值为正，也等价于所有顺序主子式为正。半正定允许零特征值，不能直接将“顺序主子式全为非负”当作相同的充分判据。

正交变换能将二次型化为平方项之和。惯性指数描述正负方向数，帮助区分椭球、双曲面和锥面；完整曲面分类还需看线性项、常数项与退化方向，不能只凭某个平方项缺失就下结论。

## 协方差把数据变成几何对象

随机向量的协方差定义为 `C=E[(X−μ)(X−μ)ᵀ]`。对角线是方差，非对角线是协方差。它对称且半正定，因为 `aᵀCa=Var(aᵀX)≥0`。

协方差为零表示线性不相关，不一般意味着独立。量纲也影响协方差；比较不同单位的特征时，可考虑先标准化，零方差特征需单独处理。

行是样本、列是特征，中心化矩阵 Xc 的样本协方差为：

```text
C = XcᵀXc/(m−1)    （m>1）
```

PCA 选择 C 的大特征值方向。主方向代表大方差，不必然代表对具体预测任务最有用的信息。

## SVD 适用于一般矩阵

对于实矩阵 `A ∈ R^(m×n)`：

```text
A = UΣVᵀ
AᵀA = VΣᵀΣVᵀ
```

U 和 V 的完整形式是正交矩阵，Σ 为矩形对角矩阵，奇异值非负。奇异值是 `AᵀA` 特征值的平方根；秩等于非零奇异值个数。

保留前 k 个奇异方向得到截断 SVD，是给定秩限制下的重要最优低秩近似。对中心化数据做 SVD，V 的列给出 PCA 的特征方向：

```text
C = V [ΣᵀΣ/(m−1)] Vᵀ
```

```python
import numpy as np

X = np.array([[1., 2.], [2., 3.], [3., 5.], [4., 4.]])
Xc = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
explained_variance = s**2 / (X.shape[0] - 1)
components = Vt[:1]
reduced = Xc @ components.T
reconstructed = reduced @ components + X.mean(axis=0)
```

返回的 s 是一维奇异值序列，Vt 已经是转置，不要重复转置后再当相同对象使用。特征向量正负号可能变化，不影响对应子空间。

## 白化与数值边界

若协方差分解为 `C=QΛQᵀ`，旋转到主方向可去相关，再以 `Λ⁻¹ᐟ²` 缩放可白化。零特征值不能直接求倒数；极小特征值会放大噪声，需截断或正则化。加正则项后通常也不再具有精确单位协方差。

对实对称协方差矩阵可用 `eigh`，数值 PCA 常直接对中心化数据做 SVD，避免显式构造 `XcᵀXc` 带来的条件数恶化。降维时还应保存训练均值与投影方向，以便新数据使用同一变换。
