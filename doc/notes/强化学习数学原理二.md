# 强化学习数学原理（二）：从蒙特卡罗到时序差分

## L5 蒙特卡罗方法

### 一、核心概念与动机

#### 1. 什么是蒙特卡罗 (MC) 估计？

- **定义**：蒙特卡罗估计是一类依赖于**重复随机采样**来解决近似问题的广泛技术 。

- 基本思想: 随着次数增大, 期望趋近于重复随机采样结果的平均值(下方: 大数定理)
 
- **模型无关性 (Model-free)**：MC 最核心的价值在于它**不需要环境模型**（即不需要知道状态转移概率 $p(s'|s,a)$ 或奖励函数 $r(s,a)$） 。

- **期望估计**：由于强化学习中的状态价值和动作价值定义为**随机变量的期望**，因此可以用 MC 均值估计来处理 。


#### 2. 数学基础：大数定律 (Law of Large Numbers)

- 通过对独立同分布 (iid) 的随机变量 $X$ 进行 $N$ 次采样 $\{x_j\}_{j=1}^N$，其算术平均值 $\bar{x} = \frac{1}{N}\sum x_j$ 是对期望 $\mathbb{E}[X]$ 的无偏估计 。
    
- **方差特性**：$Var[\bar{x}] = \frac{1}{N}Var[X]$。这意味着随着样本量 $N$ 的增加，估计的方差趋于零，精度不断提高 。
    

---

### 二、 从策略迭代到模型无关 RL

要将经典的策略迭代（Model-based）转变为模型无关（Model-free），核心在于**动作价值 $q_{\pi}(s,a)$ 的计算方式** ：

1. **基于模型 (Expression 1)**：需要状态转移概率和奖励期望 。
    
2. **模型无关 (Expression 2)**：利用定义 $q_{\pi}(s,a) = \mathbb{E}[G_t |S_t=s, A_t=a]$ 。
    
    - **方法**：从状态-动作对 $(s,a)$ 开始，按照策略 $\pi$ 生成多个片段（Episodes），计算这些片段的回报（Returns）并求平均值 。

说明：

$G _t$是一个随机变量, 根据某个特定的策略, 推测出该步后续该怎么做之后, 计算出其return为$G _t$的一个采样
        

**注意**：模型无关强化学习必须直接估计 **动作价值 $q$** 而非状态价值 $v$，因为没有模型时，仅靠 $v$ 无法直接进行策略改进 。

---

### 三、 三大 MC 算法详解

讲义介绍了从简单到实用的三种算法 ：

#### 1. MC Basic (最简单的 MC RL)

- **定位**：策略迭代的模型无关变体 。
    
- **流程** ：

	- 从某一初始策略出发, 该策略可能并不优秀
	
    - **策略评估**：对**每一个**状态-动作对 $(s,a)$，运行足够多的片段并取平均回报来更新 $q(s,a)$。

注意：

- 策略固定的是action的概率分布, 并且由于环境的影响即便采取了确定的动作，结果也不一定确定, 因此每次采样得到的片段对应的return并不是固定的
- 进而, 如果动作和环境都是固定的, 那就只需要采样一次
        
- **策略改进**：根据更新后的 $q$ 值更新策略，$\pi(s) = \arg\max_a q(s,a)$。
        
- **缺点**：效率极低，需要等待大量片段完成才能更新一次策略 。
    

#### 2. MC Exploring Starts (探索性初始化 MC)

- **改进点**：数据利用率更高 。
    
    - **片段内更新**：不仅更新起始点的 $q$ 值，还利用片段内经过的所有点。
        
    - **逐片段改进**：每生成一个片段就进行一次策略更新（Generalized Policy Iteration 框架） 。
        
- **探索性初始化 (Exploring Starts)**：要求每个 $(s,a)$ 都有可能作为片段的起点，以确保充分探索 。

- **visit**: 在采样中出现一次state-action pair

![image.png](https://cdn.jsdelivr.net/gh/lanjinnian/base_picture_bed/img/20260409140409683.png)


#### 3. MC $\epsilon$-Greedy (无须探索性初始化的 MC)

- **引入软策略 (Soft Policy)**：如果一个策略对任何动作的概率都大于零，则称为软策略 。
    
- **$\epsilon$-贪婪策略** ：
    
    - 以 $1-\epsilon$ 的概率选择最优动作。
        
    - 以 $\epsilon$ 的概率随机选择（包含最优动作在内的所有动作）。
        
    - **目的**：平衡**开发 (Exploitation)** 和 **探索 (Exploration)** 。
        
- **核心逻辑**：通过策略本身的随机性来遍历所有状态-动作对，从而**移除对“探索性起点”的强制要求** 。
    

---

### 四、 关键技术细节与发现

#### 1. 数据的有效利用：Visit 概念

- **First-visit**：仅在片段中第一次出现该状态-动作对时计算回报 。
    
- **Every-visit**：片段中每一次出现该对时都计算回报并计入平均 。

#### 2. 片段长度 (Episode Length) 的影响

- **实验观察**：在网格世界实验中，若片段过短，只有靠近目标的点才有非零价值 。
    
- **结论**：片段长度必须**足够长**才能传播奖励信号，但不需要无限长（受到折扣因子 $\gamma$ 的影响） 。
    
#### 3. 最优性与探索的权衡

- **优势**：$\epsilon$-greedy 策略具有更强的探索能力，不需要探索性起点 。
    
- **劣势**：$\epsilon$-greedy 策略通常**不是全局最优**的（仅在其所属的策略集中最优） 。
    
- **观察**：随着 $\epsilon$ 增大，策略的最优性变差，甚至可能导致目标状态的价值变为负值 。
    

---

### 五、 总结图谱

| **算法**                   | **核心特点**               | **探索机制**                 |
| ------------------------ | ---------------------- | ------------------------ |
| **MC Basic**             | 策略迭代的直接转化，效率低          | 探索性起点 (Exploring Starts) |
| **MC Exploring Starts**  | 片段内学习，逐片段改进            | 探索性起点                    |
| **MC $\epsilon$-Greedy** | 利用 $\epsilon$-贪婪策略进行探索 | 策略本身的随机性                 |

## L6 随机近似与随机梯度下降

### 1. 均值估计的迭代实现 (Mean Estimation)

均值估计是强化学习的基础，因为状态或动作价值通常被定义为期望值 。

- **计算挑战**：传统的非增量方法需要收集所有样本后统一计算平均值，这导致在样本采集期间无法获得估计结果 。
    
- **迭代公式**：通过代数推导，均值估计可以转化为增量形式 ：
    
    $$w_{k+1}=w_{k}-\frac{1}{k}(w_{k}-x_{k})$$
    
- **算法优势**：
    
    - 每获得一个新样本 $x_k$，即可立即更新均值估计 $w_{k+1}$ 。
        
    - 虽然初始估计不准确，但随着样本增加，估计值会逐渐趋向于真实期望 $\mathbb{E}[X]$ 。
        
- **通用形式**：将 $1/k$ 替换为通用的学习率系数 $\alpha_k > 0$ 。
     

---

### 2. Robbins-Monro (RM) 算法

RM 算法是随机逼近（SA）领域的先驱性工作，旨在通过有噪声的数据解决寻根或优化问题 。

#### 2.1 问题定义

- **目标**：寻找方程 $g(w)=0$ 的根 $w^*$ 。
    
- **核心困难**：函数 $g(w)$ 的表达式通常是未知的（如神经网络），只能获得观测值 $\tilde{g}(w_k,\eta_k)=g(w_k)+\eta_k$，其中 $\eta_k$ 为噪声 。

- **核心目标**: ![image.png](https://cdn.jsdelivr.net/gh/lanjinnian/base_picture_bed/img/20260413130854407.png)
    

#### 2.2 算法公式与哲学

- **算法更新**：$w_{k+1}=w_{k}-a_{k}\tilde{g}(w_{k},\eta_{k})$ 。
    
- **哲学思想**：在没有模型（即函数表达式）的情况下，依靠数据进行迭代 。

- $\tilde{g}(w_{k},\eta_{k})$: 包含噪音的观测值


#### 2.3 收敛条件 (RM 定理)

若满足以下三个条件，算法将以概率 1 收敛到 $w^*$ ：

1. **梯度限制**：$0 < c_1 \le \nabla_{w}g(w) \le c_2$，保证 $g(w)$ 单调递增且根唯一，同时梯度有上界 。
    
2. **步长约束**：
    
    - $\sum_{k=1}^{\infty}a_{k}=\infty$：确保步长不会过快收敛到 0，使算法有能力到达任意远的根 。(确保$w_1$可以随便选择)
        
    - $\sum_{k=1}^{\infty}a_{k}^{2}<\infty$：确保步长最终趋于 0 以抵消随机噪声的影响 。(确保最终$w_{k+1} - w_k$会趋近于0, 最终结果会收敛)
        
3. **噪声性质**：噪声 $\eta_k$ 的条件期望为 0，且方差有限 。
    

---

### 3. 随机梯度下降 (Stochastic Gradient Descent, SGD)

SGD 是 RM 算法在优化问题中的特殊应用 。

#### 3.1 优化目标

- **目标函数**：最小化 $J(w)=\mathbb{E}[f(w,X)]$ 。
    
- **等效根寻找**：该优化问题可转化为寻找 $\nabla_{w}J(w)=\mathbb{E}[\nabla_{w}f(w,X)]=0$ 的根 。
    

#### 3.2 三种梯度下降方法对比

|**方法**|**更新公式**|**核心差异**|
|---|---|---|
|**GD (梯度下降)**|$w_{k+1}=w_{k}-\alpha_{k}\mathbb{E}[\nabla_{w}f(w_{k},X)]$|使用真实梯度的期望值 。|
|**BGD (批量GD)**|$w_{k+1}=w_{k}-\alpha_{k}\frac{1}{n}\sum_{i=1}^{n}\nabla_{w}f(w_{k},x_{i})$|每次迭代使用数据集中所有样本 。|
|**SGD (随机GD)**|$w_{k+1}=w_{k}-\alpha_{k}\nabla_{w}f(w_{k},x_{k})$|每次迭代仅随机抽取一个样本，是 $n=1$ 的特殊情况 。|
|**MBGD (小批量GD)**|$w_{k+1}=w_{k}-\alpha_{k}\frac{1}{m}\sum_{j\in\mathcal{I}_{k}}\nabla_{w}f(w_{k},x_{j})$|每次迭代随机抽取 $m$ 个样本 。|

#### 3.3 SGD 的收敛模式

- **收敛性质**：当 $w_k$ 距离最优解 $w^*$ 较远时，SGD 的表现非常接近 GD，能够快速接近目标区域 。
    
- **随机波动**：当 $w_k$ 接近 $w^*$ 时，由于单个样本梯度的随机性，收敛过程会表现出更多的随机震荡 。
    

---

### 4. 总结与关联 (Summary)

- **数学纽带**：均值估计可以看作是一个特殊的 SGD 过程，而 SGD 本质上是一个特殊的 RM 算法过程 。
    
- **核心价值**：这些算法不依赖于模型的具体表达式，而是基于数据的反馈进行迭代更新 。
    
- **后续影响**：随机逼近的思想为下一讲“时序差分（TD）学习”提供了理论框架，因为 TD 算法在表达形式上与 SA 算法高度相似 。

## L7 时序差分方法

### 1. 时序差分（TD）学习简介

时序差分（TD）学习是强化学习中最知名且核心的方法之一 。它是继蒙特卡洛（MC）之后的第二种**免模型（Model-free）**方法 。

- **数学本质**：TD算法可以被视为求解给定策略 $\pi$ 的**贝尔曼方程**（Bellman Equation）的随机逼近（SA）算法 。
    
- **核心优势**：
    
    - **在线更新（Online）**：获得奖励后可立即更新，无需等待回合结束 。
        
    - **适用连续任务**：由于其在线特性，TD可处理非终止性的持续任务 。
        
    - **低方差**：相比MC，TD涉及的随机变量较少，因此估计方差更低 。
        

---

### 2. 状态价值的 TD 学习

#### 2.1 算法描述

更新公式为：

$$v_{t+1}(s_t) = v_t(s_t) - \alpha_t(s_t) [v_t(s_t) - (r_{t+1} + \gamma v_t(s_{t+1}))]$$

- **TD 目标 (TD Target)**：$\overline{v}_t = r_{t+1} + \gamma v(s_{t+1})$。算法将当前估计驱动向该目标 。
    
- **TD 误差 (TD Error)**：$\delta_t = v(s_t) - \overline{v}_t$。它反映了当前估计值与真实价值之间的偏差，代表了从新经验中获得的“创新”信息 。
    

#### 2.2 收敛性

在满足步长条件（$\sum \alpha = \infty, \sum \alpha^2 < \infty$）且每个状态被访问足够多次的前提下，TD算法以概率 1 收敛到 $v_\pi(s)$ 。

---

### 3. 动作价值的 TD 学习：Sarsa 及其变体

#### 3.1 Sarsa (On-policy)

Sarsa 是 TD 学习的动作价值版本，旨在求解动作价值形式的贝尔曼方程 。

- **公式**：$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t [q_t(s_t, a_t) - (r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1}))]$ 。
    
- **命名由来**：算法每一步涉及 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ 序列 。
    
- **策略改进**：将 Sarsa 估值与 $\epsilon$-greedy 策略结合，可实现策略搜索并逼近最优策略 。
     

#### 3.2 Expected Sarsa

Expected Sarsa 将 TD 目标中的下个状态动作价值替换为**期望值**：

$$\text{Target} = r_{t+1} + \gamma \sum_a \pi_t(a|s_{t+1}) q_t(s_{t+1}, a)$$

![image.png](https://cdn.jsdelivr.net/gh/lanjinnian/base_picture_bed/img/20260415215245530.png)

- **优点**：通过对动作求期望减少了随机性，方差比 Sarsa 更低 。
    

#### 3.3 n-step Sarsa

n-step Sarsa 统一了 Sarsa（1步）和蒙特卡洛（$\infty$步）方法 。

![image.png](https://cdn.jsdelivr.net/gh/lanjinnian/base_picture_bed/img/20260415221613429.png)

- **特点**：使用 n 步奖励和第 n 个状态的估值作为目标。n 较大时性能接近 MC（高方差低偏差），n 较小时接近 Sarsa（低方差高偏差）。1
    

---

### 4. 最优动作价值学习：Q-learning (Off-policy)

Q-learning 是应用最广的强化学习算法之一，直接求解**贝尔曼最优方程** 。

- **核心公式**：
    
    $$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t [q_t(s_t, a_t) - (r_{t+1} + \gamma \max_{a} q_t(s_{t+1}, a))]$$
    
- **TD 目标**：$r_{t+1} + \gamma \max_{a} q_t(s_{t+1}, a)$。它与 Sarsa 的唯一区别在于此处**取最大值**而非实际执行的动作价值 。
    

---

### 5. 同策（On-policy）与 异策（Off-policy）

这是 TD 学习中非常重要且易混淆的概念 ：

- **行为策略 (Behavior Policy)**：用于与环境交互、产生样本的策略 。
    
- **目标策略 (Target Policy)**：不断更新并期望最终达到最优的策略 。
    
- **判别**：
    
    - **On-policy (如 Sarsa, MC)**：行为策略与目标策略相同 。
        
    - **Off-policy (如 Q-learning)**：两者不同。它允许算法利用任何策略产生的样本来寻找最优策略，且行为策略可以保持探索性 。
        

---

### 6. 统一视角总结

所有上述算法均可表示为统一形式：$q_{t+1} = q_t - \alpha(q_t - \overline{q}_t)$，差异仅在于 **TD 目标 $\overline{q}_t$** 的定义不同 ：

|**算法**|**TD 目标 q​t​ 的表达式**|
|---|---|
|**Sarsa**|$r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$|
|**Expected Sarsa**|$r_{t+1} + \gamma \sum_a \pi_t(a|
|**Q-learning**|$r_{t+1} + \gamma \max_a q_t(s_{t+1}, a)$|
|**n-step Sarsa**|$r_{t+1} + \gamma r_{t+2} + \dots + \gamma^n q_t(s_{t+n}, a_{t+n})$|
|**Monte Carlo**|$r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots$|

这些算法都在以随机逼近的方式求解对应的贝尔曼方程（BE）或贝尔曼最优方程（BOE） 。
