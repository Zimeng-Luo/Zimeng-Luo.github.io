# 强化学习数学原理（二）：从蒙特卡罗到时序差分

当转移概率和奖励均值未知时，仍可以从交互经验中学习价值。关键变化是：不再枚举所有未来，而是用采样结果构造更新目标。本文沿用[第一篇](./强化学习数学原理一.md)的记号，讨论表格方法。

## 蒙特卡罗：用完整回报估计期望

固定策略，从状态或状态—动作对出发采样回合，用回报平均值估计 `vπ` 或 `qπ`。首次访问 MC 只使用一个回合中第一次访问的回报；每次访问 MC 使用所有访问对应的回报。

对于独立同分布且方差有限的样本，样本均值满足：

```text
E[X̄ₙ] = E[X]
Var(X̄ₙ) = Var(X)/n
```

同一回合内的多次访问可能相关，不能不加条件地套用独立样本的方差公式。学习时策略还可能变化，评估固定策略的结论也不能直接等同于控制算法的结论。

无需保存全部历史回报，均值可以增量更新：

```text
Qₙ = Qₙ₋₁ + (Gₙ − Qₙ₋₁)/n
```

MC 的优点是目标直接来自实际回报，不依赖下一状态的价值估计；代价是通常要等回合结束，长轨迹也带来较高方差。

## 采样为什么能够指导更新？

随机逼近用带噪声的观测代替无法直接得到的期望：

```text
wₖ₊₁ = wₖ − αₖ g̃(wₖ)
```

Robbins–Monro 的典型步长条件为 `Σαₖ = ∞`、`Σαₖ² < ∞`：保留持续调整的能力，又逐渐压低噪声影响。收敛还需要均值更新方向稳定、噪声满足适当条件等；两个步长条件并不是对任意算法的通用收敛保证。

若目标是最小化 `J(w) = E[f(w,X)]`，在可以交换微分与期望的条件下，可用样本梯度做 SGD。全批量使用整个数据集，小批量使用一组样本，单样本 SGD 则一次用一个样本。恒定步长更便于跟踪变化，但通常不能期待噪声环境中精确收敛到一点。

## TD：用下一步估值构造目标

TD(0) 不等待完整回合，而在每次转移后更新：

```text
δₜ = Rₜ₊₁ + γV(Sₜ₊₁) − V(Sₜ)
V(Sₜ) ← V(Sₜ) + αₜδₜ
```

这里统一采用“目标减当前估计”的 TD 误差符号。终止状态没有后继回报，对应价值设为 0。

假设当前 `V(Sₜ)=2`，得到奖励 1，下一状态估值为 4，`γ=0.9`，则目标为 4.6、误差为 2.6；步长 0.1 时更新为 2.26。TD 学的是长期回报，不是只把当前奖励写进表里。

| 方法 | 更新目标 | 主要取舍 |
| --- | --- | --- |
| MC | 完整回报 `Gₜ` | 无自举，通常方差较高、更新较晚 |
| TD(0) | `Rₜ₊₁ + γV(Sₜ₊₁)` | 在线、自举，目标受当前估值影响 |
| n-step | 若干步实际奖励加末端估值 | 在传播速度、方差与自举偏差间折中 |

表格 TD 对固定策略的收敛，需要充分访问、合适步长和常规 MDP 条件。把表格换成神经网络后，这一保证不再自动成立。

## 动作价值学习：差别在目标

用统一形式 `Q(s,a) ← Q(s,a) + α[y − Q(s,a)]`，不同算法主要区别如下：

| 算法 | 目标 `y` | 学习对象 |
| --- | --- | --- |
| Sarsa | 下一奖励加折扣后的实际下一动作价值 | 当前行为策略 |
| Expected Sarsa | 下一奖励加目标策略下下一动作价值的期望 | 所选目标策略 |
| Q-learning | 下一奖励加下一状态最大的动作价值 | 贪婪目标策略 |

相应公式为：

```text
Sarsa:          y = r + γQ(s′,a′)
Expected Sarsa: y = r + γΣₐ′π(a′ ∣ s′)Q(s′,a′)
Q-learning:     y = r + γmaxₐ′Q(s′,a′)
```

Expected Sarsa 对下一动作求期望，去掉了下一动作采样带来的随机性，但状态转移与奖励仍可能随机。n-step Sarsa 的完整目标为：

```text
Gₜ⁽ⁿ⁾ = Σᵢ₌₁ⁿ γⁱ⁻¹Rₜ₊ᵢ + γⁿQ(Sₜ₊ₙ,Aₜ₊ₙ)
```

若提前终止，奖励求和在终点截断，取消末端自举。

## 探索、同策与异策

行为策略负责生成样本，目标策略是要评估或优化的策略。Sarsa 通常让两者相同；Q-learning 可以用带探索的行为策略采样，同时学习贪婪目标策略。MC 和 Expected Sarsa 也有异策版本，不能只凭算法名称判断。

ε-greedy 以概率 `1 − ε` 选择贪婪动作，以概率 `ε` 在所有可选动作中随机选择。如果有 `m` 个动作且贪婪动作唯一，其概率为 `1 − ε + ε/m`，其余各为 `ε/m`。

探索性起点要求每个状态—动作对都可能成为回合起点，现实中常难满足。ε-greedy 将探索放进策略，但不保证所有状态必然可达。固定 ε 会持续采取非贪婪动作；若希望表格 Sarsa 控制收敛到最优值，典型条件还要求无限探索、极限贪婪及相应步长。表格 Q-learning 也需要充分的状态—动作覆盖。
