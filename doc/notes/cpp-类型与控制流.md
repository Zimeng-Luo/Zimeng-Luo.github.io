# C++ 入门：类型、作用域与控制流

C++ 是静态类型、通常先编译再执行的通用语言，支持过程化、面向对象和泛型编程。入门先关注两件事：数据具有什么类型，程序在什么条件下操作它。

## 从最小程序开始

```cpp
#include <iostream>

int main() {
    int count{3};
    for (int i = 0; i < count; ++i) {
        std::cout << i << '\n';
    }
}
```

`main` 是入口；声明和普通语句通常以分号结束；大括号组织代码块与作用域。类或结构体定义末尾也需要分号，函数定义的右大括号后则不需要。现代代码使用 `<iostream>` 和 `int main()`。

```bash
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
./hello
```

Windows 下可以将输出指定为 `hello.exe`，在 PowerShell 中用 `.\hello.exe` 运行。注释使用 `//` 或 `/* … */`，块注释不可嵌套。注释优先说明意图、边界和原因。

## 类型与初始化决定数据含义

| 用途 | 常见选择 | 需要注意 |
| --- | --- | --- |
| 条件状态 | `bool` | 使用 `true` / `false` |
| 普通整数 | `int` | 大小与范围依平台而定 |
| 固定宽度整数 | `<cstdint>` 中的整数类型 | 明确位宽要求 |
| 浮点计算 | `double` | 存在舍入误差 |
| 文本 | `std::string` | 不用手动管理结束字符 |
| 容器大小 | `std::size_t` | 与有符号整数混用需谨慎 |

```cpp
int safe{};             // 初始化为 0
int count{10};
double ratio{0.5};
const int limit = count;
constexpr int capacity = 16;
auto value = 3.14;       // 推导为 double
// int narrowed{3.14};  // 错误：列表初始化禁止此类窄化转换
```

`const` 限制通过该对象修改值，但不总表示编译期常量；`constexpr` 适合需要常量表达式的场景。字面量后缀如 `10U`、`10LL`、`3.14F` 会影响类型。`auto` 是类型推导，不是运行时动态类型。

局部自动变量未初始化时，读取可能产生未定义行为；静态存储期对象会先进行零初始化，但仍建议显式初始化。`sizeof` 可以查询对象或类型大小，不能把某个平台的结果当成语言统一规定。

## 名字的作用域和对象的存储期

作用域描述名字在哪里可见，存储期描述存储存在多久，链接属性描述不同文件中的名字能否指向同一实体。

| 写法 | 作用 |
| --- | --- |
| 块内普通变量 | 通常具有自动存储期 |
| 函数内 `static` | 多次调用间保留状态 |
| 命名空间作用域 `static` | 内部链接，限制在当前翻译单元 |
| `extern int count;` | 声明在别处定义的对象 |
| `thread_local` | 每个线程独立一份对象 |
| 类成员 `mutable` | 可在 `const` 成员函数中修改该成员 |

```cpp
int next_id() {
    static int value = 0;
    return ++value;
}
```

函数返回后，局部名字不可见，但这个静态对象仍存在。内层同名变量会遮蔽外层名字，最好减少这种写法。`volatile` 不提供线程同步，需要并发协调时使用原子类型或锁。

## 运算先看结果类型，再看优先级

```cpp
int q = 10 / 3;                    // 3
int r = 10 % 3;                    // 1
double fraction = 10.0 / 3;        // 浮点除法
bool allowed = q > 0 && r != 0;
```

整数除法向零截断；逻辑运算 `&&` 和 `||` 会短路。位运算操作二进制位，不能与逻辑运算混淆。`=` 是赋值，`==` 是比较；复杂表达式主动加括号，避免在同一表达式中反复修改同一变量。

左值通常标识一个对象，右值包括许多临时计算结果。`const` 对象也可以是左值，因此“是左值”不意味着一定能够赋值。

## 控制流按任务选写法

| 任务 | 写法 |
| --- | --- |
| 选择条件分支 | `if / else if / else` |
| 对离散常量分类 | `switch` |
| 已知遍历范围 | `for` 或范围 `for` |
| 条件成立时重复 | `while` |
| 至少执行一次 | `do … while` |

`break` 退出当前循环或 `switch`；`continue` 进入下一轮。`switch` 分支未写 `break` 可能继续执行后面的分支。循环尤其要检查结束边界与计数器变化。
