# C++ 入门：类型、作用域与控制流

## C++ 简介

### 1. C++ 基本定位

  - 静态类型语言：类型检查主要发生在编译阶段
  - 编译型语言：代码需要先编译再运行
  - 通用编程语言：可用于系统、应用、游戏、图形、科学计算等场景
  - 大小写敏感语言
  - 支持多种编程范式：
      - 过程化编程
      - 面向对象编程
      - 泛型编程
	  
### 2. 面向对象四大特性

  C++ 完整支持面向对象程序设计，核心包括：
  - 封装：把数据和操作数据的方法组织在类中，对外隐藏内部实现，只暴露必要接口
  - 继承：新类可以复用已有类的属性和方法，并在此基础上扩展
  - 多态：同一个接口在不同对象上可以表现出不同行为
  - 抽象：提取共同特征，忽略具体实现细节，形成更高层次的设计


### 3. C++ 标准库组成

  标准 C++ 主要由三部分组成：
  - 核心语言：变量、数据类型、常量、运算符、控制结构、函数、类等基础语法
  - C++ 标准库：提供字符串、文件、输入输出等常用功能
  - STL 标准模板库：提供常用数据结构和算法，例如 vector、map、set、sort 等

### 4. 学习 C++ 的重点

  学习 C++ 的关键不是死抠所有语法细节，而是理解核心概念，并能用它们写出结构清晰、可维护、效率较高的程序。

  应重点理解：
  - 类型系统
  - 函数
  - 类与对象
  - 封装、继承、多态
  - 模板
  - 标准库
  - 内存管理
  - 程序设计思想

### 5. C++ 的主要应用场景

  C++ 适合对性能、资源控制、底层能力要求较高的领域，包括：
  - 游戏开发
  - 嵌入式系统
  - 金融系统
  - 图形图像处理
  - 计算机视觉
  - 人工智能相关底层开发
  - 科学计算
  - 高性能计算
  对于 AI 方向，C++ 常用于模型推理部署、图像处理、推理框架底层、CUDA/TensorRT 相关开发等。

## C++ 基础语法

### 1. 最小 C++ 程序结构

一个最小的 C++ 程序通常由头文件引入、主函数和语句组成。

```cpp
#include <iostream>

int main() {
    std::cout << "Hello World" << std::endl;
    return 0;
}
```

关键组成：

- `#include <iostream>`：引入标准输入输出流头文件，提供 `std::cout`、`std::cin` 等对象。
- `int main()`：程序入口函数，程序从这里开始执行。
- `{ ... }`：函数体或语句块，表示一组逻辑上相关的语句。
- `std::cout << ...`：向标准输出打印内容。
- `return 0;`：结束 `main` 函数，并向操作系统返回状态码 `0`，通常表示程序正常结束。

### 2. 编译与运行

将源码保存为 `hello.cpp` 后，可以使用 `g++` 编译。

Linux / macOS / MSYS2：

```bash
g++ hello.cpp -o hello
./hello
```

Windows PowerShell：

```powershell
g++ hello.cpp -o hello.exe
.\hello.exe
```

命令含义：

- `g++ hello.cpp`：调用 GNU C++ 编译器编译源文件。
- `-o hello`：指定输出可执行文件名称；如果省略，类 Unix 系统通常生成 `a.out`。
- `./hello` 或 `.\hello.exe`：运行当前目录下的可执行文件。

### 3. 语句、分号与语句块

C++ 中的语句通常以分号 `;` 结束。

```cpp
int x = 1;
x = x + 1;
std::cout << x << std::endl;
```

语句块使用大括号 `{}` 包裹，用于组织多条逻辑相关的语句。

```cpp
if (x > 0) {
    std::cout << "positive" << std::endl;
}
```

判断是否需要分号，可以先看这一段代码的性质：

| 代码性质 | 常见形式 | 是否通常需要 `;` |
| --- | --- | --- |
| 声明或定义一个“东西” | 变量、类、`struct`、`enum`、函数声明、`typedef`、`using` | 需要 |
| 定义函数体 | 普通函数、成员函数、`main` | 不需要 |
| 控制流程块 | `if`、`for`、`while`、`switch` | 不需要 |

```cpp
int x;                         // 变量声明，需要 ;
struct Point { int x; int y; }; // 类型定义，需要 ;
using Count = int;             // 类型别名，需要 ;
void print(int x);             // 函数声明，需要 ;

void print(int x) {            // 函数定义，不在 } 后写 ;
    std::cout << x << std::endl;
}

if (x > 0) {                   // 控制流程块，不在 } 后写 ;
    print(x);
}
```

注意点：

- C++ 不依赖换行判断语句结束，而依赖分号。
- 一行可以写多条语句，但可读性差，不推荐。
- 控制语句、函数、类都会大量使用 `{}` 表示作用域，但不是所有 `}` 后都需要分号。
- `class`、`struct`、`enum` 定义结尾通常需要 `;`，因为它们是在声明一个类型。

### 4. 标识符命名规则

标识符用于命名变量、函数、类、命名空间等用户自定义对象。

基本规则：

- 可以由字母、数字和下划线 `_` 组成。
- 不能以数字开头。
- 不能使用 C++ 关键字。
- C++ 区分大小写，`value` 和 `Value` 是两个不同标识符。
- 以下划线加大写字母开头的名称可能被实现或标准库保留。

有效示例：

```cpp
int age = 18;
double score_value = 95.5;
int studentCount = 30;
```

不推荐或非法示例：

```cpp
int 2value = 10;      // 非法：不能以数字开头
int class = 1;        // 非法：class 是关键字
int _SystemValue = 0; // 风险：可能与实现保留命名冲突
```

### 5. 常见关键字

关键字是 C++ 语言保留的词，不能作为变量名、函数名或类名。

常见分类：

| 类别 | 示例 |
| --- | --- |
| 类型相关 | `int`、`double`、`char`、`bool`、`void`、`auto` |
| 控制流程 | `if`、`else`、`switch`、`case`、`for`、`while`、`do`、`break`、`continue`、`return` |
| 面向对象 | `class`、`struct`、`public`、`private`、`protected`、`virtual`、`this` |
| 内存管理 | `new`、`delete` |
| 异常处理 | `try`、`catch`、`throw` |
| 命名与模板 | `namespace`、`using`、`template`、`typename` |
| 类型转换 | `static_cast`、`dynamic_cast`、`const_cast`、`reinterpret_cast` |

### 6. 空白符与代码格式

C++ 会忽略多余的空格、制表符和空白行，但空白符会影响词法解析和代码可读性。

必须有空格的情况：

```cpp
int age;
```

这里 `int` 和 `age` 之间必须分隔，否则编译器无法识别类型和变量名。

可选但推荐的空格：

```cpp
int sum = a + b;
```

虽然 `sum=a+b;` 也能编译，但适当空格更容易阅读。

格式建议：

- 运算符两侧保留空格，例如 `a + b`、`x == y`。
- 每个缩进层级使用统一的 4 个空格或项目约定。
- 函数、类、控制语句的大括号风格保持一致。
- 一行只写一条主要语句。

### 7. 三字符组

早期 C/C++ 标准支持三字符组，用三个字符表示某些特殊符号，例如用 `??=` 表示 `#`。这是为了解决早期键盘字符集不完整的问题。

现代开发中基本不会主动使用三字符组。

### 8. 常见入口写法

#### 8.1 `iostream.h` 与 `<iostream>`

现代 C++ 应使用：

```cpp
#include <iostream>
```

旧教材或旧编译器中可能出现：

```cpp
#include <iostream.h>
```

这是早期非标准写法。

#### 8.2 `void main()` 与 `int main()`

标准 C++ 中应使用：

```cpp
int main() {
    return 0;
}
```

`void main()` 在某些旧编译器中可能能运行，但不是标准 C++ 的规范入口形式。

#### 8.3 全局 `using namespace std;`

入门代码中常写：

```cpp
using namespace std;
```

它可以省略 `std::` 前缀，但会把标准库中的大量名称引入当前作用域。

```cpp
std::cout << "Hello" << std::endl;
```

## C++ 注释

### 1. 注释的作用

注释是写给人看的说明文字，不参与程序运行。

常见用途：

- 解释代码为什么这样写，而不是简单重复代码做了什么。
- 标记关键逻辑、边界条件、临时处理和待完善位置。
- 在调试时临时屏蔽少量代码。
- 帮助他人或未来的自己快速理解代码结构。

### 2. 单行注释

单行注释以 `//` 开始，直到当前行末结束。

```cpp
#include <iostream>

int main() {
    // 输出问候语
    std::cout << "Hello World!" << std::endl;
    return 0;
}
```

也可以写在语句后面，用于补充说明当前语句。

```cpp
int count = 10; // 记录元素数量
```

注意点：

- `//` 后面的内容会被编译器忽略。
- 单行注释适合解释短逻辑或临时标记。
- 不建议在每一行都添加重复性注释，否则会降低可读性。

### 3. 块注释

块注释以 `/*` 开始，以 `*/` 结束，可以跨越多行。

```cpp
/*
    计算矩形面积：
    width 表示宽度
    height 表示高度
*/
int area = width * height;
```

块注释也可以写成一行。

```cpp
int result = 0; /* 初始化结果 */
```

注意点：

- 块注释适合说明一段代码的整体逻辑。
- 块注释不能直接嵌套使用。
- 如果块注释中误写了 `*/`，注释会提前结束，可能导致编译错误。

错误示例：

```cpp
/*
    外层注释开始
    /*
        内层注释
    */
    外层注释结束
*/
```

### 4. 两种注释的解析关系

在块注释内部，`//` 只是普通字符，不会开启单行注释。

```cpp
/*
    // 这里仍然属于块注释内容
*/
```

在单行注释内部，`/*` 和 `*/` 也只是普通字符，不会开启或结束块注释。

```cpp
// /* 这里不会开启块注释 */
```

### 5. 使用条件编译屏蔽代码

当需要临时屏蔽一大段代码，尤其是代码内部已经包含块注释时，可以使用 `#if 0 ... #endif`。

```cpp
#if 0
std::cout << "debug message" << std::endl;
/*
    这里可以包含块注释
*/
#endif
```

含义：

- `#if 0`：条件为假，预处理阶段会跳过其中的代码。
- `#endif`：结束条件编译区域。
- 将 `0` 改为 `1` 后，这段代码会重新参与编译。

这种方式属于预处理条件编译，不是普通注释。

### 6. 注释编写原则

优先写有信息量的注释。

```cpp
// 不推荐：给 i 加 1
i++;

// 推荐：跳过当前已经处理过的元素
i++;
```

实践建议：

- 注释应解释意图、约束、原因和风险。
- 代码本身能清楚表达的内容，不必重复注释。
- 修改代码时同步更新注释，避免注释与实现不一致。
- 对复杂算法、特殊边界和非显然的性能优化，应保留简洁说明。

## C++ 变量类型

### 1. 变量与类型

变量可以理解为程序中一块可操作存储区域的名字。

```cpp
int age = 18;
double score = 95.5;
char grade = 'A';
bool passed = true;
```

在 C++ 中，每个变量都必须有确定的类型。

类型的作用：

- 决定变量在内存中的布局和大小。
- 决定变量可表示的取值范围。
- 决定变量能参与哪些运算。
- 帮助编译器在编译阶段发现类型错误。

### 2. 常见基础类型

| 类型 | 含义 | 常见用途 |
| --- | --- | --- |
| `bool` | 布尔类型，取值为 `true` 或 `false` | 条件判断、状态标记 |
| `char` | 字符类型，通常占 1 字节 | ASCII 字符、小整数 |
| `wchar_t` | 宽字符类型 | 宽字符文本 |
| `char16_t` | 16 位字符类型 | UTF-16 编码单元 |
| `char32_t` | 32 位字符类型 | UTF-32 编码单元 |
| `short` | 短整型 | 较小整数 |
| `int` | 整型 | 普通整数 |
| `long` | 长整型 | 较大整数 |
| `long long` | 长长整型 | 更大整数 |
| `float` | 单精度浮点数 | 一般浮点计算 |
| `double` | 双精度浮点数 | 常用浮点计算 |
| `long double` | 扩展精度浮点数 | 更高精度需求 |
| `void` | 无类型或类型缺失 | 函数无返回值、通用指针相关语义 |

注意：

- C++ 标准通常规定类型的最小能力，不固定所有平台上的具体字节数。
- `int` 常见为 4 字节，但不能把所有平台都默认成这个大小。
- 如果需要确认大小，使用 `sizeof`。
- 如果需要固定宽度整数，优先查看 `<cstdint>` 中的 `std::int32_t`、`std::uint64_t` 等类型。

```cpp
#include <iostream>

int main() {
    std::cout << sizeof(int) << std::endl;
    std::cout << sizeof(double) << std::endl;
    return 0;
}
```

### 3. 变量定义

变量定义会告诉编译器创建变量，并为变量分配存储空间。

基本形式：

```cpp
type variable_name;
type variable_name = value;
```

示例：

```cpp
int count;
int age = 18;
double price = 12.5;
char level = 'A';
bool enabled = true;
```

同一类型可以一次定义多个变量。

```cpp
int i, j, k;
double width, height;
```

为了可读性，实际项目中更推荐一行只定义一个变量，尤其是初始化方式不同或类型较复杂时。

```cpp
int i = 0;
int j = 1;
int k = 2;
```

### 4. 变量初始化

定义变量时可以同时给出初始值。

```cpp
int a = 10;      // 拷贝初始化
int b(20);       // 直接初始化
int c{30};       // 列表初始化
double d{3.14};
```

现代 C++ 中常推荐使用列表初始化 `{}`，因为它能帮助发现部分窄化转换问题。

```cpp
int x = 3.14;  // 可能丢失小数部分
// int y{3.14}; // 错误：列表初始化禁止这种窄化转换
```

未初始化变量需要特别小心：

- 局部自动变量如果没有初始化，值是不确定的。
- 全局变量、静态变量等具有静态存储期的对象会被零初始化。

```cpp
int global_count; // 静态存储期，默认初始化为 0

int main() {
    int local_count; // 未初始化，值不确定
    int safe_count = 0;
    return 0;
}
```

### 5. 变量声明与定义

声明告诉编译器某个变量或函数存在；定义则会实际创建对象或给出函数实现。

对于变量：

```cpp
extern int shared_count; // 声明：变量在其他地方定义
int shared_count = 0;    // 定义：创建变量并初始化
```

在多文件程序中，常见做法是：

- 在头文件中使用 `extern` 声明全局变量。
- 在一个 `.cpp` 文件中定义这个变量。

示例：

```cpp
// config.h
extern int max_retry;
```

```cpp
// config.cpp
int max_retry = 3;
```

```cpp
// main.cpp
#include "config.h"

int main() {
    return max_retry;
}
```

注意：带初始化器的 `extern` 变量定义通常会变成定义，不再只是声明。

```cpp
extern int value;     // 声明
extern int value = 1; // 定义
```

### 6. 复合类型概览

除了基础类型，C++ 还可以定义更复杂的变量类型。

| 类型 | 示例 | 含义 |
| --- | --- | --- |
| 指针 | `int* p` | 保存某个对象的地址 |
| 引用 | `int& r = x` | 为已有对象起别名 |
| 数组 | `int nums[3]` | 固定数量、同类型元素集合 |
| 枚举 | `enum Color { Red, Green }` | 一组命名整数常量 |
| 结构体 | `struct Point { int x; int y; };` | 多个成员组成的自定义类型 |
| 类 | `class Student { ... };` | 带数据和行为的自定义类型 |
| 共用体 | `union Value { int i; double d; };` | 多个成员共用同一段存储 |

这些类型会在指针、引用、数组、结构体、类与对象等主题中继续展开。

### 7. 左值与右值

C++ 表达式可以粗略分为左值和右值。

左值通常表示有明确存储位置、可以被取地址的对象。

```cpp
int x = 10;
x = 20; // x 是左值，可以出现在赋值号左边
```

右值通常表示临时值或字面量，不能作为赋值目标。

```cpp
int y = 10 + 20; // 10 + 20 是右值
// 10 = y;       // 错误：字面量不能作为赋值目标
```

常见判断：

- 变量名通常是左值。
- 数字字面量、表达式计算结果通常是右值。
- 左值可以出现在赋值号左边或右边。
- 右值通常只能出现在赋值号右边。

### 8. 类型选择建议

实践中不要只看“能不能存下”，还要考虑语义和可维护性。

- 普通整数优先使用 `int`。
- 计数、大小、下标常见使用 `std::size_t`。
- 需要固定宽度时使用 `<cstdint>` 中的整数类型。
- 浮点计算一般优先使用 `double`。
- 条件状态使用 `bool`，不要用 `0` 和 `1` 伪装布尔含义。
- 字符串文本优先使用 `std::string`，而不是手写字符数组。

## C++ 变量作用域

### 1. 作用域的基本概念

作用域是一个名字可被访问的程序区域。

变量可以定义在不同位置：

- 函数或代码块内部：局部变量。
- 函数参数列表中：形式参数。
- 所有函数外部：全局变量。
- 类内部：成员变量或静态成员变量。

作用域影响两个问题：

- 可见性：变量名能在哪些位置被访问。
- 生命周期：变量对应的对象在什么时候创建和销毁。

注意：作用域和生命周期相关，但不是同一个概念。作用域描述“名字在哪里可见”，生命周期描述“对象什么时候存在”。

### 2. 局部作用域

在函数内部定义的变量具有局部作用域，只能在该函数内部访问。

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 20;
    int c = a + b;

    std::cout << c << std::endl;
    return 0;
}
```

特点：

- 每次进入函数时创建。
- 函数执行结束后销毁。
- 函数外部不能直接访问。
- 未初始化的局部自动变量值不确定，使用前必须初始化。

```cpp
int main() {
    int count;     // 值不确定
    int safe = 0;  // 推荐：显式初始化
    return 0;
}
```

### 3. 函数参数作用域

函数参数也是局部名字，它们只在函数体内可见。

```cpp
int add(int a, int b) {
    return a + b;
}
```

这里 `a` 和 `b` 是形式参数：

- 调用函数时由实参传入值。
- 在函数内部像局部变量一样使用。
- 函数结束后参数对象随函数调用结束而销毁。

```cpp
int result = add(10, 20);
```

### 4. 块作用域

大括号 `{}` 内部定义的变量具有块作用域，只能在当前代码块内部访问。

```cpp
#include <iostream>

int main() {
    int a = 10;

    {
        int b = 20;
        std::cout << b << std::endl;
    }

    // std::cout << b << std::endl; // 错误：b 已经离开作用域
    return 0;
}
```

块作用域常见于：

- `if`、`else` 语句块。
- `for`、`while` 循环块。
- 人为创建的临时代码块。

```cpp
for (int i = 0; i < 3; ++i) {
    std::cout << i << std::endl;
}

// i 在循环外不可见
```

### 5. 全局作用域

在所有函数和类外部定义的变量具有全局作用域。

```cpp
#include <iostream>

int g = 0; // 全局变量

int main() {
    g = 30;
    std::cout << g << std::endl;
    return 0;
}
```

特点：

- 程序开始时创建，程序结束时销毁。
- 可以被同一翻译单元中后续代码访问。
- 如果需要跨文件访问，通常配合 `extern` 声明。
- 具有静态存储期，会被默认零初始化。

全局变量会扩大状态影响范围，实际项目中应谨慎使用。更常见的替代方式是把状态封装到对象、函数参数或配置结构中。

### 6. 类作用域

类内部声明的成员名字具有类作用域，需要通过对象、指针或类名访问。

```cpp
#include <iostream>

class Counter {
public:
    int value = 0;

    void increase() {
        value++;
    }
};

int main() {
    Counter counter;
    counter.increase();
    std::cout << counter.value << std::endl;
    return 0;
}
```

静态成员变量属于类本身，通常使用类名和作用域解析运算符 `::` 访问。

```cpp
#include <iostream>

class MyClass {
public:
    static int class_value;
};

int MyClass::class_value = 30;

int main() {
    std::cout << MyClass::class_value << std::endl;
    return 0;
}
```

### 7. 同名变量与遮蔽

内层作用域可以定义与外层作用域同名的变量。此时内层变量会遮蔽外层变量。

```cpp
#include <iostream>

int g = 20;

int main() {
    int g = 10;
    std::cout << g << std::endl; // 输出 10
    return 0;
}
```

块作用域中的同名变量也是一样。

```cpp
#include <iostream>

int main() {
    int a = 10;

    {
        int a = 20;
        std::cout << "inner: " << a << std::endl;
    }

    std::cout << "outer: " << a << std::endl;
    return 0;
}
```

输出：

```text
inner: 20
outer: 10
```

如果确实要在局部作用域中访问被遮蔽的全局变量，可以使用作用域解析运算符 `::`。

```cpp
#include <iostream>

int value = 100;

int main() {
    int value = 10;

    std::cout << value << std::endl;   // 局部变量：10
    std::cout << ::value << std::endl; // 全局变量：100
    return 0;
}
```

### 8. 不同作用域变量的初始化

局部自动变量不会自动初始化。

```cpp
int main() {
    int local_value; // 值不确定
    return 0;
}
```

全局变量和静态变量具有静态存储期，会被零初始化。

```cpp
int global_int;       // 0
double global_double; // 0.0
char global_char;     // '\0'
int* global_ptr;      // nullptr
```

实践中仍然建议显式初始化变量，避免依赖隐式规则。

```cpp
int global_count = 0;

int main() {
    int local_count = 0;
    return 0;
}
```

### 9. 作用域使用建议

- 优先使用尽可能小的作用域，降低变量误用风险。
- 变量尽量在首次使用前再定义，并立即初始化。
- 避免局部变量与全局变量、成员变量随意重名。
- 控制全局变量数量，避免程序状态分散且难以追踪。
- 循环计数器优先定义在 `for` 语句内部。
- 类成员与局部变量同名时，可用 `this->member` 明确指向成员变量。

## C++ 常量

### 1. 字面量

字面量是代码中直接出现的固定值。

```cpp
42          // 整数字面量
3.14        // 浮点字面量
'A'         // 字符字面量
"hello"     // 字符串字面量
true        // 布尔字面量
```

字面量本身不能被赋值。

```cpp
// 42 = 10; // 错误
```

### 2. 整数字面量

整数字面量可以使用不同进制。

| 写法 | 含义 |
| --- | --- |
| `85` | 十进制 |
| `0213` | 八进制，以 `0` 开头 |
| `0x4b` / `0X4B` | 十六进制，以 `0x` 或 `0X` 开头 |

常见后缀：

| 后缀 | 含义 |
| --- | --- |
| `u` / `U` | 无符号整数 |
| `l` / `L` | `long` |
| `ll` / `LL` | `long long` |

```cpp
int a = 85;
unsigned int b = 85U;
long c = 85L;
long long d = 85LL;
```

### 3. 浮点字面量

浮点字面量可以使用小数形式或科学计数法。

```cpp
double a = 3.14159;
double b = 314159E-5; // 3.14159
float c = 3.14F;
long double d = 3.14L;
```

常见后缀：

| 后缀 | 含义 |
| --- | --- |
| `f` / `F` | `float` |
| `l` / `L` | `long double` |

没有后缀的浮点字面量默认通常是 `double`。

### 4. 字符和字符串字面量

字符字面量使用单引号，字符串字面量使用双引号。

```cpp
char ch = 'A';
const char* text = "hello";
```

常见转义序列：

| 转义序列 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 水平制表符 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\0` | 空字符 |

```cpp
std::cout << "hello\nworld" << std::endl;
```

多个相邻字符串字面量会在编译时自动拼接。

```cpp
const char* s = "hello "
                "world";
```

### 5. 布尔字面量

布尔字面量只有两个：

```cpp
bool ok = true;
bool failed = false;
```

它们常用于条件判断、状态标记和函数返回值。

### 6. `const` 常量

`const` 修饰的变量初始化后不能再修改。

```cpp
const int max_count = 100;
// max_count = 200; // 错误
```

常量一般在定义时初始化。

```cpp
const double pi = 3.14159;
const char newline = '\n';
```

优势：

- 有明确类型，编译器可以做类型检查。
- 遵守作用域规则。
- 调试时更容易定位。

### 7. 常量中的类型修饰符

类型修饰符用于改变基础类型的表示范围或含义，常和常量声明一起使用。

| 修饰符 | 常见含义 | 示例 |
| --- | --- | --- |
| `signed` | 有符号整数，可表示负数；整型默认通常可省略 | `signed int a = -10;` |
| `unsigned` | 无符号整数，只表示非负数 | `unsigned int b = 20U;` |
| `short` | 较短整数，`short int` 可简写为 `short` | `short s = 10;` |
| `long` | 较长整数或扩展浮点，`long int` 可简写为 `long` | `long n = 100000L;` |
| `long long` | 比 `long` 范围更大的整数 | `long long big = 10000000000LL;` |

这些修饰符可以组合使用。

```cpp
const unsigned long max_size = 1000UL;
const long double precise_pi = 3.1415926L;
```

注意：

- `unsigned` 与有符号整数混用时容易产生意外转换。
- `short`、`long` 的具体大小与平台有关，固定宽度整数可使用 `<cstdint>`。
- 字面量后缀应尽量和目标类型一致，例如 `100U`、`100L`、`100LL`。

### 8. 类型限定符

类型限定符会给变量增加额外约束。

| 限定符 | 含义 |
| --- | --- |
| `const` | 对象初始化后不能通过该名字修改 |
| `volatile` | 对象值可能被程序外部因素改变，编译器不应随意优化访问 |
| `mutable` | 类成员即使在 `const` 对象或 `const` 成员函数中也可被修改 |

```cpp
const int count = 10;
volatile int device_status = 0;
```

`volatile` 不等于线程同步；多线程共享数据通常应使用互斥锁或 `std::atomic`。

### 9. 宏常量

宏常量使用 `#define` 定义，在预处理阶段做文本替换。

```cpp
#define LENGTH 10
#define WIDTH 5

int area = LENGTH * WIDTH;
```

宏常量没有类型，也不受普通作用域规则约束，容易引入隐蔽问题。现代 C++ 中，普通常量优先使用 `const` 或 `constexpr`。

```cpp
constexpr int length = 10;
constexpr int width = 5;
int area = length * width;
```

### 10. `const` 与 `#define` 对比

| 方式 | 特点 | 推荐程度 |
| --- | --- | --- |
| `const` | 有类型、有作用域、可调试 | 常用 |
| `constexpr` | 编译期常量表达式，适合数组大小、模板参数等场景 | 优先用于明确编译期常量 |
| `#define` | 预处理文本替换，无类型检查 | 少用，主要用于条件编译 |

实践中：

- 普通命名常量优先使用 `const`。
- 确定需要编译期求值时使用 `constexpr`。
- 需要条件编译或头文件保护时再使用宏。

## C++ 存储类

### 1. 先区分三个概念

| 概念 | 含义 |
| --- | --- |
| 作用域 | 名字在代码中哪里可见 |
| 存储期 | 对象在内存中存在多久 |
| 链接属性 | 名字能否跨文件被同一个实体引用 |

存储类说明符常同时影响这三者，因此容易和变量作用域混在一起。

### 2. 常见存储类速查

| 关键字            | 主要作用                    | 常见场景                 |
| -------------- | ----------------------- | -------------------- |
| `static`       | 静态存储期；在命名空间作用域可限制为文件内可见 | 局部计数器、文件私有全局变量、类静态成员 |
| `extern`       | 声明外部链接对象或函数             | 多文件共享全局变量或函数声明       |
| `thread_local` | 每个线程拥有独立副本              | 线程上下文、线程局部缓存         |
| `mutable`      | 允许类成员在 `const` 成员函数中被修改 | 缓存、统计计数              |

### 3. `static`

`static` 在不同位置含义不同。

| 位置 | 含义 |
| --- | --- |
| 函数内部局部变量 | 只初始化一次，函数多次调用之间保留值 |
| 命名空间/全局作用域 | 限制为当前文件内部链接 |
| 类内部成员 | 属于类本身，所有对象共享一份 |

局部静态变量：

```cpp
#include <iostream>

void count() {
    static int n = 0;
    ++n;
    std::cout << n << std::endl;
}

int main() {
    count(); // 1
    count(); // 2
    return 0;
}
```

文件私有变量：

```cpp
static int file_count = 0; // 只在当前 .cpp 文件可见
```

### 4. `extern`

`extern` 用于声明变量或函数在别处定义，常用于多文件共享。

```cpp
// config.h
extern int max_retry;
```

```cpp
// config.cpp
int max_retry = 3;
```

```cpp
// main.cpp
#include "config.h"

int main() {
    return max_retry;
}
```

注意：

- `extern int x;` 是声明，不分配存储。
- `int x = 1;` 是定义，分配存储。
- `extern int x = 1;` 带初始化，通常也是定义。

### 5. `thread_local`

`thread_local` 表示每个线程都有自己的独立变量副本。

```cpp
#include <iostream>
#include <thread>

thread_local int local_id = 0;

void work(int id) {
    local_id = id;
    std::cout << local_id << std::endl;
}

int main() {
    std::thread t1(work, 1);
    std::thread t2(work, 2);
    t1.join();
    t2.join();
    return 0;
}
```

特点：

- 不同线程读写互不影响。
- 生命周期通常从线程开始使用到线程结束。
- 适合保存线程上下文，不等于自动解决所有并发问题。

### 6. `mutable`

`mutable` 只能修饰类的非静态数据成员，允许它在 `const` 成员函数中被修改。

```cpp
class Counter {
public:
    int get() const {
        ++read_count;
        return value;
    }

private:
    int value = 0;
    mutable int read_count = 0;
};
```

常见用途：

- 缓存计算结果。
- 记录访问次数。
- 维护不影响对象外部语义的内部状态。

### 7. `auto`

现代 C++ 中，`auto` 用于根据初始化表达式推导类型。

```cpp
auto x = 3.14;      // double
auto text = "hello"; // const char*
```

同一条 `auto` 声明中的多个变量必须推导出同一类型。

```cpp
auto a = 1, b = 2;   // 正确
// auto c = 1, d = 2.0; // 错误：推导类型不一致
```

### 8. 常见判断

| 写法 | 判断 |
| --- | --- |
| 函数内普通局部变量 | 自动存储期，离开作用域销毁 |
| 函数内 `static` 变量 | 静态存储期，保留到程序结束 |
| 全局变量 | 静态存储期，默认外部链接 |
| 全局 `static` 变量 | 静态存储期，内部链接，仅当前文件可见 |
| `extern` 声明 | 声明外部实体，不一定定义对象 |
| `thread_local` 变量 | 每个线程一份独立对象 |

补充：局部 `const` 变量默认仍是自动存储期，不会因为 `const` 自动变成 `static`。

## C++ 运算符

### 1. 算术运算符

| 运算符  | 含义       | 示例          |
| ---- | -------- | ----------- |
| `+`  | 加法       | `a + b`     |
| `-`  | 减法       | `a - b`     |
| `*`  | 乘法       | `a * b`     |
| `/`  | 除法       | `a / b`     |
| `%`  | 取模，求整数余数 | `a % b`     |
| `++` | 自增       | `++a`、`a++` |
| `--` | 自减       | `--a`、`a--` |

```cpp
int a = 10;
int b = 3;

int sum = a + b; // 13
int div = a / b; // 3，整数除法会丢弃小数部分
int mod = a % b; // 1
```

注意：

- `%` 只能用于整数类型。
- 整数相除得到整数；需要小数结果时至少有一个操作数应为浮点数。
- `++a` 先自增再使用，`a++` 先使用再自增。

### 2. 关系运算符

关系运算符用于比较两个值，结果是 `bool`。

| 运算符 | 含义 |
| --- | --- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

```cpp
int a = 10;
int b = 20;

bool less = a < b;     // true
bool same = a == b;    // false
bool different = a != b; // true
```

注意：判断相等使用 `==`，赋值使用 `=`。

### 3. 逻辑运算符

逻辑运算符用于组合布尔表达式。

| 运算符 | 含义 |
| --- | --- |
| `&&` | 逻辑与，两个条件都为真才为真 |
| <code>&#124;&#124;</code> | 逻辑或，至少一个条件为真就为真 |
| `!` | 逻辑非，取反 |

```cpp
int age = 20;
bool has_ticket = true;

if (age >= 18 && has_ticket) {
    // 可以进入
}
```

短路规则：

- `a && b`：如果 `a` 为假，不再计算 `b`。
- `a || b`：如果 `a` 为真，不再计算 `b`。

### 4. 位运算符

位运算符直接操作整数的二进制位。

| 运算符 | 含义 |
| --- | --- |
| `&` | 按位与 |
| <code>&#124;</code> | 按位或 |
| `^` | 按位异或 |
| `~` | 按位取反 |
| `<<` | 左移 |
| `>>` | 右移 |

```cpp
unsigned int a = 5; // 0101
unsigned int b = 3; // 0011

unsigned int x = a & b; // 0001
unsigned int y = a | b; // 0111
unsigned int z = a ^ b; // 0110
```

常见用途：

- 位掩码。
- 标志位组合。
- 底层协议和硬件寄存器操作。

### 5. 赋值运算符

赋值运算符会修改左侧变量。

| 运算符 | 等价形式 |
| --- | --- |
| `=` | 普通赋值 |
| `+=` | `a = a + b` |
| `-=` | `a = a - b` |
| `*=` | `a = a * b` |
| `/=` | `a = a / b` |
| `%=` | `a = a % b` |
| `<<=` | `a = a << b` |
| `>>=` | `a = a >> b` |
| `&=` | `a = a & b` |
| `^=` | `a = a ^ b` |
| <code>&#124;=</code> | <code>a = a &#124; b</code> |

```cpp
int count = 10;
count += 5; // 15
count *= 2; // 30
```

### 6. 条件运算符

条件运算符 `?:` 是三元运算符。

```cpp
int score = 80;
const char* result = score >= 60 ? "pass" : "fail";
```

形式：

```cpp
condition ? value_if_true : value_if_false;
```

适合简单二选一表达式；逻辑复杂时优先使用 `if`。

### 7. 成员、指针和地址相关运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 通过对象访问成员 | `obj.value` |
| `->` | 通过指针访问成员 | `ptr->value` |
| `&` | 取地址 | `&x` |
| `*` | 解引用指针 | `*p` |
| `sizeof` | 获取类型或对象大小 | `sizeof(int)` |

```cpp
struct Point {
    int x;
    int y;
};

Point p{1, 2};
Point* ptr = &p;

int a = p.x;
int b = ptr->y;
```

注意：`*` 既可以表示乘法，也可以表示指针解引用；`&` 既可以表示按位与，也可以表示取地址，具体含义由上下文决定。

### 8. 逗号运算符

逗号运算符会从左到右依次计算表达式，整个表达式的值是最后一个表达式的值。

```cpp
int a = 1;
int b = (a += 2, a * 3); // a 为 3，b 为 9
```

实际项目中不要滥用逗号运算符，避免降低可读性。

### 9. 运算符优先级要点

| 优先级 | 运算符 | 结合性 |
| --- | --- | --- |
| 1 | `::` | 左到右 |
| 2 | `()` `[]` `->` `.` `++` `--` `typeid` `dynamic_cast` `static_cast` `const_cast` `reinterpret_cast` | 左到右 |
| 3 | 一元运算：`+` `-` `!` `~` `*` `&` `++` `--` `sizeof` `new` `delete` | 右到左 |
| 4 | `.*` `->*` | 左到右 |
| 5 | 乘除模：`*` `/` `%` | 左到右 |
| 6 | 加减：`+` `-` | 左到右 |
| 7 | 移位：`<<` `>>` | 左到右 |
| 8 | 关系：`<` `<=` `>` `>=` | 左到右 |
| 9 | 相等：`==` `!=` | 左到右 |
| 10 | 位与：`&` | 左到右 |
| 11 | 位异或：`^` | 左到右 |
| 12 | 位或：`&#124;` | 左到右 |
| 13 | 逻辑与：`&&` | 左到右 |
| 14 | 逻辑或：`&#124;&#124;` | 左到右 |
| 15 | 条件：`?:` | 右到左 |
| 16 | 赋值：`=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `&#124;=` | 右到左 |
| 17 | 逗号：`,` | 左到右 |

几个常见记法：

```cpp
a + b * c;      // 先乘后加
a << b + c;     // 先算 b + c
x = y = 3;      // 右结合，先 y = 3
a && b || c;    // 先 && 后 ||
```

复杂表达式建议加括号，不依赖读者记忆优先级。

### 10. 常见易错点

- 把 `=` 写成 `==`，或把 `==` 写成 `=`。
- 整数除法误以为会保留小数。
- 在同一个复杂表达式中多次修改同一变量。
- 混淆逻辑运算符 `&&`、`||` 和位运算符 `&`、`|`。
- 忽略 `&&`、`||` 的短路行为。

## C++ 控制流程

### 1. 判断结构

判断结构用于根据条件选择执行路径。

#### 1.1 `if`

```cpp
if (condition) {
    // 条件为真时执行
}
```

#### 1.2 `if...else`

```cpp
if (condition) {
    // 真分支
} else {
    // 假分支
}
```

#### 1.3 `else if`

```cpp
if (score >= 90) {
    grade = 'A';
} else if (score >= 60) {
    grade = 'B';
} else {
    grade = 'C';
}
```

#### 1.4 `switch`

`switch` 适合一个变量对应多个离散值的判断。

```cpp
switch (day) {
    case 1:
        std::cout << "Monday\n";
        break;
    case 2:
        std::cout << "Tuesday\n";
        break;
    default:
        std::cout << "Other day\n";
        break;
}
```

要点：

- `case` 后通常跟常量表达式。
- `break` 用于防止继续落入下一个 `case`。
- `default` 是兜底分支，可选但常用。

#### 1.5 条件运算符

`?:` 常用于简单二选一。

```cpp
int max_value = (a > b) ? a : b;
```

### 2. 循环结构

循环用于重复执行一段代码。

#### 2.1 `while`

先判断，再执行。

```cpp
int i = 0;
while (i < 5) {
    ++i;
}
```

#### 2.2 `for`

适合已知循环次数或明确边界的场景。

```cpp
for (int i = 0; i < 5; ++i) {
    // 循环体
}
```

#### 2.3 `do...while`

先执行一次，再判断条件。

```cpp
int i = 0;
do {
    ++i;
} while (i < 5);
```

#### 2.4 嵌套循环

循环内部还可以套循环，常用于二维遍历。

```cpp
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        // 处理二维数据
    }
}
```

#### 2.5 无限循环

```cpp
for (;;) {
    // 一直执行
}
```

### 3. 循环控制语句

#### 3.1 `break`

立即终止当前循环或 `switch`。

#### 3.2 `continue`

跳过本次循环剩余语句，进入下一轮判断。

#### 3.3 `goto`

可跳转到标签位置，但一般不建议使用。

```cpp
start:
    // ...
    goto start;
```

### 4. 常见记法

```cpp
a > b ? a : b;          // 条件选择
a && b || c;            // 先 && 后 ||
for (int i = 0; i < n; ++i) {}
while (condition) {}
do {} while (condition);
```

### 5. 常见易错点

- `switch` 忘记写 `break`。
- `while` 和 `do...while` 的执行顺序混淆。
- 循环边界写错，导致少一次或多一次。
- 把复杂分支强行写成嵌套三元表达式。
