# 线程

## 核心摘要

线程是进程内部的执行流。同一进程内的线程共享代码段、数据段和打开文件，但各自拥有线程 ID、程序计数器、寄存器和栈。

## 线程概述

引入线程的主要动机是减少进程级并发的开销，提高响应速度和资源利用率。

| 对比 | 进程 | 线程 |
| --- | --- | --- |
| 资源拥有 | 资源分配单位 | 通常不独立拥有资源 |
| 调度 | 可被调度 | 可被调度 |
| 切换成本 | 较高 | 较低 |
| 隔离性 | 强 | 同进程内隔离弱 |

## 多线程优点

| 优点 | 说明 |
| --- | --- |
| 响应快 | 一个线程阻塞时其他线程仍可运行 |
| 资源共享 | 同进程线程天然共享地址空间 |
| 经济性 | 创建和切换成本低于进程 |
| 可扩展 | 多核系统中可并行执行 |

## 多线程模型

用户线程由用户态线程库管理，内核线程由操作系统内核管理。两者映射关系形成多线程模型。

| 模型 | 说明 | 特点 |
| --- | --- | --- |
| 多对一 | 多个用户线程映射到一个内核线程 | 管理简单，但一个阻塞会影响全部 |
| 一对一 | 一个用户线程映射一个内核线程 | 并发能力强，内核开销较大 |
| 多对多 | 多个用户线程映射到多个内核线程 | 灵活，但实现复杂 |

Linux 和 Windows 常见实现接近一对一模型。

## 线程库

线程库提供创建、同步和销毁线程的 API。

| 线程库 | 说明 |
| --- | --- |
| POSIX Pthreads | Unix/Linux 常用线程标准 |
| Windows Threads | Windows 原生线程接口 |
| Java Threads | Java 语言级线程抽象 |

Pthreads 中常见接口包括 `pthread_create()`、`pthread_join()`、`pthread_exit()`。

## 多线程问题

| 问题 | 含义 |
| --- | --- |
| `fork()` 与 `exec()` | 多线程进程调用 `fork()` 时需明确复制哪些线程 |
| 信号处理 | 信号应递送给特定线程还是整个进程 |
| 线程取消 | 需要处理异步取消和延迟取消 |
| 线程局部存储 | 同一进程内为每个线程保存独立数据 |
| 调度激活 | 用户线程库和内核之间协调线程调度 |

多线程共享地址空间，因此并发访问共享数据时必须配合同步机制。
