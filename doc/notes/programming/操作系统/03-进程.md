# 进程

## 核心摘要

进程是执行中的程序，是操作系统进行资源分配和调度的基本对象。理解进程要抓住进程地址空间、PCB、状态转换、调度队列、上下文切换和进程间通信。

## 进程概念

程序是静态文件，进程是程序装入内存后的动态执行实体。

| 内容 | 说明 |
| --- | --- |
| 代码段 | 程序指令 |
| 数据段 | 全局变量、静态数据 |
| 堆 | 运行时动态分配内存 |
| 栈 | 函数参数、返回地址、局部变量 |

## 进程控制块 PCB

PCB 是操作系统描述和管理进程的数据结构。

| 信息 | 作用 |
| --- | --- |
| 进程状态 | new、ready、running、waiting、terminated |
| 程序计数器 | 下一条要执行的指令地址 |
| CPU 寄存器 | 上下文切换时保存执行现场 |
| CPU 调度信息 | 优先级、队列指针等 |
| 内存管理信息 | 页表、段表、地址范围 |
| 记账信息 | CPU 时间、进程号、用户号 |
| I/O 状态 | 打开的文件、分配的设备 |

## 进程状态

```text
new -> ready -> running -> terminated
          ^        |
          |        v
        waiting <- I/O 或事件等待
```

运行态进程可能因时间片用完回到就绪态，因 I/O 或事件等待进入等待态，事件完成后回到就绪态。

## 进程调度

多道程序的目标是让 CPU 尽量保持忙碌。调度器从就绪队列中选择进程运行。

| 调度器 | 作用 |
| --- | --- |
| 长期调度 | 决定哪些作业进入内存成为进程 |
| 短期调度 | 从就绪队列选择下一个运行进程 |
| 中期调度 | 通过换入换出调整多道程序程度 |

上下文切换是保存当前进程状态并恢复另一进程状态的过程，本身不产生有效业务计算，因此切换成本应尽量降低。

## 进程操作

| 操作 | 说明 |
| --- | --- |
| 创建 | 父进程创建子进程，形成进程树 |
| 执行替换 | 子进程可装入新程序映像 |
| 等待 | 父进程等待子进程结束 |
| 终止 | 释放进程占用资源 |

Unix/Linux 中常见模型是 `fork()` 创建子进程，`exec()` 装入新程序，`wait()` 等待子进程结束。

## 进程间通信 IPC

进程间通信用于交换数据和协作执行。

| 方式 | 特点 |
| --- | --- |
| 共享内存 | 速度快，但需要同步机制保证一致性 |
| 消息传递 | 通过内核发送/接收消息，隔离性较好 |
| 管道 | 适合有亲缘关系进程的字节流通信 |
| Socket | 适合跨主机或网络通信 |

通信时需要关注命名方式、同步方式、缓冲策略和消息大小限制。
