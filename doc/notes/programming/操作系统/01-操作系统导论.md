# 操作系统导论

## 核心摘要

操作系统是位于硬件与应用程序之间的系统软件，核心作用是管理软硬件资源、提供程序运行环境，并向用户和应用提供统一服务接口。

## 操作系统的定义

| 角度 | 含义 |
| --- | --- |
| 资源管理者 | 管理 CPU、内存、I/O 设备、文件等硬件和软件资源 |
| 控制程序 | 控制程序执行，防止错误和资源滥用 |
| 服务平台 | 为用户交互、应用运行、系统调用提供环境 |

常见操作系统包括 Windows、Linux、Unix、macOS、Android、iOS、openEuler 等。

## 计算机系统结构

计算机系统通常由硬件、操作系统、系统程序、应用程序和用户组成。

| 层次 | 内容 |
| --- | --- |
| 硬件 | CPU、内存、I/O 设备、存储设备 |
| 操作系统 | 管理硬件并向上提供抽象 |
| 系统程序 | 编译器、Shell、文件管理工具等 |
| 应用程序 | 浏览器、数据库、办公软件等 |

## 计算机系统组织

CPU、内存和设备控制器通过总线连接。设备控制器负责具体 I/O 设备，CPU 通过中断感知 I/O 完成或异常事件。

### 中断

中断是硬件或软件通知 CPU 需要处理事件的机制。

1. CPU 保存当前程序计数器和执行现场。
2. 跳转到对应的中断服务程序。
3. 服务程序结束后恢复原执行现场。

### I/O 结构

| 方式 | 特点 |
| --- | --- |
| 程序控制 I/O | CPU 主动等待设备完成，效率低 |
| 中断驱动 I/O | I/O 完成后通过中断通知 CPU |
| DMA | 设备控制器直接在内存和设备间传输数据，减少 CPU 参与 |

### 存储结构

存储系统按速度、容量和成本形成层次结构：寄存器、缓存、内存、固态/磁盘、外部存储。越靠近 CPU，速度越快、容量越小、成本越高。

## 计算机体系结构

| 类型 | 特点 |
| --- | --- |
| 单处理器系统 | 一个通用 CPU 执行用户进程和操作系统 |
| 多处理器系统 | 多个 CPU 共享内存和 I/O，提高吞吐量与可靠性 |
| 集群系统 | 多台计算机协同工作，可用于高可用或高性能计算 |

## 操作系统的结构与操作

操作系统从早期串行处理发展到批处理、多道程序、分时系统和现代交互系统。

| 概念 | 说明 |
| --- | --- |
| 多道程序 | 内存中同时保存多个作业，CPU 在作业间切换 |
| 分时系统 | 通过时间片让多个用户/任务交互使用系统 |
| 双模式运行 | 区分用户态和内核态，保护系统资源 |
| 定时器 | 防止用户程序长期占用 CPU |

## 操作系统管理内容

| 管理对象 | 主要职责 |
| --- | --- |
| 进程 | 创建、调度、同步、通信、终止 |
| 内存 | 分配、回收、地址转换、保护 |
| 文件 | 文件创建、删除、读写、权限管理 |
| I/O | 设备驱动、缓冲、缓存、设备分配 |
| 安全保护 | 身份认证、访问控制、资源隔离 |

## 其他计算环境

操作系统还支持移动计算、分布式系统、虚拟化、云计算和实时系统等环境。不同环境的重点不同：移动系统关注能耗和交互，实时系统关注响应时限，云平台关注资源隔离和弹性调度。
