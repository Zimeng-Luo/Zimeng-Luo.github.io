# CPU 调度

## 核心摘要

CPU 调度决定就绪队列中哪个进程获得 CPU。重点是调度时机、评价准则和典型算法：FCFS、SJF、优先级、轮转、多级队列和多级反馈队列。

## 基本概念

进程执行通常在 CPU 区间和 I/O 区间之间交替。I/O 密集型进程通常有较多短 CPU 区间，CPU 密集型进程通常有较长 CPU 区间。

| 概念 | 说明 |
| --- | --- |
| 抢占式调度 | 正在运行的进程可被强制让出 CPU |
| 非抢占式调度 | 进程主动阻塞或结束后才让出 CPU |
| 分派程序 | 实际执行上下文切换并转交 CPU |
| 分派延迟 | 停止一个进程并启动另一个进程所需时间 |

## 调度准则

| 指标 | 目标 |
| --- | --- |
| CPU 利用率 | 尽量高 |
| 吞吐量 | 单位时间完成进程数尽量多 |
| 周转时间 | 从提交到完成的时间尽量短 |
| 等待时间 | 在就绪队列等待时间尽量短 |
| 响应时间 | 从提交请求到首次响应尽量短 |

## 调度算法

| 算法 | 类型 | 特点 |
| --- | --- | --- |
| FCFS | 非抢占 | 简单，但可能产生护航效应 |
| SJF | 可抢占/非抢占 | 平均等待时间短，但难准确预测 CPU 区间 |
| 优先级调度 | 可抢占/非抢占 | 重要任务优先，可能导致饥饿 |
| 轮转 RR | 抢占 | 按时间片轮流执行，适合分时系统 |
| 多级队列 | 通常抢占 | 按进程类型划分多个队列 |
| 多级反馈队列 | 抢占 | 进程可在队列间移动，兼顾响应与公平 |

### 关键问题

| 问题 | 处理 |
| --- | --- |
| SJF 预测 | 用历史 CPU 区间做指数平均 |
| 优先级饥饿 | 使用老化机制逐步提高等待进程优先级 |
| RR 时间片 | 太大接近 FCFS，太小会增加上下文切换 |

## 线程调度

用户级线程可由线程库调度，内核级线程由操作系统调度。现代系统通常调度内核可见的线程。

## 多处理器调度

多处理器调度需要考虑负载均衡和处理器亲和性。

| 概念 | 说明 |
| --- | --- |
| 非对称多处理 | 一个主处理器负责调度和系统活动 |
| 对称多处理 | 每个处理器都可运行内核和调度任务 |
| 处理器亲和性 | 尽量让进程继续在原 CPU 上运行以复用缓存 |

## 实时调度

实时系统关注截止期限。硬实时系统必须在期限内完成任务，软实时系统允许偶发超时但会降低服务质量。
