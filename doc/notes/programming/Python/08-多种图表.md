## 1. Matplotlib 鏁ｇ偣鍥?(Scatter Plot)

鏁ｇ偣鍥句富瑕佺敤浜庤瀵熷拰鏄剧ず涓や釜鍙橀噺涔嬮棿鐨勭浉鍏虫€ф垨鍒嗗竷瓒嬪娍銆傞€氳繃璋冩暣鐐圭殑澶у皬鍜岄鑹诧紝鏁ｇ偣鍥捐繕鍙互灞曠ず涓夌淮鐢氳嚦鍥涚淮鏁版嵁銆?

**鏍稿績鍑芥暟涓庡弬鏁帮細**

- **`plt.scatter(x, y)`**
    
- **`s`**: 鏁ｇ偣鐨勫ぇ灏?(size)锛屽彲浠ユ槸鏍囬噺锛屼篃鍙互鏄笌 `x` 闀垮害鐩稿悓鐨勬暟缁勩€?

**浠ｇ爜绀轰緥锛?*

import numpy as np

# 鐢熸垚闅忔満鏁版嵁

colors = np.random.rand(100) # 闅忔満棰滆壊鏄犲皠鍊?

plt.title("Scatter Plot Example")
plt.show()
```

## 2. Matplotlib 鏌卞舰鍥?(Bar Chart)

鏌卞舰鍥剧敤浜庢樉绀哄垎绫绘暟鎹殑瀵规瘮鎯呭喌锛岄暱鏉＄殑楂樺害琛ㄧず鍚勭被鍒殑鏁板€煎ぇ灏忋€?

- **`plt.barh(y, width)`**: 缁樺埗姘村钩鏉″舰鍥俱€?

- **`color`**: 鏌卞瓙鐨勯鑹层€?

**浠ｇ爜绀轰緥锛?*

plt.show()
```

## 3. Matplotlib 楗煎浘 (Pie Chart)

楗煎浘鐢ㄤ簬鏄剧ず鍚勯」鏁版嵁鍦ㄦ€诲拰涓墍鍗犵殑姣斾緥銆?

- **`colors`**: 棰滆壊鍒楄〃銆?
    
- **`explode`**: 涓€涓暟缁勶紝鎸囧畾姣忎釜鎵囧舰鍋忕鍦嗗績鐨勮窛绂伙紝甯哥敤浜庣獊鍑烘樉绀烘煇涓壒瀹氶儴鍒嗐€?

## 4. Matplotlib 鐩存柟鍥?(Histogram)

鐩存柟鍥剧敤浜庡睍绀鸿繛缁暟鎹殑棰戠巼鍒嗗竷鎯呭喌銆傚畠灏嗘暟鎹寖鍥村垝鍒嗕负鑻ュ共涓繛缁殑鍖洪棿锛坆ins锛夛紝骞剁粺璁℃瘡涓尯闂村唴鍖呭惈鐨勬暟鎹釜鏁般€?

**鏍稿績鍑芥暟涓庡弬鏁帮細**

- **`plt.hist(x)`**: `x` 鏄竴缁存暟鎹暟缁勩€?
    
- **`bins`**: 鐩存柟鍥剧殑鏌辨暟锛堟暣鏁帮級锛屾垨鑷畾涔夌殑鍖洪棿杈圭晫鏁扮粍銆傞粯璁や负 10銆?

- **`facecolor` / `color`**: 鏌卞瓙鐨勫～鍏呴鑹层€?
    
- **`alpha`**: 閫忔槑搴︺€?
