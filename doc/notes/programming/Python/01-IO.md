## 1. NumPy 涓撴湁浜岃繘鍒舵枃浠?(`.npy` 鍜?`.npz`)

浣跨敤 NumPy 涓撴湁鐨勪簩杩涘埗鏍煎紡淇濆瓨鏁版嵁锛岃鍐欓€熷害鏋佸揩锛屼笖鑳藉畬缇庝繚鐣欐暟缁勭殑褰㈢姸锛坰hape锛夊拰鏁版嵁绫诲瀷锛坉type锛夌瓑淇℃伅銆?
