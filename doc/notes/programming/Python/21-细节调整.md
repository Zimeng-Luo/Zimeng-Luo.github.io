- **`markerfacecolor` 鎴?`mfc`**: 鏍囪鍐呴儴鐨勫～鍏呴鑹层€?
    

**浠ｇ爜绀轰緥锛?*

## 3. Matplotlib 杞存爣绛惧拰鏍囬 (Labels & Titles)

娓呮櫚鐨勬爣棰樺拰鍧愭爣杞磋鏄庢槸涓撲笟鍥捐〃鐨勬爣閰嶃€備綘鍙互閫氳繃 `fontdict` 瀛楀吀鍙傛暟娣卞害瀹氬埗鏂囧瓧鐨勫瑙傘€?

**鏍稿績鍑芥暟涓庡弬鏁帮細**

- **`plt.xlabel()` / `plt.ylabel()`**: 璁剧疆 X 杞村拰 Y 杞寸殑鏍囩銆?
    
- **`plt.title()`**: 璁剧疆鍥捐〃鐨勪富鏍囬銆?

- **`fontdict`**: 瀛椾綋灞炴€у瓧鍏革紝鐢ㄤ簬缁熶竴璁剧疆 `family` (瀛椾綋), `color` (棰滆壊), `weight` (绮楃粏), `size` (澶у皬)銆?
    

**浠ｇ爜绀轰緥锛?*
