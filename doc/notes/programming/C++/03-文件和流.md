# C++ 文件和流

## 核心摘要

C++ 使用 `&lt;fstream&gt;` 进行文件读写，核心类是 `std::ifstream`、`std::ofstream` 和 `std::fstream`。文件流的用法与标准输入输出流类似：读文件用 `>>` / `std::getline`，写文件用 `<<`，并通过打开模式控制读写、追加、二进制和截断行为。

## 文件流类

| 类 | 作用 | 常见用途 |
| --- | --- | --- |
| `std::ifstream` | 输入文件流 | 从文件读取 |
| `std::ofstream` | 输出文件流 | 向文件写入 |
| `std::fstream` | 输入输出文件流 | 同一文件既读又写 |

使用前需要包含头文件：

```cpp
#include <fstream>
```

## 打开与关闭文件

文件可以在构造时打开，也可以先创建流对象再调用 `open()`。

```cpp
#include <fstream>

int main() {
    std::ofstream out("data.txt");
    out << "hello\n";
    out.close();

    std::ifstream in;
    in.open("data.txt");
    in.close();
}
```

文件流对象析构时会自动关闭文件，但显式 `close()` 可以更清楚地释放文件句柄。

## 常用打开模式

| 模式 | 含义 |
| --- | --- |
| `std::ios::in` | 读模式 |
| `std::ios::out` | 写模式 |
| `std::ios::app` | 追加写入，每次写入都在文件末尾 |
| `std::ios::ate` | 打开后定位到文件末尾，之后仍可移动位置 |
| `std::ios::trunc` | 打开时清空原文件内容 |
| `std::ios::binary` | 二进制模式 |

多个模式用 `|` 组合：

```cpp
std::ofstream log("app.log", std::ios::out | std::ios::app);
```

## 写入文件

写文件通常使用 `std::ofstream` 和插入运算符 `<<`。

```cpp
#include <fstream>
#include <iostream>

int main() {
    std::ofstream out("user.txt");

    if (!out) {
        std::cerr << "open file failed\n";
        return 1;
    }

    out << "Alice\n";
    out << 18 << '\n';
}
```

## 读取文件

读取单词或数字可以用 `>>`；读取整行文本用 `std::getline()`。

```cpp
#include <fstream>
#include <iostream>
#include <string>

int main() {
    std::ifstream in("user.txt");
    std::string line;

    while (std::getline(in, line)) {
        std::cout << line << '\n';
    }
}
```

## 文件位置指针

文件流内部维护读写位置，可用于随机访问。

| 函数 | 作用 |
| --- | --- |
| `tellg()` | 获取当前读位置 |
| `seekg()` | 移动读位置 |
| `tellp()` | 获取当前写位置 |
| `seekp()` | 移动写位置 |

常见定位基准：

| 基准 | 含义 |
| --- | --- |
| `std::ios::beg` | 文件开头 |
| `std::ios::cur` | 当前位置 |
| `std::ios::end` | 文件末尾 |

```cpp
std::ifstream in("data.txt", std::ios::binary);
in.seekg(0, std::ios::end);
auto size = in.tellg();
```

## 使用要点

- 新代码优先使用 `std::ifstream` / `std::ofstream` 明确读写方向。
- 打开文件后先检查流状态：`if (!file)` 或 `if (file.is_open())`。
- 文本逐行读取优先使用 `std::getline()`。
- `std::ios::app` 是强制追加；`std::ios::ate` 只是打开后先移动到末尾。
- 写模式可能清空原文件，保留原内容时使用 `std::ios::app`。
- 处理图片、音频、结构体等非纯文本数据时使用 `std::ios::binary`。
