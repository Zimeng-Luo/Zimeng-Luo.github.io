# C++ 基本输入输出

## 核心摘要

C++ 通过 `&lt;iostream&gt;` 提供标准输入输出流。`cout` 用于标准输出，`cin` 用于标准输入。常用重点是流插入 `<<`、流提取 `>>`、`endl` 换行、`cin` 按空白分隔读取。

## 1. 标准流

| 流 | 作用 | 特点 |
| --- | --- | --- |
| `cout` | 标准输出 | 常用于正常信息输出 |
| `cin` | 标准输入 | 从键盘读取数据 |
| `cerr` | 标准错误输出 | 非缓冲，错误会立即输出 |
| `clog` | 标准日志输出 | 缓冲输出，适合日志信息 |

## 2. 输出

```cpp
#include <iostream>

int main() {
    std::cout << "Hello C++" << std::endl;
}
```

要点：

- `<<` 是流插入运算符。
- `endl` 会输出换行并刷新缓冲区。
- 同一条语句可以连续输出多个值。

```cpp
std::cout << "name: " << name << ", age: " << age << '\n';
```

## 3. 输入

```cpp
#include <iostream>

int main() {
    char name[50];
    int age;

    std::cin >> name >> age;
}
```

要点：

- `>>` 是流提取运算符。
- `cin` 默认按空白字符分隔输入，空格、换行、制表符都会结束当前读取。
- 连续输入可直接写成 `cin >> a >> b >> c;`。

## 4. 常见易错点

- 误以为 `cin` 会读取整行；它默认只读到空白字符前。
- 用 `getline()` 前没有处理前一次输入留下的换行。
- 忘记 `endl` 会刷新缓冲区，和 `'\n'` 不完全相同。
