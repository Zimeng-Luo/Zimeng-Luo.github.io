# C++ 注释

## 核心摘要

C++ 注释用于解释代码意图、提高可读性，也可在调试时临时屏蔽代码。编译器会忽略注释内容。常用注释形式包括单行注释 `//` 和块注释 `/* ... */`；需要大段屏蔽代码时，也可以使用预处理条件编译 `#if 0 ... #endif`。

## 1. 注释的作用

注释是写给人看的说明文字，不参与程序运行。

常见用途：

- 解释代码为什么这样写，而不是简单重复代码做了什么。
- 标记关键逻辑、边界条件、临时处理和待完善位置。
- 在调试时临时屏蔽少量代码。
- 帮助他人或未来的自己快速理解代码结构。

## 2. 单行注释

单行注释以 `//` 开始，直到当前行末结束。

```cpp
#include <iostream>

int main() {
    // 输出问候语
    std::cout << "Hello World!" << std::endl;
    return 0;
}
```

也可以写在语句后面，用于补充说明当前语句。

```cpp
int count = 10; // 记录元素数量
```

注意点：

- `//` 后面的内容会被编译器忽略。
- 单行注释适合解释短逻辑或临时标记。
- 不建议在每一行都添加重复性注释，否则会降低可读性。

## 3. 块注释

块注释以 `/*` 开始，以 `*/` 结束，可以跨越多行。

```cpp
/*
    计算矩形面积：
    width 表示宽度
    height 表示高度
*/
int area = width * height;
```

块注释也可以写成一行。

```cpp
int result = 0; /* 初始化结果 */
```

注意点：

- 块注释适合说明一段代码的整体逻辑。
- 块注释不能直接嵌套使用。
- 如果块注释中误写了 `*/`，注释会提前结束，可能导致编译错误。

错误示例：

```cpp
/*
    外层注释开始
    /*
        内层注释
    */
    外层注释结束
*/
```

## 4. 两种注释的解析关系

在块注释内部，`//` 只是普通字符，不会开启单行注释。

```cpp
/*
    // 这里仍然属于块注释内容
*/
```

在单行注释内部，`/*` 和 `*/` 也只是普通字符，不会开启或结束块注释。

```cpp
// /* 这里不会开启块注释 */
```

## 5. 使用条件编译屏蔽代码

当需要临时屏蔽一大段代码，尤其是代码内部已经包含块注释时，可以使用 `#if 0 ... #endif`。

```cpp
#if 0
std::cout << "debug message" << std::endl;
/*
    这里可以包含块注释
*/
#endif
```

含义：

- `#if 0`：条件为假，预处理阶段会跳过其中的代码。
- `#endif`：结束条件编译区域。
- 将 `0` 改为 `1` 后，这段代码会重新参与编译。

这种方式属于预处理条件编译，不是普通注释。

## 6. 注释编写原则

优先写有信息量的注释。

```cpp
// 不推荐：给 i 加 1
i++;

// 推荐：跳过当前已经处理过的元素
i++;
```

实践建议：

- 注释应解释意图、约束、原因和风险。
- 代码本身能清楚表达的内容，不必重复注释。
- 修改代码时同步更新注释，避免注释与实现不一致。
- 对复杂算法、特殊边界和非显然的性能优化，应保留简洁说明。
