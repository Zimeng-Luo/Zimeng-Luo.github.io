# C++ 友元与静态成员

## 核心摘要

友元用于让类外函数或其他类访问当前类的私有成员；静态成员属于类本身，由所有对象共享。二者都改变普通成员访问方式，使用时应保持边界清晰。

## 友元函数

友元函数不是成员函数，但被类授权后可以访问其 `private` 和 `protected` 成员。

```cpp
class Box {
private:
    double width = 0.0;

public:
    void setWidth(double wid) {
        width = wid;
    }

    friend void printWidth(const Box& box);
};

void printWidth(const Box& box) {
    cout << box.width << endl;
}
```

| 要点 | 说明 |
| --- | --- |
| 非成员 | 友元函数没有 `this` 指针 |
| 非继承 | 友元关系不能继承，也不能传递 |
| 破坏封装 | 只在确有必要时使用 |

## 友元类

如果希望一个类的所有成员函数都能访问当前类的私有成员，可以声明整个类为友元。

```cpp
class BigBox;

class Box {
private:
    double width = 0.0;

public:
    friend class BigBox;
};
```

## 静态数据成员

静态数据成员属于类本身，所有对象共享同一份数据。

```cpp
class Box {
public:
    static int objectCount;

    Box() {
        objectCount++;
    }
};

int Box::objectCount = 0;
```

静态数据成员在类内声明，通常还要在类外定义并初始化。

## 静态成员函数

静态成员函数不依赖具体对象，不能直接访问非静态成员，也没有 `this` 指针。

```cpp
class Box {
public:
    static int objectCount;

    static int getCount() {
        return objectCount;
    }
};

int count = Box::getCount();
```

## 速查

| 机制 | 作用 | 注意 |
| --- | --- | --- |
| `friend` 函数 | 类外函数访问私有成员 | 不是成员函数 |
| `friend class` | 整个类获得访问权限 | 关系不传递 |
| `static` 数据成员 | 类级共享状态 | 一般需类外定义 |
| `static` 成员函数 | 类级工具函数或访问静态数据 | 没有 `this` |
