# C++ 控制流程

## 核心摘要

C++ 的控制流程主要由判断、循环和跳转语句组成。判断结构用来分支执行，循环结构用来重复执行，`break`、`continue` 等语句用来调整流程；实际编写时重点掌握条件表达式、循环边界和短路行为。

## 1. 判断结构

判断结构用于根据条件选择执行路径。

### 1.1 `if`

```cpp
if (condition) {
    // 条件为真时执行
}
```

### 1.2 `if...else`

```cpp
if (condition) {
    // 真分支
} else {
    // 假分支
}
```

### 1.3 `else if`

```cpp
if (score >= 90) {
    grade = 'A';
} else if (score >= 60) {
    grade = 'B';
} else {
    grade = 'C';
}
```

### 1.4 `switch`

`switch` 适合一个变量对应多个离散值的判断。

```cpp
switch (day) {
    case 1:
        std::cout << "Monday\n";
        break;
    case 2:
        std::cout << "Tuesday\n";
        break;
    default:
        std::cout << "Other day\n";
        break;
}
```

要点：

- `case` 后通常跟常量表达式。
- `break` 用于防止继续落入下一个 `case`。
- `default` 是兜底分支，可选但常用。

### 1.5 条件运算符

`?:` 常用于简单二选一。

```cpp
int max_value = (a > b) ? a : b;
```

## 2. 循环结构

循环用于重复执行一段代码。

### 2.1 `while`

先判断，再执行。

```cpp
int i = 0;
while (i < 5) {
    ++i;
}
```

### 2.2 `for`

适合已知循环次数或明确边界的场景。

```cpp
for (int i = 0; i < 5; ++i) {
    // 循环体
}
```

### 2.3 `do...while`

先执行一次，再判断条件。

```cpp
int i = 0;
do {
    ++i;
} while (i < 5);
```

### 2.4 嵌套循环

循环内部还可以套循环，常用于二维遍历。

```cpp
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        // 处理二维数据
    }
}
```

### 2.5 无限循环

```cpp
for (;;) {
    // 一直执行
}
```

## 3. 循环控制语句

### 3.1 `break`

立即终止当前循环或 `switch`。

### 3.2 `continue`

跳过本次循环剩余语句，进入下一轮判断。

### 3.3 `goto`

可跳转到标签位置，但一般不建议使用。

```cpp
start:
    // ...
    goto start;
```

## 4. 常见记法

```cpp
a > b ? a : b;          // 条件选择
a && b || c;            // 先 && 后 ||
for (int i = 0; i < n; ++i) {}
while (condition) {}
do {} while (condition);
```

## 5. 常见易错点

- `switch` 忘记写 `break`。
- `while` 和 `do...while` 的执行顺序混淆。
- 循环边界写错，导致少一次或多一次。
- 把复杂分支强行写成嵌套三元表达式。
