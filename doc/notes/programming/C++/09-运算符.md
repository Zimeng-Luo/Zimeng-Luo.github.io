# C++ 运算符

## 核心摘要

C++ 运算符用于对变量、字面量和表达式执行计算、比较、逻辑判断、位操作、赋值和对象访问。实际使用时重点掌握运算符含义、结果类型、短路逻辑、副作用和优先级；复杂表达式应主动加括号提升可读性。

## 1. 算术运算符

| 运算符  | 含义       | 示例          |
| ---- | -------- | ----------- |
| `+`  | 加法       | `a + b`     |
| `-`  | 减法       | `a - b`     |
| `*`  | 乘法       | `a * b`     |
| `/`  | 除法       | `a / b`     |
| `%`  | 取模，求整数余数 | `a % b`     |
| `++` | 自增       | `++a`、`a++` |
| `--` | 自减       | `--a`、`a--` |

```cpp
int a = 10;
int b = 3;

int sum = a + b; // 13
int div = a / b; // 3，整数除法会丢弃小数部分
int mod = a % b; // 1
```

注意：

- `%` 只能用于整数类型。
- 整数相除得到整数；需要小数结果时至少有一个操作数应为浮点数。
- `++a` 先自增再使用，`a++` 先使用再自增。

## 2. 关系运算符

关系运算符用于比较两个值，结果是 `bool`。

| 运算符 | 含义 |
| --- | --- |
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

```cpp
int a = 10;
int b = 20;

bool less = a < b;     // true
bool same = a == b;    // false
bool different = a != b; // true
```

注意：判断相等使用 `==`，赋值使用 `=`。

## 3. 逻辑运算符

逻辑运算符用于组合布尔表达式。

| 运算符 | 含义 |
| --- | --- |
| `&&` | 逻辑与，两个条件都为真才为真 |
| <code>&#124;&#124;</code> | 逻辑或，至少一个条件为真就为真 |
| `!` | 逻辑非，取反 |

```cpp
int age = 20;
bool has_ticket = true;

if (age >= 18 && has_ticket) {
    // 可以进入
}
```

短路规则：

- `a && b`：如果 `a` 为假，不再计算 `b`。
- `a || b`：如果 `a` 为真，不再计算 `b`。

## 4. 位运算符

位运算符直接操作整数的二进制位。

| 运算符 | 含义 |
| --- | --- |
| `&` | 按位与 |
| <code>&#124;</code> | 按位或 |
| `^` | 按位异或 |
| `~` | 按位取反 |
| `<<` | 左移 |
| `>>` | 右移 |

```cpp
unsigned int a = 5; // 0101
unsigned int b = 3; // 0011

unsigned int x = a & b; // 0001
unsigned int y = a | b; // 0111
unsigned int z = a ^ b; // 0110
```

常见用途：

- 位掩码。
- 标志位组合。
- 底层协议和硬件寄存器操作。

## 5. 赋值运算符

赋值运算符会修改左侧变量。

| 运算符 | 等价形式 |
| --- | --- |
| `=` | 普通赋值 |
| `+=` | `a = a + b` |
| `-=` | `a = a - b` |
| `*=` | `a = a * b` |
| `/=` | `a = a / b` |
| `%=` | `a = a % b` |
| `<<=` | `a = a << b` |
| `>>=` | `a = a >> b` |
| `&=` | `a = a & b` |
| `^=` | `a = a ^ b` |
| <code>&#124;=</code> | <code>a = a &#124; b</code> |

```cpp
int count = 10;
count += 5; // 15
count *= 2; // 30
```

## 6. 条件运算符

条件运算符 `?:` 是三元运算符。

```cpp
int score = 80;
const char* result = score >= 60 ? "pass" : "fail";
```

形式：

```cpp
condition ? value_if_true : value_if_false;
```

适合简单二选一表达式；逻辑复杂时优先使用 `if`。

## 7. 成员、指针和地址相关运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 通过对象访问成员 | `obj.value` |
| `->` | 通过指针访问成员 | `ptr->value` |
| `&` | 取地址 | `&x` |
| `*` | 解引用指针 | `*p` |
| `sizeof` | 获取类型或对象大小 | `sizeof(int)` |

```cpp
struct Point {
    int x;
    int y;
};

Point p{1, 2};
Point* ptr = &p;

int a = p.x;
int b = ptr->y;
```

注意：`*` 既可以表示乘法，也可以表示指针解引用；`&` 既可以表示按位与，也可以表示取地址，具体含义由上下文决定。

## 8. 逗号运算符

逗号运算符会从左到右依次计算表达式，整个表达式的值是最后一个表达式的值。

```cpp
int a = 1;
int b = (a += 2, a * 3); // a 为 3，b 为 9
```

实际项目中不要滥用逗号运算符，避免降低可读性。

## 9. 运算符优先级要点

| 优先级 | 运算符 | 结合性 |
| --- | --- | --- |
| 1 | `::` | 左到右 |
| 2 | `()` `[]` `->` `.` `++` `--` `typeid` `dynamic_cast` `static_cast` `const_cast` `reinterpret_cast` | 左到右 |
| 3 | 一元运算：`+` `-` `!` `~` `*` `&` `++` `--` `sizeof` `new` `delete` | 右到左 |
| 4 | `.*` `->*` | 左到右 |
| 5 | 乘除模：`*` `/` `%` | 左到右 |
| 6 | 加减：`+` `-` | 左到右 |
| 7 | 移位：`<<` `>>` | 左到右 |
| 8 | 关系：`<` `<=` `>` `>=` | 左到右 |
| 9 | 相等：`==` `!=` | 左到右 |
| 10 | 位与：`&` | 左到右 |
| 11 | 位异或：`^` | 左到右 |
| 12 | 位或：`&#124;` | 左到右 |
| 13 | 逻辑与：`&&` | 左到右 |
| 14 | 逻辑或：`&#124;&#124;` | 左到右 |
| 15 | 条件：`?:` | 右到左 |
| 16 | 赋值：`=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `&#124;=` | 右到左 |
| 17 | 逗号：`,` | 左到右 |

几个常见记法：

```cpp
a + b * c;      // 先乘后加
a << b + c;     // 先算 b + c
x = y = 3;      // 右结合，先 y = 3
a && b || c;    // 先 && 后 ||
```

复杂表达式建议加括号，不依赖读者记忆优先级。

## 10. 常见易错点

- 把 `=` 写成 `==`，或把 `==` 写成 `=`。
- 整数除法误以为会保留小数。
- 在同一个复杂表达式中多次修改同一变量。
- 混淆逻辑运算符 `&&`、`||` 和位运算符 `&`、`|`。
- 忽略 `&&`、`||` 的短路行为。
