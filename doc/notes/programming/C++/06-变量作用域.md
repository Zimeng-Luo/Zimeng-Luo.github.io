# C++ 变量作用域

## 核心摘要

C++ 变量作用域决定变量名在程序中哪些位置可见。常见作用域包括局部作用域、函数参数作用域、块作用域、全局作用域和类作用域。作用域越小，变量越容易控制；同名变量出现在内外层作用域时，内层变量会遮蔽外层变量。

## 1. 作用域的基本概念

作用域是一个名字可被访问的程序区域。

变量可以定义在不同位置：

- 函数或代码块内部：局部变量。
- 函数参数列表中：形式参数。
- 所有函数外部：全局变量。
- 类内部：成员变量或静态成员变量。

作用域影响两个问题：

- 可见性：变量名能在哪些位置被访问。
- 生命周期：变量对应的对象在什么时候创建和销毁。

注意：作用域和生命周期相关，但不是同一个概念。作用域描述“名字在哪里可见”，生命周期描述“对象什么时候存在”。

## 2. 局部作用域

在函数内部定义的变量具有局部作用域，只能在该函数内部访问。

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 20;
    int c = a + b;

    std::cout << c << std::endl;
    return 0;
}
```

特点：

- 每次进入函数时创建。
- 函数执行结束后销毁。
- 函数外部不能直接访问。
- 未初始化的局部自动变量值不确定，使用前必须初始化。

```cpp
int main() {
    int count;     // 值不确定
    int safe = 0;  // 推荐：显式初始化
    return 0;
}
```

## 3. 函数参数作用域

函数参数也是局部名字，它们只在函数体内可见。

```cpp
int add(int a, int b) {
    return a + b;
}
```

这里 `a` 和 `b` 是形式参数：

- 调用函数时由实参传入值。
- 在函数内部像局部变量一样使用。
- 函数结束后参数对象随函数调用结束而销毁。

```cpp
int result = add(10, 20);
```

## 4. 块作用域

大括号 `{}` 内部定义的变量具有块作用域，只能在当前代码块内部访问。

```cpp
#include <iostream>

int main() {
    int a = 10;

    {
        int b = 20;
        std::cout << b << std::endl;
    }

    // std::cout << b << std::endl; // 错误：b 已经离开作用域
    return 0;
}
```

块作用域常见于：

- `if`、`else` 语句块。
- `for`、`while` 循环块。
- 人为创建的临时代码块。

```cpp
for (int i = 0; i < 3; ++i) {
    std::cout << i << std::endl;
}

// i 在循环外不可见
```

## 5. 全局作用域

在所有函数和类外部定义的变量具有全局作用域。

```cpp
#include <iostream>

int g = 0; // 全局变量

int main() {
    g = 30;
    std::cout << g << std::endl;
    return 0;
}
```

特点：

- 程序开始时创建，程序结束时销毁。
- 可以被同一翻译单元中后续代码访问。
- 如果需要跨文件访问，通常配合 `extern` 声明。
- 具有静态存储期，会被默认零初始化。

全局变量会扩大状态影响范围，实际项目中应谨慎使用。更常见的替代方式是把状态封装到对象、函数参数或配置结构中。

## 6. 类作用域

类内部声明的成员名字具有类作用域，需要通过对象、指针或类名访问。

```cpp
#include <iostream>

class Counter {
public:
    int value = 0;

    void increase() {
        value++;
    }
};

int main() {
    Counter counter;
    counter.increase();
    std::cout << counter.value << std::endl;
    return 0;
}
```

静态成员变量属于类本身，通常使用类名和作用域解析运算符 `::` 访问。

```cpp
#include <iostream>

class MyClass {
public:
    static int class_value;
};

int MyClass::class_value = 30;

int main() {
    std::cout << MyClass::class_value << std::endl;
    return 0;
}
```

## 7. 同名变量与遮蔽

内层作用域可以定义与外层作用域同名的变量。此时内层变量会遮蔽外层变量。

```cpp
#include <iostream>

int g = 20;

int main() {
    int g = 10;
    std::cout << g << std::endl; // 输出 10
    return 0;
}
```

块作用域中的同名变量也是一样。

```cpp
#include <iostream>

int main() {
    int a = 10;

    {
        int a = 20;
        std::cout << "inner: " << a << std::endl;
    }

    std::cout << "outer: " << a << std::endl;
    return 0;
}
```

输出：

```text
inner: 20
outer: 10
```

如果确实要在局部作用域中访问被遮蔽的全局变量，可以使用作用域解析运算符 `::`。

```cpp
#include <iostream>

int value = 100;

int main() {
    int value = 10;

    std::cout << value << std::endl;   // 局部变量：10
    std::cout << ::value << std::endl; // 全局变量：100
    return 0;
}
```

## 8. 不同作用域变量的初始化

局部自动变量不会自动初始化。

```cpp
int main() {
    int local_value; // 值不确定
    return 0;
}
```

全局变量和静态变量具有静态存储期，会被零初始化。

```cpp
int global_int;       // 0
double global_double; // 0.0
char global_char;     // '\0'
int* global_ptr;      // nullptr
```

实践中仍然建议显式初始化变量，避免依赖隐式规则。

```cpp
int global_count = 0;

int main() {
    int local_count = 0;
    return 0;
}
```

## 9. 作用域使用建议

- 优先使用尽可能小的作用域，降低变量误用风险。
- 变量尽量在首次使用前再定义，并立即初始化。
- 避免局部变量与全局变量、成员变量随意重名。
- 控制全局变量数量，避免程序状态分散且难以追踪。
- 循环计数器优先定义在 `for` 语句内部。
- 类成员与局部变量同名时，可用 `this->member` 明确指向成员变量。
