# C++ 数组、指针与字符串

## 核心摘要

数组用于存放一组连续、同类型的数据；指针用于保存变量地址并间接访问内存；字符串既可以用 C 风格字符数组表示，也可以用更安全易用的 `std::string` 表示。三者的共同重点是内存连续性、下标边界、地址与解引用。

## 1. 数组

数组是固定大小、元素类型相同、内存连续的数据集合。

### 1.1 声明与初始化

```cpp
int nums[5];                    // 声明 5 个 int
int a[3] = {1, 2, 3};           // 完整初始化
int b[5] = {1, 2};              // 后续元素自动置 0
int c[] = {1, 2, 3};            // 自动推断长度为 3
```

数组长度在普通数组声明后不可改变，访问元素使用下标：

```cpp
int first = a[0];
a[1] = 10;
```

注意：C++ 数组下标从 `0` 开始，合法范围是 `0` 到 `长度 - 1`。

### 1.2 多维数组

二维数组常用于表格、矩阵等结构。

```cpp
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

int x = matrix[1][2]; // 6
```

### 1.3 数组与函数

数组作为函数参数时会退化为指针，函数内部无法直接知道原始数组长度，通常需要额外传入长度。

```cpp
void printArray(int arr[], int size) {
    for (int i = 0; i < size; ++i) {
        std::cout << arr[i] << '\n';
    }
}
```

## 2. 指针

指针变量保存的是地址。通过指针可以间接访问或修改目标对象。

### 2.1 基本语法

```cpp
int value = 10;
int* p = &value;  // & 取地址

std::cout << p;   // 输出地址
std::cout << *p;  // * 解引用，得到 10

*p = 20;          // 修改 value
```

常见符号：

| 符号 | 含义 |
| --- | --- |
| `&x` | 取得变量 `x` 的地址 |
| `int* p` | 声明指向 `int` 的指针 |
| `*p` | 解引用，访问指针指向的对象 |
| `nullptr` | 空指针，表示不指向任何有效对象 |

### 2.2 空指针与安全访问

```cpp
int* p = nullptr;

if (p != nullptr) {
    std::cout << *p;
}
```

不要解引用空指针或未初始化指针，否则会产生未定义行为。

### 2.3 指针运算

指针加减会按指向类型的大小移动，常用于遍历数组。

```cpp
int arr[3] = {10, 20, 30};
int* p = arr;

std::cout << *p;       // 10
std::cout << *(p + 1); // 20
```

数组名在多数表达式中会退化为指向首元素的指针，因此 `arr[i]` 与 `*(arr + i)` 等价。

## 3. 字符串

C++ 中常见两类字符串：C 风格字符串和 `std::string`。

### 3.1 C 风格字符串

C 风格字符串本质是以空字符 `'\0'` 结尾的字符数组。

```cpp
char str1[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
char str2[] = "Hello";
```

字符串字面量会自动包含结尾的 `'\0'`，因此 `"Hello"` 实际需要 6 个字符空间。

常见函数需要包含头文件：

```cpp
#include <cstring>

std::strlen(str2);      // 字符串长度，不含 '\0'
std::strcpy(str1, str2); // 复制字符串
std::strcmp(str1, str2); // 比较字符串
```

### 3.2 `std::string`

`std::string` 是 C++ 标准库字符串类型，推荐日常优先使用。

```cpp
#include <string>

std::string s = "Hello";
s += " C++";

std::cout << s.length();
std::cout << s[0];
```

常用操作：

| 操作 | 示例 |
| --- | --- |
| 拼接 | `s1 + s2`、`s += "x"` |
| 长度 | `s.size()`、`s.length()` |
| 访问字符 | `s[i]`、`s.at(i)` |
| 判空 | `s.empty()` |
| C 字符串指针 | `s.c_str()` |

## 4. 三者关系

| 主题 | 关键关系 |
| --- | --- |
| 数组与指针 | 数组名常退化为首元素指针 |
| 指针与字符串 | C 风格字符串常用 `char*` 或 `const char*` 表示 |
| 数组与字符串 | 字符数组以 `'\0'` 结尾时可作为 C 风格字符串 |
| `std::string` | 封装了动态字符序列，更适合普通业务代码 |

## 5. 常见易错点

- 数组越界访问，例如访问 `arr[size]`。
- 忘记 C 风格字符串末尾需要 `'\0'`。
- 误以为数组参数能自动保留数组长度。
- 解引用未初始化指针、空指针或已经失效的指针。
- 混淆 `p`、`&p`、`*p` 的含义。
- 用 `==` 比较 C 风格字符串内容；应使用 `std::strcmp`，或改用 `std::string`。
