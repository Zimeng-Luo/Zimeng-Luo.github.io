# 线性代数（一）：用秩串联矩阵、向量空间与方程组

矩阵可以看成线性映射。对于 `A ∈ R^(m×n)`，输入 n 维向量，输出 m 维向量。秩描述输出中真正独立的方向数量，因而能够连接向量空间、可逆性和解的自由度。

## 运算首先检查尺寸

```text
A: m×n，B: n×p  →  AB: m×p
(AB)ᵀ = BᵀAᵀ
(AB)⁻¹ = B⁻¹A⁻¹    （A、B 都是可逆方阵时）
```

矩阵乘法一般不交换，也不能像普通数字那样随意消去。`AB = AC` 只有在 A 具有合适的可消去条件时才能推出 `B = C`，例如 A 可逆；`AB = 0` 也不意味着某个因子必为零。

矩阵幂只对方阵定义，`A⁰=I`。多项式 `f(A)` 的常数项对应常数乘单位矩阵。同一个矩阵的多项式可以交换，不同矩阵的多项式则不能据此交换。

## 秩是独立方向数量

列向量张成列空间，行向量张成行空间，两者的维数相同，称为矩阵秩。它也等于非零子式的最高阶数：

```text
0 ≤ rank(A) ≤ min(m,n)
rank(A) = rank(Aᵀ)
rank(AB) ≤ min(rank(A), rank(B))
```

初等行、列变换都保持秩。行变换保持各列之间的线性依赖关系，因此从行最简形找主元列后，应回到原矩阵取这些列作为列空间基。

```text
A = [1 2 3]  →  行化简后只有一行非零  →  rank(A)=1
    [2 4 6]
```

三列都落在同一条直线上，不是三个独立输出方向。

## 基与坐标

向量组线性无关表示只有全零系数才能使线性组合为零。空间的一组基必须既线性无关，又张成整个空间；基不唯一，但所含向量数量即维数不变。零空间的维数可以是 0，其基为空组。

设基矩阵 `B` 的列是基向量，向量 `x=Bc` 中的 c 是坐标。如果新基 `B′=BP`，则同一向量满足 `c=Pc′`。向量没有改变，坐标随基变化。方阵基矩阵情况下 `P=B⁻¹B′`。

## 方程组的解由秩决定

令增广矩阵为 `[A ∣ b]`，未知数数量为 n：

| 条件 | 解的情况 |
| --- | --- |
| 两个秩不相等 | 无解 |
| 两个秩相等且为 n | 唯一解 |
| 两个秩相等且小于 n | 无穷多解 |

齐次系统 `Ax=0` 总有零解，零空间维数为 `n − rank(A)`。非齐次系统有解时，全部解写成：

```text
x = xₚ + Σᵢ cᵢzᵢ
```

`xₚ` 是一个特解，`zᵢ` 是零空间的基。解集通常是仿射空间，非零右端时不是经过原点的向量子空间。

对前面的秩为 1 的矩阵，若 `b=(1,2)ᵀ`，方程等价于 `x₁+2x₂+3x₃=1`，通解为：

```text
x = (1,0,0)ᵀ + u(−2,1,0)ᵀ + v(−3,0,1)ᵀ
```

## 行列式与可逆性

对于 n 阶方阵，满秩、可逆、行列式非零、零不为特征值、齐次系统只有零解彼此等价。非方阵不能直接套用这一整组判据。

行列式交换两行变号、一行乘 k 就乘 k、一行加另一行的倍数不变。矩阵整体乘 k 时，则 `det(kA)=kⁿdet(A)`。沿一行展开要带代数余子式符号。

伴随矩阵记为 `adj(A)`，满足 `A adj(A)=det(A)I`。可逆时 `A⁻¹=adj(A)/det(A)`；它与转置和逆不是同一个对象。范德蒙德行列式的因子是对所有 `j<i` 取 `xᵢ−xⱼ`，不是对一个未定义索引随意相乘。

实际求解方程优先用消元或分解，不显式求逆。浮点环境下还要检查条件数与残差：理论可逆也可能因接近奇异而对扰动十分敏感。
