# 线性代数（二）：内积、正交与空间几何

上一章关心能生成多少独立方向，本篇关心方向之间的长度与夹角。内积给空间加入几何结构，正交基使投影和坐标表达更简单。

## 内积定义长度和夹角

本文统一把向量写成列向量。在实数欧氏空间中：

```text
⟨a,b⟩ = aᵀb
‖a‖ = √⟨a,a⟩
cos θ = ⟨a,b⟩/(‖a‖‖b‖)    （两向量非零）
|⟨a,b⟩| ≤ ‖a‖‖b‖
```

内积为零表示正交；零向量与所有向量正交，但零向量没有方向，也不与其他向量定义夹角。两两正交的非零向量一定线性无关。

将 a 投影到非零向量 b 的方向：

```text
proj_b(a) = [⟨a,b⟩/⟨b,b⟩] b
```

余项 `a − proj_b(a)` 与 b 正交。最小二乘也是投影思想：把无法精确满足的目标投到可表达的列空间中。

## 正交化与正交矩阵

Gram–Schmidt 将线性无关的向量逐个减去前面方向上的投影：

```text
uₖ = aₖ − Σⱼ<ₖ [⟨aₖ,uⱼ⟩/⟨uⱼ,uⱼ⟩]uⱼ
qₖ = uₖ/‖uₖ‖
```

如果输入已相关，某一步可能得到零向量，不能再单位化。浮点计算时经典形式可能丢失正交性，工程上常用稳定的 QR 分解或改进算法。

方阵 Q 满足 `QᵀQ=I` 时为正交矩阵，`Q⁻¹=Qᵀ`，保持长度、内积和夹角，行列式为 ±1。+1 可对应旋转，−1 可包含反射。正交矩阵的和一般不再正交。

非方阵的列也可以正交归一，此时 `QᵀQ=I`，但 `QQᵀ` 通常只是投影矩阵，不能按方阵求逆公式使用。

## 三维中的叉积与体积

```text
a×b = (aᵧb_z−a_zbᵧ, a_zbₓ−aₓb_z, aₓbᵧ−aᵧbₓ)
‖a×b‖ = ‖a‖‖b‖sin θ
(a×b)·c = det([aᵀ; bᵀ; cᵀ])
```

叉积方向垂直于原两向量，大小是平行四边形面积；混合积绝对值是平行六面体体积，为零表示线性相关。

判断平行可用叉积为零，避免坐标比值遇到分母为零。零向量参与时最好直接说线性相关，不给它强行赋予方向。

## 平面、直线与距离

平面法向量 n 非零，过点 p₀ 的平面为 `n·(x−p₀)=0`。直线以非零方向 d 和起点 p₀ 表示为 `x=p₀+td`。参数式避免对称式出现方向分量为零而无法相除。

```text
点 p 到平面： |n·(p−p₀)|/‖n‖
点 p 到直线： ‖(p−p₀)×d‖/‖d‖
两条非平行直线： |(p₂−p₁)·(d₁×d₂)|/‖d₁×d₂‖
```

最后一式给出两条非平行直线的最短距离，异面时为正，相交时为零；平行时分母为零，需另行用点到直线距离计算。三点确定平面也要求它们不共线。

例子：平面 `z=2` 的法向量为 `(0,0,1)`，点 `(1,3,5)` 到平面距离为 3。它在平面上的投影是 `(1,3,2)`，误差方向恰好沿法向量。

将空间公式放回“投影到哪个方向、消除了哪部分误差”来理解，比单独背坐标式更容易处理边界情况。
