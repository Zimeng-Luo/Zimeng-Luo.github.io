## 位置相关操作

### pwd

作用：查看当前目录。

```bash
pwd
```

PowerShell 对应：

```powershell
Get-Location
```

---

### ls

作用：列出当前目录下的文件和文件夹。

```bash
ls
ls notes
ls -a
ls -l
```

先记住最常用的两种：

- `ls`：看当前目录内容
- `ls 某目录`：看指定目录内容

> -a：查看全部文件（包括隐藏的文件）
> -l：查看详细信息

---

### cd

作用：切换目录。

```bash
cd notes
cd ..
cd .
```

同时应该记住：

- `.`：当前目录
- `..`：上一级目录


## 更改相关操作

### mkdir

作用：创建目录。

```bash
mkdir demo
mkdir notes
```

---

### `cp`

作用：复制文件或目录。

```bash
cp a.txt b.txt
cp a.txt notes/
cp -r dir1 dir2
```

常见理解：

- 文件到文件：复制并改名
- 文件到目录：复制进去
- 目录复制：一般需要 `-r`

---

### mv

作用：移动文件，或者重命名。

```bash
mv a.txt notes/
mv old.txt new.txt
```

它常见有两种用途：

- 换位置
- 改名字

---

### rm

作用：删除文件或目录。

```bash
rm a.txt
rm -r notes
```

## 查找相关操作

### find

作用：按名字、路径、类型查找文件或目录。

```bash
find . -name "*.txt"
find . -type d
find . -name "note*"
```

参数释义：

- `.`：从当前目录开始找
- `-name "*.txt"`：找所有 `.txt` 文件
- `-type d`：只找目录

---

### grep

作用：在文件内容中搜索关键词。

```bash
grep "hello" a.txt
grep -r "TODO" .
grep -n "error" log.txt
```

常用参数：

- `-r`：递归搜索
- `-n`：显示行号

区分：

- `find`：找文件名
- `grep`：找文件内容

## 预览相关操作

### cat

作用：直接打印文件内容。

```bash
cat a.txt
cat notes.txt
```

适合小文件，不适合特别长的文件。


---

### less

作用：分页查看文件，适合长文件。

```bash
less log.txt
```

常见操作：

  - 空格 或 PageDown：下一页
  - b 或 PageUp：上一页
  - Enter 或 j：下一行
  - k：上一行
  - g：跳到文件开头
  - G：跳到文件结尾
  - /关键词：向下搜索
  - ?关键词：向上搜索
  - n：跳到下一个搜索结果
  - N：跳到上一个搜索结果
  - q：退出
  - h：查看帮助

---

### head

作用：查看文件开头几行。

```bash
head a.txt
head -n 5 a.txt
```

---

### tail

作用：查看文件末尾几行。

```bash
tail a.txt
tail -n 5 a.txt
tail -f log.txt
```

常见用途：

- `tail -n 5`：看最后 5 行
- `tail -f`：持续观察日志追加内容

## 编辑相关操作

### >

作用：把输出写入文件，并覆盖原内容。

```bash
echo hello > a.txt
ls > files.txt
```

如果目标文件已经有内容，会被覆盖。

---

### >>

作用：把输出追加到文件末尾。

```bash
echo world >> a.txt
```
