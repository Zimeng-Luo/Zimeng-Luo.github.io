# Python 基础：数据模型与控制流

## Python 基础语法

### 1. 编码与标识符

**默认编码：**

Python 3 源码文件默认使用 **UTF-8** 编码，这意味着你可以直接在代码中使用中文作为变量名（虽然在实际开发中极其不推荐这样做）。

**标识符（命名规则）：**

- 由字母、数字、下划线 `_` 组成。
    
- **不能以数字开头**（如 `1var` 是错误的，`var1` 是正确的）。
    
- **严格区分大小写**（`Runoob` 和 `runoob` 是两个不同的变量）。
    
- 不能使用 Python 的保留字（关键字）。
    

**查看保留字：**

```python
import keyword
print(keyword.kwlist)
# 输出如: ['False', 'None', 'True', 'and', 'as', 'assert', 'break', 'class', 'continue', 'def', ...]
```

### 2. 注释与代码块（缩进）

这是 Python 区别于 C、Java 等语言最显著的特征。

**注释：**

- **单行注释**：使用井号 `#`。
    
- **多行注释**：使用三个单引号 `'''` 或三个双引号 `"""`。
    

```python
# 这是一个单行注释
print("Hello, World!") 

'''
这是多行注释
可以写很多行
'''
```

**缩进 (Indentation)：**

Python 不使用大括号 `{}` 来控制类、函数以及其他逻辑判断，而是**严格使用缩进**来写代码块。

- 缩进的空白数量是可变的，但**同一个代码块的语句必须包含相同的缩进空格数**（通常约定俗成为 **4 个空格**）。
    
- 如果缩进不一致，程序会直接报错 `IndentationError`。
    

```python
if True:
    print("True")  # 缩进 4 个空格
else:
    print("False") # 缩进 4 个空格
```

### 3. 多行语句

通常 Python 的一行就是一条语句。但如果语句很长，可以使用反斜杠 `\` 来实现多行语句。

```python
total = item_one + \
        item_two + \
        item_three
```

**例外情况**：在 `[]`, `{}`, 或 `()` 中的多行语句，不需要使用反斜杠 `\`。

```python
my_list = ['item_one', 'item_two', 
           'item_three', 'item_four']
```

### 4. 数据类型与字符串基础

Python 3 中有 6 个标准的数据类型（Number 数字、String 字符串、List 列表、Tuple 元组、Set 集合、Dictionary 字典）。这里重点提一下最常用的字符串语法：

- 单引号 `'` 和双引号 `"` 用法完全相同。
    
- 三引号 `'''` 或 `"""` 可以指定一个多行字符串。
    
- **转义符 `\`**：如 `\n` 代表换行。
    
- **自然字符串 (Raw String)**：在字符串前面加上 `r` 或 `R`，表示按原样输出，不发生转义。
    

```python
word = '字符串'
sentence = "这是一个句子。"
paragraph = """这是一个段落，
可以跨越多行。"""

print(r"这里的 \n 不会换行，会原样输出")
```

### 5. 基础输入与输出

**输出 `print()`：**

`print` 默认输出是换行的。如果想要实现不换行，需要在末尾加上 `end=""` 参数。

```python
print("Hello", end=" ")
print("World")
# 输出结果: Hello World
```

**输入 `input()`：**

执行到 `input()` 时，程序会暂停，等待用户在控制台输入文本，按下回车键后继续。**接收到的所有输入都会被当作字符串 (String) 处理**。

```python
user_name = input("请输入你的名字: ")
print("你好, " + user_name)
```

### 6. 导入模块 (Import)

在 Python 中，你需要导入其他文件或内置模块来使用它们的功能。

- **`import somemodule`**: 将整个模块导入。
    
- **`from somemodule import somefunction`**: 从某个模块中导入特定的函数或变量。
    
- **`from somemodule import *`**: 将某个模块中的所有函数导入（通常不推荐，容易造成命名空间污染）。
    

```python
# 导入整个 sys 模块
import sys
print(sys.path)

# 只导入 sys 模块中的 argv 变量
from sys import argv
print(argv)
```

## Python 控制语句

### 1. 条件控制 (if...elif...else)

Python 依靠条件语句的执行结果（`True` 或 `False`）来决定执行哪个代码块。与其他语言不同，Python 完全依赖**缩进**来划分代码块，而不是大括号。

#### 基础语法

```python
if condition_1:
    # 如果 condition_1 为 True，执行这里的代码
    statement_block_1
elif condition_2:
    # 如果 condition_1 为 False 且 condition_2 为 True，执行这里
    statement_block_2
else:
    # 如果以上所有条件都为 False，执行这里
    statement_block_3
```

**注意**：

1. 每个条件后面必须有冒号 `:`。
    
2. `elif` 是 `else if` 的缩写，可以有零个或多个 `elif`。
    
3. `else` 是可选的，最多只能有一个。
    

#### 代码示例

```python
age = int(input("请输入你家狗狗的年龄: "))

if age <= 0:
    print("你是在逗我吧！")
elif age == 1:
    print("相当于 14 岁的人类。")
elif age == 2:
    print("相当于 22 岁的人类。")
else:
    human_age = 22 + (age - 2) * 5
    print(f"对应人类年龄: {human_age} 岁。")
```

#### `match...case` (Python 3.10+)

如果你使用的是较新的 Python 版本，可以使用类似于其他语言中 `switch...case` 的语法进行模式匹配：

```python
status = 404
match status:
    case 400:
        print("Bad request")
    case 404:
        print("Not found")
    case _:  # 下划线表示通配符，相当于 default 或 else
        print("Something's wrong")
```

### 2. 循环语句 (while & for)

Python 提供了两种主要的循环结构：`while` 循环和 `for` 循环。

#### ① `while` 循环

只要条件为 `True`，`while` 循环就会一直执行内部的代码块。通常用于**事先不知道要循环多少次**的场景。

```python
n = 1
sum_val = 0

# 计算 1 到 100 的和
while n <= 100:
    sum_val += n
    n += 1

print(f"1 到 100 的和为: {sum_val}")
```

**死循环警告**：如果 `while` 的条件永远不变为 `False`（例如忘记更新计数器变量），程序将无限运行下去。可以通过 `Ctrl + C` 来强制中断。

#### ② `for` 循环

Python 的 `for` 循环非常强大，它主要用于**遍历任何序列项目**（如列表、字符串、元组或字典）。

```python
languages = ["C", "C++", "Perl", "Python"] 
for x in languages:
    print(x)
```

#### ③ `range()` 函数

如果你需要遍历一个数字序列，内置的 `range()` 函数非常方便。它可以生成数列。

- `range(5)`: 生成 `0, 1, 2, 3, 4`（不包含结束值 5）。
    
- `range(2, 6)`: 生成 `2, 3, 4, 5`。
    
- `range(0, 10, 3)`: 生成 `0, 3, 6, 9`（指定步长为 3）。
    

```python
for i in range(3):
    print(f"这是第 {i} 次循环")
```

### 3. 循环控制语句 (break, continue, pass)

在循环执行的过程中，有时我们需要强行改变循环的默认流程。

- **`break`**: **打破整个循环**。立即退出当前的 `for` 或 `while` 循环，不再执行循环体中剩余的代码。
    
- **`continue`**: **跳过本次循环**。停止执行当前这一次循环中剩余的代码，直接进入下一次循环条件的判断。
    
- **`pass`**: **占位符**。它什么也不做，通常用于保证语法的完整性（当你还没想好这里写什么代码，但不写又会报错时使用）。
    

#### `break` 与 `continue` 对比示例

```python
print("--- 测试 break ---")
for letter in 'Python':
    if letter == 'h':
        break  # 遇到 'h' 直接结束整个循环
    print(f"当前字母: {letter}")
# 输出: P, y, t

print("\n--- 测试 continue ---")
for letter in 'Python':
    if letter == 'h':
        continue # 遇到 'h' 跳过这一次，继续下一个字母
    print(f"当前字母: {letter}")
# 输出: P, y, t, o, n
```

---

### 4. 循环中的 `else` 语句

这是 Python 语言中一个相对独特且很多人容易误解的语法：`for...else` 和 `while...else`。

- **触发机制**：只有当循环**正常执行完毕**（即没有被 `break` 强行中断）时，`else` 块里面的代码才会被执行。
    
- **应用场景**：常用于搜索操作。如果在循环里找到了目标（触发 `break`），就不执行 `else`；如果整个循环跑完了都没找到，就执行 `else`。
    

```python
# 寻找质数的经典示例
for num in range(10, 20):  # 迭代 10 到 19
    for i in range(2, num): # 根据因子迭代
        if num % i == 0:    # 确定第一个因子
            j = num / i     # 计算第二个因子
            print(f"{num} 等于 {i} * {j}")
            break # 找到了因子，不是质数，打断内层循环
    else: 
        # 内层循环正常跑完（没有触发 break），说明没找到因子
        print(f"{num} 是一个质数")
```

## Python 数据类型

### 1. 六大标准数据类型概览

Python3 中有 6 个标准的数据类型，它们按照**是否可变（Mutable）**被划分为两大类：

- **不可变数据 (Immutable)**：一旦创建，内存中的值不能被修改。
    
    - **Number (数字)**
        
    - **String (字符串)**
        
    - **Tuple (元组)**
        
- **可变数据 (Mutable)**：内存中的值可以被修改。
    
    - **List (列表)**
        
    - **Dictionary (字典)**
        
    - **Set (集合)**
        

**技巧**：你可以使用内建函数 `type(var)` 来查看变量的类型，或者使用 `isinstance(var, type)` 来判断变量是否属于某个特定的类型。

### 2. 基础数据类型详解

#### 2.1 Number (数字)

Python3 支持四种不同的数值类型：

- **`int` (整型)**：Python3 中只有长整型，没有 Python2 中的 `Long`。可以表示任意大小的整数。
    
- **`float` (浮点型)**：带有小数部分的数字。
    
- **`bool` (布尔型)**：`True` 和 `False`。在 Python3 中，布尔值其实是整型的子类，`True` 相当于 `1`，`False` 相当于 `0`，它们甚至可以进行数学运算。
    
- **`complex` (复数)**：如 `1 + 2j`，由实数部分和虚数部分构成。
    

#### 2.2 String (字符串)

字符串由单引号 `'` 或双引号 `"` 括起来。

- **截取 (切片)**：语法为 `变量[头下标:尾下标:步长]`。正向索引从 `0` 开始，反向索引从 `-1` 开始。
    
- **运算**：加号 `+` 用于字符串拼接，星号 `*` 用于字符串重复。
    

```python
word = 'Python'
print(word[0:2])  # 输出: Py (截取索引0到2，不包含2)
print(word[-1])   # 输出: n (获取最后一个字符)
print(word * 2)   # 输出: PythonPython
```

#### 2.3 List (列表)

列表是 Python 中使用最频繁的数据类型。它写在方括号 `[]` 之间，元素可以是不同的数据类型（甚至可以嵌套列表）。

- 列表完全支持像字符串那样的切片操作。
    
- 列表是**可变的**，可以通过索引直接修改元素。
    

```python
my_list = [1, 'hello', 3.14, True]
my_list[0] = 100  # 修改第一个元素
print(my_list)    # 输出: [100, 'hello', 3.14, True]
```

#### 2.4 Tuple (元组)

元组写在小括号 `()` 里，元素用逗号隔开。它和列表非常相似，但**元组的元素不能修改**。

- 主要用于保护数据不被意外更改，或者作为字典的键。
    
- **注意**：构造包含 1 个元素的元组时，必须加逗号，否则会被当作普通的括号运算符。例如 `tup = (50,)`。
    

#### 2.5 Set (集合)

集合是由一个或数个形态各异的大小整体组成的，构成集合的事物或对象称作元素。它使用大括号 `{}` 或 `set()` 函数创建。

- **特点**：集合中的元素是**无序**且**不重复**的（自带去重功能）。
    
- **注意**：创建一个空集合必须用 `set()` 而不是 `{}`，因为 `{}` 是用来创建空字典的。
    
- 支持集合的数学运算，如差集 `-`，并集 `|`，交集 `&`，对称差集 `^`。
    

```python
a = set('abracadabra') # 自动去重
print(a) # 输出可能为: {'a', 'r', 'b', 'c', 'd'} (每次顺序可能不同)
```

#### 2.6 Dictionary (字典)

字典是无序的 **键(key) : 值(value)** 集合。写在大括号 `{}` 里。

- **键 (key)**：必须是唯一的，且必须是**不可变类型**（如字符串、数字或元组）。
    
- **值 (value)**：可以是任意数据类型。
    
- 字典是通过键来存取数据的，而不是通过偏移量（索引）。
    

```python
my_dict = {'name': 'Alice', 'age': 25}
print(my_dict['name']) # 输出: Alice
```

### 3. 数据类型转换

在实际编程中，我们经常需要将数据从一种类型转换为另一种类型。类型转换分为**隐式类型转换**和**显式类型转换**。

#### 3.1 隐式类型转换 (自动转换)

在进行数学运算时，Python 会自动将低精度类型转换为高精度类型以避免数据丢失。

```python
num_int = 123
num_float = 1.23
# 整数和浮点数相加，Python会自动将整数123转为浮点数123.0
result = num_int + num_float 
print(type(result)) # 输出: <class 'float'>
```

#### 3.2 显式类型转换 (强制转换)

这是我们在写代码时最常用的方式，通过调用内置的转换函数来实现：

- **`int(x)`**: 将 x 转换为一个整数。如果是浮点数，会**直接丢弃**小数部分。如果是纯数字字符串可以转换，但包含字母或小数点的字符串（如 `"12.3"`）直接用 `int()` 会报错。
    
- **`float(x)`**: 将 x 转换为一个浮点数。
    
- **`str(x)`**: 将对象 x 转换为字符串表示。
    
- **`list(x)`**: 将序列 x（如字符串、元组、集合）转换为一个列表。
    
- **`tuple(x)`**: 将序列 x 转换为一个元组。
    
- **`set(x)`**: 将序列 x 转换为一个集合（同时达到去重的效果）。
    
- **`dict(d)`**: 创建一个字典，d 必须是一个包含 `(key, value)` 元组的序列。
    

```python
# 字符串转整数
s = "100"
n = int(s)

# 列表去重的小技巧 (列表 -> 集合 -> 列表)
raw_list = [1, 2, 2, 3, 3, 3]
unique_list = list(set(raw_list)) 
print(unique_list) # 输出: [1, 2, 3]
```

## Python 数据类型常用操作

### 1. 数字 (Number) 高阶操作

除了基本的加减乘除，Python 提供了强大的数学和随机数处理模块。在使用高级数学函数前，通常需要导入 `math` 或 `random` 模块。

**常用数学函数 (`import math`)：**
* `abs(x)`: 返回数字的绝对值（内置函数，不需要导包）。
* `round(x, n)`: 返回浮点数 x 的四舍五入值，保留 n 位小数（内置函数）。
* `math.ceil(x)`: 向上取整，如 `math.ceil(4.1)` 返回 `5`。
* `math.floor(x)`: 向下取整，如 `math.floor(4.9)` 返回 `4`。

**常用随机数函数 (`import random`)：**
* `random.random()`: 随机生成下一个实数，范围在 `[0, 1)` 之间。
* `random.randint(a, b)`: 生成一个指定范围 `[a, b]` 内的整数。
* `random.choice(seq)`: 从序列（列表、元组、字符串）中随机挑选一个元素。
* `random.shuffle(lst)`: 将列表的所有元素随机打乱。

### 2. 字符串 (String) 核心方法

字符串是不可变的，因此所有的字符串修改方法**都会返回一个新字符串**，而不会改变原字符串。

**字符串格式化 (强烈推荐 f-string)：**
Python 3.6+ 引入了极简的 f-string 格式化方法，在字符串前加 `f`，即可直接在大括号 `{}` 中放入变量名或表达式。
```python
name = "Alice"
age = 20
print(f"我的名字是 {name}，明年 {age + 1} 岁。") 
```

**极其高频的内置方法：**
* `str.split(sep)`: 将字符串以 `sep` 为分隔符拆分成**列表**。
* `str.join(seq)`: 将序列（如列表）中的元素以指定的字符连接生成一个新的**字符串**。
* `str.strip(chars)`: 去除字符串头尾指定的字符（默认为空格或换行符）。
* `str.replace(old, new)`: 将字符串中的 `old` 替换成 `new`。
* `str.upper()` / `str.lower()`: 全部转换为大写 / 小写。
* `str.find(sub)`: 查找子串，找到返回起始索引，找不到返回 `-1`。

```python
# join 和 split 是黄金搭档
words = ["I", "love", "Python"]
sentence = " ".join(words)  # 输出: "I love Python"
print(sentence.split(" "))  # 输出: ['I', 'love', 'Python']
```

### 3. 列表 (List) 核心方法

列表是可变的，以下方法通常会**直接在原列表上进行修改**（就地修改），不会返回新列表（返回 `None`）。

**增删改查：**
* **增**:
    * `list.append(obj)`: 在列表末尾添加新的**一个**对象。
    * `list.extend(seq)`: 在列表末尾一次性追加另一个序列中的**多个**值。
    * `list.insert(index, obj)`: 将对象插入到指定索引位置。
* **删**:
    * `list.pop([index])`: 移除列表中的一个元素（默认最后一个元素），并且**返回该元素的值**。
    * `list.remove(obj)`: 移除列表中某个值的**第一个**匹配项。
    * `del list[index]`: 使用 `del` 语句通过索引删除。
* **排序与翻转**:
    * `list.sort(reverse=False)`: 对原列表进行升序排序（设为 True 为降序）。
    * `list.reverse()`: 反向列表中元素。

### 4. 元组 (Tuple) 进阶特性

元组的核心特性就是**不可变**，因此它没有 `append`、`remove` 等修改方法。它的常用操作通常仅限于：
* `len(tup)`: 计算元组元素个数。
* `max(tup)` / `min(tup)`: 返回元组中元素最大/最小值。

**⚠️ 经典陷阱：元组中的可变对象**
虽然元组本身不可变，但如果元组的某个元素是**可变对象**（如列表），那么该可变对象内部的内容是可以被修改的！
```python
tup = (1, 2, [3, 4])
# tup[0] = 100  # 这会报错，因为元组的元素指向不能变
tup[2].append(5) # 这是合法的！改变的是列表内部
print(tup)       # 输出: (1, 2, [3, 4, 5])
```

集合（Set）的主要应用场景是**去重**和**关系测试**（数学里的交、并、差集）。

**修改集合：**
* `set.add(elm)`: 为集合添加**一个**元素（已存在则不进行任何操作）。
* `set.update(set2)`: 添加**多个**元素（可以是列表、元组、字典等）。
* `set.remove(elm)`: 移除元素，如果元素不存在会**报错 (KeyError)**。
* `set.discard(elm)`: 移除元素，如果元素不存在**不会报错**（比 remove 更安全）。

**数学集合运算：**
```python
set_A = {1, 2, 3, 4}
set_B = {3, 4, 5, 6}

print(set_A - set_B) # 差集: {1, 2} (在A中但不在B中)
print(set_A | set_B) # 并集: {1, 2, 3, 4, 5, 6} (包含A和B的所有元素)
print(set_A & set_B) # 交集: {3, 4} (同时在A和B中的元素)
print(set_A ^ set_B) # 对称差集: {1, 2, 5, 6} (不同时在A和B中的元素)
```

## Python 注释与运算

### 1. 注释 (Comments)

注释是写给程序员看的，Python 解释器在执行代码时会完全忽略它们。合理使用注释可以极大地提高代码的可读性。

#### 单行注释

使用井号 `#`。可以将注释放在代码的上方，也可以放在代码的正后方。

```python
# 这是一个单行注释，解释接下来的代码用途
print("Hello")  # 这也是注释，通常用于解释当前行的逻辑
```

#### 多行注释

使用三个单引号 `'''` 或三个双引号 `"""`。虽然它们本质上是未赋值的字符串常量，但在实际开发中常被用作多行注释，特别是在编写函数或类的说明文档（Docstring）时。

```python
"""
这是一个多行注释的示例。
你可以在这里写很长的说明，
比如算法的思路、参数的定义等。
"""
```

### 2. 运算符 (Operators)

Python 支持极其丰富的运算符，以下按照功能进行了分类梳理。

#### ① 算术运算符

用于执行基本的数学运算。

|**运算符**|**描述**|**实例**|
|---|---|---|
|`+`|加|`10 + 20` 输出 `30`|
|`-`|减|`10 - 20` 输出 `-10`|
|`*`|乘|`10 * 20` 输出 `200`|
|`/`|除 (**总是返回浮点数**)|`10 / 2` 输出 `5.0`|
|`%`|取模 (返回除法的余数)|`10 % 3` 输出 `1`|
|`**`|幂运算|`2 ** 3` 输出 `8`|
|`//`|取整除 (向下取整)|`10 // 3` 输出 `3`|

#### ② 比较 (关系) 运算符

用于比较两个值，返回的结果一定是布尔值 (`True` 或 `False`)。

|**运算符**|**描述**|**实例 (假设 a=10, b=20)**|
|---|---|---|
|`==`|等于 (比较**值**是否相等)|`a == b` 返回 `False`|
|`!=`|不等于|`a != b` 返回 `True`|
|`>`|大于|`a > b` 返回 `False`|
|`<`|小于|`a < b` 返回 `True`|
|`>=`|大于等于|`a >= 10` 返回 `True`|
|`<=`|小于等于|`b <= 10` 返回 `False`|

#### ③ 赋值运算符

用于给变量赋值，最基本的是等号 `=`。

- **复合赋值**：将算术运算与赋值结合。例如 `a += 2` 等价于 `a = a + 2`。同理还有 `-=`, `*=`, `/=`, `%=`, `**=`, `//=`.
    
- **海象运算符 `:=`** (Python 3.8+ 新增)：允许在表达式内部为变量赋值。
    
    ```python
    # 传统写法
    n = len(a)
    if n > 10:
        print(f"太长了，共有 {n} 个元素")
    
    # 使用海象运算符 (让代码更紧凑)
    if (n := len(a)) > 10:
        print(f"太长了，共有 {n} 个元素")
    ```
    

#### ④ 逻辑运算符

用于组合多个条件判断语句。

|**运算符**|**逻辑**|**描述**|
|---|---|---|
|`and`|与|只有两个条件**都为** `True` 时，结果才为 `True`。（具有**短路**特性：如果第一个条件为 False，直接返回 False，不再计算第二个条件）|
|`or`|或|只要有一个条件为 `True`，结果就为 `True`。（短路特性：如果第一个条件为 True，直接返回 True）|
|`not`|非|逻辑反转。如果条件为 True，返回 `False`。|

#### ⑤ 成员运算符

Python 独有的优雅语法，用于测试一个元素是否包含在序列（如字符串、列表、元组或字典的键）中。

- **`in`**: 如果在指定的序列中找到值，返回 `True`。
    
- **`not in`**: 如果没有在指定的序列中找到值，返回 `True`。
    
    ```python
    my_list = [1, 2, 3]
    print(2 in my_list)      # 输出: True
    print(5 not in my_list)  # 输出: True
    ```
    

#### ⑥ 身份运算符

用于比较两个对象的**内存地址**（即判断它们是不是同一个对象）。

- **`is`**: 判断两个标识符是不是引用自同一个对象。
    
- **`is not`**: 判断两个标识符是不是引用自不同的对象。
    

**核心易错点：`is` 和 `==` 的区别！**

- `==` 比较的是两个变量的**值**是否相等。
    
- `is` 比较的是两个变量的**内存地址** (id) 是否相同。
    

```python
a = [1, 2, 3]
b = a[:] # 切片会复制出一个新列表

print(a == b) # True (它们里面的值一模一样)
print(a is b) # False (它们在内存中是两个不同的列表)
```
