# Python 基础：数据模型与控制流

Python 变量绑定到对象，类型属于对象本身。理解“绑定了谁、修改了什么”，比逐条背下所有语法更有用。本文以 Python 3.10 及以上的常见写法为例。

## 语法先保持清晰

代码块以冒号开始，用一致缩进组织，通常使用四个空格。`#` 是注释；三引号产生多行字符串，放在模块、类或函数开头时可作为文档字符串，并不是专门的注释语法。

```python
scores = [62, 90, 48]
passed = []
for score in scores:
    if score >= 60:
        passed.append(score)
print(f"及格人数：{len(passed)}")
```

Python 3 源码默认支持 UTF-8。命名区分大小写，不使用关键字；长表达式优先放进括号跨行，减少反斜杠续行。

## 按任务选择数据类型

| 需求 | 常用对象 | 特性 |
| --- | --- | --- |
| 数值计算 | `int / float / complex` | 整数可任意精度，浮点有舍入误差 |
| 条件状态 | `bool` | 只有 `True` 和 `False`，是 int 的子类 |
| 文本 | `str` | 不可变字符序列 |
| 顺序记录 | `list` | 可变序列 |
| 固定结构记录 | `tuple` | 元素绑定不可变 |
| 唯一元素与集合运算 | `set` | 不重复，不保证遍历顺序 |
| 按键查找 | `dict` | 保持插入顺序 |

这只是常用类型，不是 Python 全部类型的封闭清单。字典键和集合元素必须可哈希，不是简单地“不可变就都可以”；包含列表的元组也不可哈希。

```python
record = {"name": "Alice", "scores": [80, 90]}
record["scores"].append(95)
unique = list(dict.fromkeys([3, 1, 3, 2]))  # 保持首次出现顺序
```

字符串的 `split`、`join`、`strip`、`replace` 返回结果而不原地改写字符串。列表 `append` 加一个对象，`extend` 加一组元素，`sort` 原地排序并返回 `None`，`sorted` 则生成新列表；`pop` 会返回移除的元素。

## 可变性与复制

```python
a = [[1], [2]]
b = a.copy()
b[0].append(3)
print(a)                 # [[1, 3], [2]]
```

浅拷贝只复制外层容器，里面的对象仍共享。元组不可重新绑定其中的元素，但其中包含的列表仍可变。需要完全独立的嵌套结构时，可考虑深拷贝，同时理解复制成本。

`==` 比较值，`is` 比较对象身份；判断空值使用 `value is None`，不要依赖小整数或字符串缓存来比较值。

## 运算要关注实际返回值

`/` 对普通整数执行浮点除法，`//` 向下取整，`int()` 对浮点向零截断：`-5 // 2` 为 `-3`，`int(-2.5)` 为 `-2`。浮点与大整数混合也可能损失精度，并非自动转换总能避免信息损失。

`and` 与 `or` 短路并返回操作数，而不总返回布尔值，例如 `[] or [1]` 返回 `[1]`。`in` 判断成员，字典中默认判断键。集合的 `&`、`|`、`-`、`^` 分别用于交、并、差、对称差。

## 条件与循环

| 场景 | 写法 |
| --- | --- |
| 普通分支 | `if / elif / else` |
| 遍历可迭代对象 | `for` |
| 条件控制重复 | `while` |
| 结构模式匹配 | `match / case`，Python 3.10+ |

`range` 的终点不包含在内；切片也通常是左闭右开。`break` 退出当前循环，`continue` 跳过本轮剩余部分，`pass` 只是占位。

```python
for item in [1, 3, 5]:
    if item == 4:
        print("找到")
        break
else:
    print("没有找到")
```

循环的 `else` 在没有通过 `break` 中断的正常结束时执行，也包括循环一次都没进入的情况。若异常或 `return` 使流程离开，自然不会继续执行这个 `else`。
