# 强化学习数学原理（三）：函数近似、策略梯度与 Actor-Critic

[上一篇](./强化学习数学原理二.md)用表格保存价值。面对图像、高维状态或连续空间，需要用参数化函数共享信息；面对连续动作，还可以直接学习策略。本篇围绕“用什么模型、怎样构造学习信号”连接这两条路线。

## 价值函数近似：共享参数带来泛化

用 `v̂(s,w)` 或 `q̂(s,a,w)` 代替价值表。线性模型可以写成 `v̂(s,w)=φ(s)ᵀw`，神经网络则学习更复杂的表示。更新一个状态会通过共享参数影响其他状态，既带来泛化，也可能相互干扰。

给定状态权重 `d(s)`，理想的均方价值误差为：

```text
J(w) = ½ Σₛ d(s)[vπ(s) − v̂(s,w)]²
```

权重表达“哪些状态更值得拟合”。在持续任务中可选平稳分布，在回合或折扣任务中也可选相应的访问分布；不能把所有目标都解释为同一个平稳分布。

真实价值未知，可以用 MC 回报或 TD 目标代替。TD 半梯度更新为：

```text
δ = r + γv̂(s′,w) − v̂(s,w)
w ← w + αδ ∇w v̂(s,w)
```

“半梯度”表示更新时把目标视为常数，不对目标中的下一状态估值求导。它不是简单地对理想均方价值误差做精确 SGD；函数近似、异策学习、自举共同出现时尤其可能不稳定。

## DQN：稳定一个持续变化的目标

DQN 用神经网络近似动作价值，经典形式适合有限离散动作。它引入经验回放和目标网络：

```text
y = r + γ(1 − done) maxₐ′ q̂(s′,a′,w⁻)
L(w) = ½[y − q̂(s,a,w)]²
```

经验池随机抽取小批量，减弱相邻转移的相关性并复用经验；旧参数 `w⁻` 提供相对稳定的目标，定期或缓慢同步。两者改善稳定性，却不是“神经网络一定收敛”的证明。

这里的 `done` 表示真正的任务终止。仅因采样时间上限而截断轨迹时，是否自举要看任务定义，不能一律把后继价值置零。

## 策略梯度：直接优化动作分布

策略 `πθ(a ∣ s)` 输出动作概率或概率密度。确定优化目标后，才能正确理解梯度中的状态分布。以固定初始分布下的折扣回报为目标：

```text
J(θ) = Eπθ[Σₜ₌₀∞ γᵗRₜ₊₁]
dγ(s) = (1 − γ)Σₜ₌₀∞ γᵗPrπθ(Sₜ=s)
∇θJ = 1/(1 − γ) Eₛ∼dγ,ₐ∼πθ[qπθ(s,a)∇θlog πθ(a ∣ s)]
```

状态访问分布随策略变化，但策略梯度定理让梯度写成价值与对数概率梯度的乘积。式中的常数可在固定折扣时吸收入步长；平均奖励目标有另一套分布与价值定义，不能直接混用。

直观上，回报高的动作得到较大的正向权重。连续动作通常用高斯分布等策略表示，避免每一步枚举连续动作空间中的最大 Q 值。

## REINFORCE 与基线

REINFORCE 用回合回报 `Gₜ` 估计动作价值。与上述起点折扣目标一致的回合梯度估计为：

```text
ĝ = Σₜ γᵗGₜ ∇θlog πθ(Aₜ ∣ Sₜ)
θ ← θ + αĝ
```

完整回报无需自举，通常方差较大。加入不依赖当前动作的状态基线 `b(s)`：

```text
ĝ = Σₜ γᵗ[Gₜ − b(Sₜ)] ∇θlog πθ(Aₜ ∣ Sₜ)
```

基线不改变期望梯度，因为固定状态下 `Σₐπθ(a ∣ s)∇θlog πθ(a ∣ s)=0`。合适的基线可以降低方差，任意基线却不保证都有效。实现 Actor 更新时应把该权重当成常数，避免意外对基线反向传播。

## Actor-Critic：让评价网络提供信号

Actor 学习策略参数 `θ`，Critic 学习价值参数 `w`。Q-AC 可以用 `q̂(s,a,w)` 作为策略梯度权重；更常见的状态价值 Critic 使用优势：

```text
Aπ(s,a) = qπ(s,a) − vπ(s)
δₜ = rₜ₊₁ + γv̂(sₜ₊₁,w) − v̂(sₜ,w)
w ← w + αw δₜ ∇w v̂(sₜ,w)
```

Actor 用 `δₜ` 或多步优势估计替代前一节的回报权重。若对应折扣起点目标，采样与时间权重也需与该目标一致。共享网络时，价值损失和策略损失可以一起训练，但 Actor 的优势权重通常要停止梯度。

准确价值函数满足：

```text
E[δₜ ∣ sₜ=s, aₜ=a] = Aπ(s,a)    （v̂ = vπ 时）
```

近似 Critic 一般会引入偏差。Actor-Critic 的取舍正是：以一定近似偏差换取更及时、通常更低方差的更新。Critic 更新得更快是常见调参思路，不是普遍必需的学习率大小关系。

## 如何选择这几类方法？

| 场景 | 可优先理解的路线 | 主要关注 |
| --- | --- | --- |
| 小型离散问题 | 表格 TD / Q-learning | 探索覆盖和步长 |
| 高维状态、离散动作 | DQN | 回放分布与目标网络 |
| 需要直接学习随机策略 | REINFORCE | 回报方差和基线 |
| 连续动作或及时更新 | Actor-Critic | Critic 偏差与训练稳定性 |

PPO、SAC、DDPG 等在这些思想上加入不同机制，不能仅凭“都有两个网络”就认为算法等价。本系列保留从 MDP 到策略优化的基础推导，不把未展开的现代算法名称当成完整教程。
