# 强化学习数学原理（三）：函数近似、策略梯度与 Actor-Critic

## L8 值函数近似

### 1. 课程动机：从表格表示到函数表示

在之前的课程（如蒙特卡洛、TD学习）中，状态/动作价值均采用**表格（Tabular）**形式进行存储和更新。

- **表格方法的局限性**：
    
    - **存储瓶颈**：当状态空间或动作空间极大，甚至是连续空间时，表格无法存储所有价值（维度灾难）。
        
    - **泛化能力差（Lack of Generalization）**：表格中每个状态的价值是独立更新的。未被访问过的状态，其价值无法得到更新。
        
- **函数近似方法（Function Approximation）**：
    
    - **核心思想**：引入一个参数化的函数 $\hat{v}(s, w)$ 或 $\hat{q}(s, a, w)$ 来近似真实的价值函数，其中 $w$ 是参数向量（例如神经网络的权重）。
        
    - **优势**：极大地节省了存储空间；具备**泛化能力**，一旦参数 $w$ 通过部分访问过的状态得到更新，未访问过状态的价值也会自动更新。
        

---

### 2. 状态价值近似的目标函数 (Objective Function)

为了找到最优的参数 $w$ 使得 $\hat{v}(s, w)$ 最接近真实的策略状态价值 $v_\pi(s)$，我们需要定义一个目标函数。

#### 2.1 均方价值误差 (Mean Squared Value Error, MSVE)

目标函数定义为估计值与真实值差值的均方期望：

$$J(w) = \frac{1}{2} \mathbb{E}_{S \sim d_\pi} \left[ (v_\pi(S) - \hat{v}(S, w))^2 \right]$$

- **随机变量 $S$ 的分布**：期望是对状态 $S$ 求的，其概率分布为 $d_\pi(s)$。这是策略 $\pi$ 下马尔可夫链的**平稳分布（Stationary Distribution）**。
    
- **含义**：它表示在长期运行中，智能体处于各个状态的概率。这意味着我们更关心那些经常被访问的状态的近似精度。
    

---

### 3. 状态价值的参数更新 (State Value Approximation)

优化的目标是寻找 $w$ 最小化 $J(w)$。这可以结合前两讲学到的**随机梯度下降（SGD）**来实现。

#### 3.1 理想的随机梯度下降

计算 $J(w)$ 对 $w$ 的梯度：

$$\nabla_w J(w) = -\mathbb{E} \left[ (v_\pi(S) - \hat{v}(S, w)) \nabla_w \hat{v}(S, w) \right]$$

采用 SGD 更新参数 $w$：

$$w_{t+1} = w_t + \alpha \left[ v_\pi(s_t) - \hat{v}(s_t, w_t) \right] \nabla_w \hat{v}(s_t, w_t)$$

- **痛点**：在实际中，我们根本**不知道真实的 $v_\pi(s_t)$**，因此上述理想公式无法直接使用。
    

#### 3.2 结合 TD 学习的近似更新

为了解决不知道真实价值的问题，我们使用 **TD 目标（TD Target）** 来替代 $v_\pi(s_t)$：

- **TD 目标**：$\bar{v}_t = r_{t+1} + \gamma \hat{v}(s_{t+1}, w_t)$
    
    将 TD 目标代入更新公式，得到**带函数近似的 TD 算法**：
    
    $$w_{t+1} = w_t + \alpha \big[ r_{t+1} + \gamma \hat{v}(s_{t+1}, w_t) - \hat{v}(s_t, w_t) \big] \nabla_w \hat{v}(s_t, w_t)$$
    
- **TD 误差 $\delta_t$**：中间的括号项即为 TD 误差。
    

---

### 4. 动作价值的函数近似 (Action Value Approximation)

类似于状态价值，我们可以用 $\hat{q}(s, a, w)$ 近似动作价值 $q_\pi(s, a)$，从而进行策略改进并寻找最优策略。

#### 4.1 Sarsa 与价值函数近似 (On-policy)

将函数近似应用于 Sarsa，更新公式变为：

$$w_{t+1} = w_t + \alpha \big[ r_{t+1} + \gamma \hat{q}(s_{t+1}, a_{t+1}, w_t) - \hat{q}(s_t, a_t, w_t) \big] \nabla_w \hat{q}(s_t, a_t, w_t)$$

- **数据需求**：需要完整的 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ 经验序列。
    

#### 4.2 Q-learning 与价值函数近似 (Off-policy)

将函数近似应用于 Q-learning，利用贝尔曼最优方程的思想，TD 目标取动作空间的最大值：

$$w_{t+1} = w_t + \alpha \big[ r_{t+1} + \gamma \max_{a'} \hat{q}(s_{t+1}, a', w_t) - \hat{q}(s_t, a_t, w_t) \big] \nabla_w \hat{q}(s_t, a_t, w_t)$$

- **数据需求**：只需 $(s_t, a_t, r_{t+1}, s_{t+1})$ 即可更新。
    

---

### 5. 深度强化学习的基石：DQN (Deep Q-Network)

当用**深度神经网络（DNN）作为函数近似器时，直接使用上述 Q-learning 更新会导致训练极不稳定甚至发散。经典算法 **DQN** 引入了两个关键技术来解决这一问题：

1. **经验回放 (Experience Replay)**：
    
    - 将智能体收集到的经验样本 $(s, a, r, s')$ 存入经验池（Replay Buffer）。
        
    - 训练时从中**随机小批量（Mini-batch）采样**进行更新。这打破了序列样本间的高时间相关性，使数据分布更接近独立同分布（i.i.d）。
        
2. **目标网络 (Target Network)**：
    
    - 在计算 TD 目标 $r + \gamma \max \hat{q}(s', a', w^-)$ 时，使用一个独立的旧参数网络 $w^-$（目标网络）。
        
    - $w^-$ 定期从正在训练的主网络 $w$ 同步。这避免了“追逐移动靶”的问题，大幅提升了学习的稳定性。
        

---

### 6. 总结 (Summary)

- **方法跨越**：价值函数近似使得强化学习从离散、小规模的问题，跨越到了能够处理高维状态空间（如自动驾驶图像输入、围棋棋盘）的现代深度强化学习（Deep RL）领域。

**数学连贯性**：

- **SGD (第6讲)** 提供了参数更新的优化框架。
    
- **TD 学习 (第7讲)** 提供了逼近真实价值的数据目标。
    
- **函数近似 (第8讲)** 将两者结合，形成了能在复杂环境中实际部署的核心算法（如 DQN）。

## L9 策略梯度方法

### 1. 课程动机：从基于价值到基于策略

在前面的课程（如 Sarsa、Q-learning）中，我们学习的都是**基于价值（Value-based）**的方法：先求解出最优价值函数，然后通过 $\max_a$ 操作导出最优策略。

- **价值方法的局限性**：
    
    - 难以处理**连续动作空间**（在连续空间中求全局最大值计算量极大）。
        
    - 通常只能学到确定性策略。
        
- **策略梯度方法（Policy-based）**：
    
    - **核心思想**：绕过价值函数，直接使用一个参数化的函数（如神经网络）来表示策略 $\pi(a|s, \theta)$，其中 $\theta$ 是需要优化的参数。
        
    - **优势**：能够自然地处理高维或连续的动作空间，并且可以学习到**随机策略（Stochastic Policy）**，这在某些部分可观测环境（POMDP）中至关重要。
        

---

### 2. 目标函数 (Objective Function)

要优化策略参数 $\theta$，我们首先需要一个数学指标来衡量当前策略 $\pi_\theta$ 的好坏。常用的目标函数有两种：

1. **平均状态价值 (Average State Value)**：
    
    $$J(\theta) = \sum_{s} d_0(s) v_{\pi_\theta}(s)$$
    
    - 其中 $d_0(s)$ 是初始状态的概率分布。该指标衡量的是从初始状态出发，长期能够获得的预期价值。
        
2. **平均单步奖励 (Average Reward)**：
    
    $$\bar{r}(\pi_\theta) = \sum_{s} d_{\pi_\theta}(s) \sum_{a} \pi_\theta(a|s) r(s,a)$$
    
    - 适用于没有明确起点的持续性任务。
        

**优化目标**：寻找使 $J(\theta)$ 最大的参数 $\theta$。这可以通过**梯度上升法（Gradient Ascent）**实现：

$$\theta_{t+1} = \theta_t + \alpha \nabla_\theta J(\theta_t)$$

---

### 3. 策略梯度定理 (Policy Gradient Theorem)

由于价值函数 $v_{\pi_\theta}(s)$ 的计算本身也依赖于 $\theta$，直接对 $J(\theta)$ 求导非常困难。**策略梯度定理**解决了这个数学难题，它给出了目标函数梯度的解析期望形式：

$$\nabla_\theta J(\theta) = \mathbb{E}_{S \sim d_{\pi_\theta}, A \sim \pi_\theta} \left[ q_{\pi_\theta}(S,A) \nabla_\theta \ln \pi_\theta(A|S) \right]$$

- **物理直觉理解**：
    
    - $q_{\pi_\theta}(S,A)$ 代表某个动作带来的长期回报好坏。
        
    - 梯度更新的方向会使得高回报动作的概率 $\pi_\theta(A|S)$ 增加，低回报动作的概率减小。
        
    - $\nabla_\theta \ln \pi_\theta(A|S)$ 是对数梯度（也叫 Score Function），它起到归一化作用，防止高频但低回报的动作主导梯度方向。
        

---

### 4. REINFORCE 算法 (蒙特卡洛策略梯度)

因为策略梯度公式里包含期望 $\mathbb{E}$，现实中无法遍历所有状态和动作，因此我们需要用**采样**来近似这个期望。

REINFORCE 算法使用**蒙特卡洛采样（Monte Carlo）**：

- 智能体在环境中运行完整的一个回合（Episode），得到一条轨迹数据。
    
- 使用真实的回报 $G_t$（Discounted Return）来无偏估计未知的动作价值 $q_{\pi_\theta}(s_t, a_t)$。
    
- **参数更新公式**：
    
    $$\theta_{t+1} = \theta_t + \alpha G_t \nabla_\theta \ln \pi_\theta(a_t|s_t)$$
    

**算法痛点**：REINFORCE 必须等待回合结束才能更新，且由于 $G_t$ 是整条轨迹奖励的累加，随机性极高，导致**梯度估计的方差（Variance）非常大**，训练过程很不稳定。

---

### 5. 带基线的 REINFORCE (REINFORCE with Baseline)

为了解决 REINFORCE 方差过大的问题，数学上可以引入一个**基线函数（Baseline）$b(S)$**。

- **数学原理**：可以证明，在策略梯度公式中减去一个仅与状态有关（与动作无关）的基线 $b(S)$，**不会改变期望的值（即无偏差）**，但可以大幅降低方差。
    
    $$\nabla_\theta J(\theta) = \mathbb{E} \left[ (q_{\pi_\theta}(S,A) - b(S)) \nabla_\theta \ln \pi_\theta(A|S) \right]$$
    
- **通常的选择**：最常用的基线是状态的**价值函数 $v_w(S)$**（由另一个参数 $w$ 近似）。
    
- **改进后的更新公式**：
    
    $$\theta_{t+1} = \theta_t + \alpha (G_t - v_w(s_t)) \nabla_\theta \ln \pi_\theta(a_t|s_t)$$
    
    - 这里 $(G_t - v_w(s_t))$ 实际上表示的是一种**优势（Advantage）**：当前动作 $a_t$ 的回报比平均预期回报好多少。
        

---

### 6. 总结 (Summary)

- **地位**：策略梯度直接优化策略网络参数，是当代深度强化学习（如 PPO, TRPO, DDPG）最核心的理论基石。
    
- **演进**：从普通的 REINFORCE 演进到带基线的 REINFORCE，其核心目的是通过数学技巧在不引入偏差的前提下**降低训练方差**。
    
- **启下**：带基线的 REINFORCE 已经包含了两种网络：一个是策略网络 $\theta$（决定动作），另一个是基线价值网络 $w$（评价状态）。这正是下一讲**演员-评论家（Actor-Critic）算法**的雏形。

## L10 Actor-Critic 方法

### 1. 课程动机：结合价值与策略的优势

在前面的课程中，我们学习了两大类强化学习方法：

- **基于价值（Value-based）**：如 Q-learning、DQN。先学习价值函数，再隐含地推导策略（如 $\epsilon$-greedy）。缺点是难以处理连续动作空间。
    
- **基于策略（Policy-based）**：如 REINFORCE。直接参数化并学习策略网络。优点是能处理连续动作和随机策略，但缺点是使用蒙特卡洛回报 $G_t$ 更新，导致**方差极大、学习效率低**。
    

**Actor-Critic (AC) 方法**的诞生正是为了结合两者的优点：

- **Actor（演员）**：即**策略网络 $\pi_\theta(a|s)$**。负责在给定状态下选择动作，并在Critic的指导下更新策略参数 $\theta$。
    
- **Critic（评论家）**：即**价值网络**（如 $q_w(s,a)$ 或 $v_w(s)$）。负责评估Actor当前选择的动作有多好，并利用TD学习（时序差分）更新自己的参数 $w$，为Actor提供低方差的梯度指导。
    

---

### 2. Q-Actor-Critic (Q-AC)

这是最基础的 Actor-Critic 形式，Critic 使用动作价值函数 $q_w(s,a)$。

#### 2.1 数学原理

根据策略梯度定理，策略的目标函数梯度为：

$$\nabla_\theta J(\theta) = \mathbb{E} \left[ q_{\pi_\theta}(S,A) \nabla_\theta \ln \pi_\theta(A|S) \right]$$

在 REINFORCE 中，我们用回合的总回报 $G_t$ 来近似真实的 $q_{\pi_\theta}(s,a)$。而在 Q-AC 中，我们**直接用一个神经网络 $q_w(s,a)$ 来逼近它**。

#### 2.2 参数更新过程

1. **Critic 更新（评价动作）**：
    
    使用类似于 Sarsa 的 TD 学习方法更新价值网络参数 $w$：
    
    $$w_{t+1} = w_t + \alpha_w \big[ r_{t+1} + \gamma q_w(s_{t+1}, a_{t+1}) - q_w(s_t, a_t) \big] \nabla_w q_w(s_t, a_t)$$
    
2. **Actor 更新（改进策略）**：
    
    使用 Critic 给出的 Q 值来指导策略网络参数 $\theta$ 的更新：
    
    $$\theta_{t+1} = \theta_t + \alpha_\theta q_w(s_t, a_t) \nabla_\theta \ln \pi_\theta(a_t|s_t)$$
    

---

### 3. 优势演员-评论家 (Advantage Actor-Critic, A2C)

虽然 Q-AC 解决了方差极大的问题，但直接使用 Q 值作为梯度权重依然存在一定的波动。为了进一步**降低方差**，我们引入**基线（Baseline）**的概念，演进为 A2C 算法。

#### 3.1 优势函数 (Advantage Function)

我们在策略梯度公式中减去一个基线 $v(S)$（状态价值函数），得到**优势函数**：

$$A_{\pi}(s, a) = q_{\pi}(s, a) - v_{\pi}(s)$$

- **物理含义**：优势函数衡量的是“在状态 $s$ 下采取动作 $a$，比该状态下所有动作的**加权平均表现**要好多少”。
    
- 引入基线后的策略梯度为：
    
    $$\nabla_\theta J(\theta) = \mathbb{E} \left[ A_{\pi}(S,A) \nabla_\theta \ln \pi_\theta(A|S) \right]$$
    

#### 3.2 绝妙的数学替换：TD 误差

如果要直接计算 $A(s,a)$，似乎需要同时训练 $Q$ 网络和 $V$ 网络，这会增加系统的复杂性。但数学推导给出了一个极其优雅的结论：**TD 误差是优势函数的无偏估计**。

- **TD 误差**定义为：$\delta_t = r_{t+1} + \gamma v_w(s_{t+1}) - v_w(s_t)$
    
- 可以证明：$\mathbb{E}[\delta_t | s_t, a_t] = A_{\pi}(s_t, a_t)$
    

因此，在 A2C 中，我们**只需要一个状态价值网络 $v_w(s)$** 即可！

#### 3.3 A2C 的参数更新公式

1. **计算 TD 误差 (Critic 的评价信号)**：
    
    $$\delta_t = r_{t+1} + \gamma v_w(s_{t+1}) - v_w(s_t)$$
    
2. **Critic 更新（优化打分能力）**：
    
    $$w_{t+1} = w_t + \alpha_w \delta_t \nabla_w v_w(s_t)$$
    
3. **Actor 更新（根据评价调整策略）**：
    
    $$\theta_{t+1} = \theta_t + \alpha_\theta \delta_t \nabla_\theta \ln \pi_\theta(a_t|s_t)$$
    

- **直观理解**：
    
    - 如果 $\delta_t > 0$：说明实际执行动作 $a_t$ 后的结果比预期的 $v(s_t)$ 要好（惊喜），Actor 就增加该动作的被选概率。
        
    - 如果 $\delta_t < 0$：说明动作表现不及预期（失望），Actor 就降低该动作的被选概率。
        

---

### 4. 总结 (Summary)

- **网络结构**：Actor-Critic 包含策略网络（Actor）和价值网络（Critic）。它们可以独立设计，但在深度强化学习中（如 A3C, PPO），为了提取公共特征，Actor 和 Critic 通常会**共享底层神经网络的隐藏层**，只在最后输出两个不同的头（一个是动作概率分布，一个是标量状态价值）。
    
- **步长/学习率**：通常 Critic 的学习率 $\alpha_w$ 要比 Actor 的学习率 $\alpha_\theta$ 大。因为 Critic 必须先准确评价出状态的好坏，Actor 才能跟着学到正确的策略（评价得准，才能学得好）。
    
- **算法地位**：Actor-Critic 框架结合了 Value-based 的低方差/单步更新特性与 Policy-based 的处理连续动作/随机策略特性，是现代强化学习最主流的基础架构（DDPG、TRPO、PPO、SAC 等先进算法均基于此框架）。
