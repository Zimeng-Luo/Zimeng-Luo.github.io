# 强化学习数学原理（一）：从 MDP 到动态规划

强化学习研究的是连续决策：一次动作不仅影响当前奖励，也会改变未来能到达的状态。本篇先假设环境模型已知，建立“怎样评价一个策略、怎样找到更好的策略”的数学框架。默认讨论有限状态、有限动作、奖励有界且 `0 ≤ γ < 1` 的折扣问题。

## 用 MDP 描述交互

马尔可夫决策过程（MDP）包含状态集合、动作集合、状态转移与奖励分布，以及折扣因子。策略是智能体要选择的决策规则，不是环境本身的固定组成。

| 量 | 回答的问题 |
| --- | --- |
| `sₜ` | 当前环境处于什么状态？ |
| `aₜ` | 现在采取什么动作？ |
| `p(s′, r ∣ s, a)` | 执行动作后如何转移、得到多少奖励？ |
| `π(a ∣ s)` | 智能体按什么概率选择动作？ |
| `γ` | 多看重未来的奖励？ |

马尔可夫性要求：给定当前状态和动作后，下一状态与奖励的分布不再依赖更早的历史。如果“当前位置”不足以预测未来，就可能还需要将速度、剩余资源等信息纳入状态。

回报把一连串即时奖励合成长期评价：

```text
Gₜ = Rₜ₊₁ + γRₜ₊₂ + γ²Rₜ₊₃ + …
   = Rₜ₊₁ + γGₜ₊₁
```

奖励有界且折扣小于 1，保证无限时域回报收敛。有限回合可以在终止状态结束求和；终止后的价值通常设为 0。较大的折扣因子提高远期奖励的权重，但最终行为仍由奖励和转移共同决定。

## 从回报推导贝尔曼方程

同一状态可能产生不同轨迹，因此用期望回报评价策略：

```text
vπ(s)    = Eπ[Gₜ ∣ Sₜ = s]
qπ(s,a)  = Eπ[Gₜ ∣ Sₜ = s, Aₜ = a]
vπ(s)    = Σₐ π(a ∣ s) qπ(s,a)
```

动作价值固定第一步动作，随后继续遵循策略。即使当前策略不会选择某个动作，它的动作价值仍有定义。

对 `Gₜ = Rₜ₊₁ + γGₜ₊₁` 取条件期望，记 `r̄(s,a)` 为即时奖励的条件均值，得到：

```text
qπ(s,a) = r̄(s,a) + γ Σₛ′ p(s′ ∣ s,a) vπ(s′)
vπ(s)   = Σₐ π(a ∣ s) [r̄(s,a) + γ Σₛ′ p(s′ ∣ s,a) vπ(s′)]
```

这一拆分不要求奖励与下一状态独立；需要时也可以直接对联合分布求和。

固定策略后，令 `Pπ` 为策略诱导的状态转移矩阵，`rπ` 为平均奖励向量：

```text
vπ = rπ + γPπvπ
(I − γPπ)vπ = rπ
```

小问题可以解线性方程组；数值实现通常直接求解系统，不显式计算逆矩阵。大问题可以反复更新 `vₖ₊₁ = rπ + γPπvₖ`，这就是迭代策略评估。

## 为什么反复更新能收敛？

把更新写成算子 `Tπv = rπ + γPπv`。由于 `Pπ` 的每一行是概率分布，在最大绝对值范数下：

```text
‖Tπu − Tπv‖∞ ≤ γ ‖u − v‖∞
```

每次更新至多保留原误差的 `γ` 倍。有限维实向量空间是完备空间，算子又把该空间映射回自身，因此收缩映射定理保证唯一不动点及迭代收敛。

例如只有一个状态、每步奖励为 1、`γ = 0.9`，则 `v = 1 + 0.9v`，解为 10。从 0 开始迭代得到 1、1.9、2.71……逐渐接近 10。若没有收缩条件，“存在不动点”本身并不能保证任意初值的迭代收敛。

## 从评价策略到寻找最优策略

最优状态价值 `v*` 是所有策略可达到的最大价值。对每个状态挑选最好的动作，得到贝尔曼最优方程：

```text
v*(s) = maxₐ [r̄(s,a) + γ Σₛ′ p(s′ ∣ s,a)v*(s′)]
```

固定状态下，对动作概率分布求最大期望，等价于取最大动作价值。多个动作并列时，可以任选一个，也可以在这些动作之间随机选择。因此最优价值唯一，并不意味着最优策略唯一。

| 算法 | 核心操作 | 计算取舍 |
| --- | --- | --- |
| 值迭代 | 对每个状态执行一次最优贝尔曼更新 | 每轮工作少，价值逐步接近最优值 |
| 策略迭代 | 先评估当前策略，再对其动作价值取贪婪策略 | 每轮评估成本较高，改进更充分 |
| 截断策略迭代 | 评估若干步后就改进 | 在单步更新和充分评估之间折中 |

最优算子同样是 `γ` 收缩，因此值迭代收敛到 `v*`。策略改进定理则说明，对准确的 `qπ` 取贪婪动作，得到的新策略不会比旧策略差。近似评估不能直接照搬这一精确保证。

实际停止值迭代时可以查看残差 `‖Tv − v‖∞`；在上述条件下，价值误差至多为残差除以 `1 − γ`。折扣越接近 1，同样的残差对应的误差上界越大。

## 奖励变换什么时候保持策略？

把奖励乘以正数，会保持策略之间的回报大小关系。对于每一步都计奖、具有相同无限折扣时域的任务，若 `r′ = ar + b` 且 `a > 0`：

```text
v′π = avπ + b/(1 − γ)
```

所有策略增加相同偏移，最优策略集合保持不变。`a < 0` 会逆转偏好；不同长度的回合若只在终止前增加常数，累计偏移又可能依赖回合长度，此时不能声称策略不变。
