# SVD 分解

## 核心摘要

SVD（Singular Value Decomposition，奇异值分解）把任意矩阵分解为两个正交矩阵和一个非负对角矩阵。它适用于非方阵、不可逆矩阵和低秩矩阵，是降维、压缩、最小二乘和 PCA 的基础工具。

## 1. 基本形式

对任意实矩阵 $A \in \mathbb{R}^{m \times n}$，都有：

$$
A = U\Sigma V^T
$$

| 符号 | 含义 |
| --- | --- |
| $U \in \mathbb{R}^{m \times m}$ | 左奇异向量组成的正交矩阵 |
| $\Sigma \in \mathbb{R}^{m \times n}$ | 非负对角矩阵 |
| $V \in \mathbb{R}^{n \times n}$ | 右奇异向量组成的正交矩阵 |
| $\sigma_i$ | $\Sigma$ 对角线上的奇异值，满足 $\sigma_i \ge 0$ |

正交矩阵满足：

$$
U^TU=I,\quad V^TV=I
$$

## 2. 奇异值从哪里来

SVD 和特征值分解的关系：

$$
A^TA = V\Sigma^T\Sigma V^T
$$

$$
AA^T = U\Sigma\Sigma^T U^T
$$

因此：

- $V$ 的列向量是 $A^TA$ 的特征向量。
- $U$ 的列向量是 $AA^T$ 的特征向量。
- 奇异值满足 $\sigma_i=\sqrt{\lambda_i}$，其中 $\lambda_i$ 是 $A^TA$ 的非负特征值。

## 3. 几何意义

矩阵 $A$ 对向量的作用可以理解为三步：

1. $V^T$：先旋转或反射坐标系。
2. $\Sigma$：沿各主方向缩放，缩放倍数是奇异值 $\sigma_i$。
3. $U$：再旋转或反射到输出空间。

奇异值越大，说明矩阵在对应方向上的拉伸越强；奇异值为 0，说明该方向被压扁，矩阵存在信息丢失。

## 4. 常用结论

- 矩阵的秩等于非零奇异值的个数。
- 最大奇异值表示矩阵最大的拉伸倍数。
- 若 $A$ 是实对称正定矩阵，SVD 和特征值分解形式会高度接近。
- 任意矩阵都可以做 SVD，但不是任意矩阵都能做普通特征值分解。

## 5. 截断 SVD

若只保留最大的 $k$ 个奇异值：

$$
A \approx U_k\Sigma_kV_k^T
$$

这称为截断 SVD，得到的是原矩阵的低秩近似。

常见用途：

- 数据降维
- 图像压缩
- 去噪
- 推荐系统
- PCA 的矩阵分解视角

## 6. 与 PCA 的关系

PCA 的目标是找到数据方差最大的方向。在线性代数视角下，可先理解 [[数学/07 01 线性代数 - 07 协方差矩阵.md]]] 的特征值分解；若数据矩阵已经中心化，对数据矩阵做 SVD，也可以得到主成分方向。

- $V$ 中的方向对应输入特征空间的主方向。
- 奇异值越大，对应方向解释的数据变化越多。
- 保留前 $k$ 个奇异值，相当于保留最主要的 $k$ 个信息方向。

## 7. NumPy 示例

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4],
    [5, 6],
])

U, S, Vt = np.linalg.svd(A)

print(U.shape)   # (3, 3)
print(S)         # 奇异值，一维数组
print(Vt.shape)  # (2, 2)
```

`np.linalg.svd(A)` 默认返回的 `S` 是一维奇异值数组，不是完整的 $\Sigma$ 矩阵。
