# 文件与权限

## 核心摘要

本篇用于查阅 Linux/类 Unix 环境中的文件、目录、软链接、权限位、`chmod`、`which` 和 `PATH`。

## 1. 文件、目录、软链接分别是什么
- 文件：存数据的基本单位，比如代码、日志、图片、模型权重。
- 目录：装文件的“容器”，本质上是名字到对象的映射。
- 软链接：一个指向目标路径的特殊文件，类似快捷方式。

## 2. 软链接和普通文件的区别
- 普通文件保存的是内容本身。
- 软链接保存的是“目标路径”。
- 目标文件删掉后，软链接会失效。

## 3. 权限位怎么看
执行 `ls -l` 时，你会看到类似：

```bash
-rwxr-xr--
drwxr-xr-x
lrwxrwxrwx
```

第一位代表类型：
- `-` 普通文件
- `d` 目录
- `l` 软链接

后面九位分三组：
- 拥有者权限
- 同组用户权限
- 其他用户权限

每组三位分别表示：
- `r` 读
- `w` 写
- `x` 执行

## 4. `chmod` 怎么用
`chmod` 用来改权限，常见有两种写法：

```bash
chmod 755 run.sh
chmod u+x run.sh
```

数字写法里：
- `r = 4`
- `w = 2`
- `x = 1`

所以：
- `7 = rwx`
- `6 = rw-`
- `5 = r-x`
- `4 = r--`

目录和文件的 `x` 含义不一样：
- 对文件：可执行
- 对目录：可进入、可访问里面的内容

## 5. `which`、环境变量和 `PATH`
`which` 用来找命令实际在哪个路径里。

```bash
which python
which pip
which ssh
```

如果系统找得到这个命令，说明它在 `PATH` 里。`PATH` 是 shell 查找命令时的搜索列表，通常用冒号分隔。

查看环境变量：

```bash
echo $PATH
printenv PATH
env | grep PATH
```

临时加路径：

```bash
export PATH="$HOME/bin:$PATH"
```
