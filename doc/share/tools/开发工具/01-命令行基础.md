# 命令行基础

## 核心摘要

本篇用于查阅命令行最常用的文件与目录操作，包括查看位置、切换目录、创建/复制/移动/删除文件、搜索文件和查看文件内容。


## 1. 最小心智模型

先把命令行理解成下面这几句话：

- `pwd`：我在哪
- `ls`：这里有什么
- `cd`：我要去哪
- `mkdir`：新建一个地方
- `cp`：复制一份
- `mv`：搬走或改名
- `rm`：删掉
- `find`：按文件名找
- `grep`：按内容找
- `cat` / `less` / `head` / `tail`：看文件
- `>` / `>>`：把输出写进文件

## 2. 看位置

### `pwd`

作用：查看当前目录。

```bash
pwd
```

PowerShell 对应：

```powershell
Get-Location
```

---

### `ls`

作用：列出当前目录下的文件和文件夹。

```bash
ls
ls notes
ls -a
ls -l
```

先记住最常用的两种：

- `ls`：看当前目录内容
- `ls 某目录`：看指定目录内容

> -a：查看全部文件（包括隐藏的文件）
> -l：查看详细信息

PowerShell 对应：

```powershell
Get-ChildItem
```

---

### `cd`

作用：切换目录。

```bash
cd notes
cd ..
cd .
```

你需要记住：

- `.`：当前目录
- `..`：上一级目录

例子：

如果当前目录是 `H:\study\learning`，那么：

```powershell
cd ..
```

会切换到：

```powershell
H:\study
```

## 3. 改文件和目录

### `mkdir`

作用：创建目录。

```bash
mkdir demo
mkdir notes
```

---

### `cp`

作用：复制文件或目录。

```bash
cp a.txt b.txt
cp a.txt notes/
cp -r dir1 dir2
```

常见理解：

- 文件到文件：复制并改名
- 文件到目录：复制进去
- 目录复制：一般需要 `-r`

PowerShell 对应：

```powershell
Copy-Item
```

---

### `mv`

作用：移动文件，或者重命名。

```bash
mv a.txt notes/
mv old.txt new.txt
```

它常见有两种用途：

- 换位置
- 改名字

PowerShell 对应：

```powershell
Move-Item
```

---

### `rm`

作用：删除文件或目录。

```bash
rm a.txt
rm -r notes
```

注意：

- 这是高风险命令。
- 初学时先只删除自己创建的练习目录和练习文件。

PowerShell 对应：

```powershell
Remove-Item
```

## 4. 找东西

### `find`

作用：按名字、路径、类型查找文件或目录。

```bash
find . -name "*.txt"
find . -type d
find . -name "note*"
```

解释：

- `.`：从当前目录开始找
- `-name "*.txt"`：找所有 `.txt` 文件
- `-type d`：只找目录

PowerShell 里更常见的替代写法：

```powershell
Get-ChildItem -Recurse -Filter *.txt
```

---

### `grep`

作用：在文件内容中搜索关键词。

```bash
grep "hello" a.txt
grep -r "TODO" .
grep -n "error" log.txt
```

常用参数：

- `-r`：递归搜索
- `-n`：显示行号

PowerShell 对应：

```powershell
Select-String "hello" a.txt
Select-String "TODO" -Path .\* -Recurse
```

区分：

- `find`：找文件名
- `grep`：找文件内容

## 5. 看文件内容

### `cat`

作用：直接打印文件内容。

```bash
cat a.txt
cat notes.txt
```

适合小文件，不适合特别长的文件。

PowerShell 对应：

```powershell
Get-Content
```

---

### `less`

作用：分页查看文件，适合长文件。

```bash
less log.txt
```

常见操作：

  - 空格 或 PageDown：下一页
  - b 或 PageUp：上一页
  - Enter 或 j：下一行
  - k：上一行
  - g：跳到文件开头
  - G：跳到文件结尾
  - /关键词：向下搜索
  - ?关键词：向上搜索
  - n：跳到下一个搜索结果
  - N：跳到上一个搜索结果
  - q：退出
  - h：查看帮助

注意：

- PowerShell 原生环境不一定有 `less`。
- 如果没有，可以先用 `Get-Content`、`head`、`tail` 代替部分需求。

---

### `head`

作用：查看文件开头几行。

```bash
head a.txt
head -n 5 a.txt
```

PowerShell 对应：

```powershell
Get-Content a.txt -Head 5
```

---

### `tail`

作用：查看文件末尾几行。

```bash
tail a.txt
tail -n 5 a.txt
tail -f log.txt
```

常见用途：

- `tail -n 5`：看最后 5 行
- `tail -f`：持续观察日志追加内容

PowerShell 对应：

```powershell
Get-Content a.txt -Tail 5
```

## 6. 输出重定向

### `>`

作用：把输出写入文件，并覆盖原内容。

```bash
echo hello > a.txt
ls > files.txt
```

如果目标文件已经有内容，会被覆盖。

---

### `>>`

作用：把输出追加到文件末尾。

```bash
echo world >> a.txt
```

例如，文件原来是：

```txt
hello
```

执行后变成：

```txt
hello
world
```
