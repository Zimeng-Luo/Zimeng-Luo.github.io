# LaTeX 公式

## 核心摘要

本篇用于查阅 LaTeX 数学公式的常见写法，包括行内公式、独立公式、编号、操作符、关系符、希腊字母、加粗、箭头、上标和跨行符号。

简易操作工具：[公式编辑器](https://www.latexlive.com/)

## 1. 简介

**行内公式**（与文字在同一行）：

```latex
勾股定理：$a^2 + b^2 = c^2$ 是几何学基本定理。
```

勾股定理：  $ a^2+b^2 = c^2$是几何学基本定理。

**独立公式**（单独成行，居中显示）：

```latex
$$
E = mc^2
$$
```

$$
E=mc^2
$$
